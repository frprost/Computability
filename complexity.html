Complexity: time and space of computation

Knowing that a problem is decidable does not say whether it is feasible. Here we measure the time and memory of a computation: complexity classes, constants that can always be gained, memory that nondeterminism saves only up to a square, and NP-complete problems.

That a problem has a computable solution does not say whether it can be obtained before the end of the universe. Here we measure the time and memory needed, and meet the greatest open question of computer science: is P equal to NP?

So far, we have asked what is computable, without worrying about time. But a computation that requires more steps than there are atoms in the universe is, in practice, impossible. Complexity theory measures the cost of computations: how many steps, how much memory.

It separates the “easy” problems, whose computation time grows reasonably with the size of the data, from the problems that seem to require trying all possibilities. Between the two lie thousands of concrete problems (timetables, delivery rounds, giant sudokus), about which nobody knows whether they are easy or hard. A one-million-dollar prize will reward whoever settles the question.

The previous chapters separated the decidable from the undecidable. Within the decidable, not everything is within reach: an algorithm that needs $2^n$ steps on an input of size $n$ is unusable from $n=100$ on. Complexity theory classifies decidable problems according to the resources they require, time and space (memory). It takes up the tools of computability: simulation, diagonalization, reduction, completeness.

Measuring time and space

The time of a computation is measured by its number of steps and memory by the number of cells used, as a function of the size of the data. Problems are then grouped into classes: those solvable in “polynomial” time (P), those for which a proposed solution can be checked quickly (NP), those that require a reasonable memory (PSPACE), etc.

Definition
Machines, time and space

We use the $k$-tape Turing machines of chapter 2: at each step, the machine reads the $k$ symbols under its heads and, according to its state, writes $k$ symbols, moves each head one cell (or leaves it in place) and changes state. It has an accepting state and a rejecting state, in which it halts. A nondeterministic machine may have several possible transitions; it accepts if at least one of its computations reaches the accepting state (chapter 3).

  • The machine works in time $t(n)$ if, on every input of length $n$, all its computations halt in at most $t(n)$ steps.
  • For space, the input is on a read-only tape, between two end markers that the head does not cross, and only the cells visited on the other tapes, called work tapes, are counted. The machine works in space $s(n)$ if, on every input of length $n$, none of its computations visits more than $s(n)$ work cells. A deterministic machine in space $s(n)$ that decides a language must moreover halt on every input.

We write $\mathrm{DTIME}(t)$, $\mathrm{NTIME}(t)$ for the classes of languages decided (accepted, in the nondeterministic case) by a deterministic (nondeterministic) machine in time $O(t(n))$, and $\mathrm{DSPACE}(s)$, $\mathrm{NSPACE}(s)$ for their analogues for space.

A function $s(n)\ge\log_2n$ is space-constructible if a deterministic machine computes the binary expansion of $s(n)$ from an input of length $n$, in space $O(s(n))$. A function $t(n)\ge n$ is time-constructible if a deterministic machine computes the binary expansion of $t(n)$ in time $O(t(n))$. The usual functions ($\log_2n$ rounded, $n^k$, $2^n$, $n\log_2n$…) are.

In plain words. The time of a computation is its number of steps; its space is the number of memory cells it uses to work. They are measured as a function of the size of the data: how many steps to sort a thousand names, a million names?

The data themselves are not counted in the memory used. This makes it possible to speak of very frugal computations, which use only enough to hold a few counters, while the input is enormous. To look up a name in a directory of a million pages, it suffices to remember two page numbers: the first and the last page of the area where one is still searching.

The number of tapes changes time only by a polynomial factor (one-tape simulation, in $O((n+t)^2)$), and space only by a constant factor (the $k$ work tapes are stored on $k$ tracks of a single one, as in the same simulation). The convention “all computations halt in at most $t(n)$ steps” is that of chapter 3; for space, nondeterministic computations are not required to halt, only never to leave the allotted space.

For logarithmic space, picture a program that reads a huge file without being able to copy it, and has only a few integer variables, each the size of a pointer into the file: counting brackets, comparing two positions, following a path in a graph remembering only the current vertex.

Definition
The main complexity classes
$$\begin{aligned} \mathsf L&=\mathrm{DSPACE}(\log n), & \mathsf{NL}&=\mathrm{NSPACE}(\log n),\\ \mathsf P&=\textstyle\bigcup_k\mathrm{DTIME}(n^k), & \mathsf{NP}&=\textstyle\bigcup_k\mathrm{NTIME}(n^k),\\ \mathsf{PSPACE}&=\textstyle\bigcup_k\mathrm{DSPACE}(n^k), & \mathsf{NPSPACE}&=\textstyle\bigcup_k\mathrm{NSPACE}(n^k),\\ \mathsf{EXP}&=\textstyle\bigcup_k\mathrm{DTIME}(2^{n^k}). && \end{aligned}$$

For a class $\mathcal C$, $\mathrm{co}\mathcal C$ denotes the class of complements of languages of $\mathcal C$.

In plain words. Problems are sorted into families, called classes, according to the time or memory they require. The main ones are P (problems solved in reasonable time), NP (problems for which a solution is checked in reasonable time), PSPACE (problems solved with a reasonable memory) and EXP (problems that require exponential time).

“Reasonable” has a precise meaning: the time grows like a fixed power of the size of the data (the square, the cube…), and not like 2 multiplied by itself as many times as the input has characters. A giant Sudoku gives the idea: finding the solution seems to require an enormous time, but checking a filled grid is quick. It is a problem in NP. Many two-player games, played on larger and larger boards, are in PSPACE. These families do not depend on the machine chosen, thanks to the simulations between machines.

These definitions agree with those of chapter 3 for $\mathsf P$ and $\mathsf{NP}$: a $k$-tape machine in time $n^j$ is simulated by a one-tape machine in time $O(n^{2j})$, and the simulation also works for nondeterministic machines (each choice is simulated the same way). Examples: the language of palindromes is in $\mathsf L$ (two counters indicate the positions to compare); reachability in a directed graph (is there a path from $u$ to $v$?) is in $\mathsf{NL}$ (guess the path vertex by vertex, remembering only the current vertex and a length counter); satisfiability of propositional formulas is in $\mathsf{NP}$ (guess an assignment, evaluate the formula).

The file complexite.py contains two reachability algorithms for graphs: breadth-first search, which remembers all vertices already seen, and Savitch’s algorithm proved below, which remembers only three per level of recursion.

Lemma
Counting configurations

Let $M$ be a machine (deterministic or not) with $k$ work tapes, in space $s(n)\ge\log_2n$. There is a constant $c_M$ such that, for $n\ge2$, the number of configurations of $M$ on an input of length $n$ (state, position of the input head, contents and head positions of the work tapes) is at most $2^{c_Ms(n)}$. In particular, a deterministic machine in space $s(n)$ that halts does so in at most $2^{c_Ms(n)}$ steps.

In plain words. A machine that uses little memory has only a limited number of possible situations. If it runs longer than this number, it necessarily passes again through a situation already seen, and it loops.

With ten memory cells each holding 0 or 1, there are only 1,024 possible states of the memory. A machine that makes more than 1,024 steps passes again through a state already seen, and since it has no randomness, it will do exactly the same thing as before, forever. Little memory therefore implies a limited time, even if this limit can be very large.

With $E$ the set of states and $A$ the alphabet, there are at most $|E|\cdot(n+2)\cdot\big(s(n)\,|A|^{s(n)}\big)^k$ configurations. For $n\ge2$, $n+2\le n^2\le2^{2s(n)}$ and $s(n)\le2^{s(n)}$, whence the bound $2^{c_Ms(n)}$ with $c_M=\log_2|E|+2+k(1+\log_2|A|)$. If a deterministic computation lasts longer than this number of steps, two configurations repeat; the computation is then periodic and does not halt.

This is chapter 3’s argument for bounded-tape machines, made quantitative. A computer with one megabyte of memory has at most $2^{8{,}388{,}608}$ states: it is in principle a finite automaton, but the number is such that the remark has no practical bearing.

Theorem
Inclusions between the classes

For $t(n)\ge n$ time-constructible and $s(n)\ge\log_2n$ space-constructible:

$$\mathrm{DTIME}(t)\subseteq\mathrm{NTIME}(t)\subseteq\mathrm{DSPACE}(t),\qquad \mathrm{DSPACE}(s)\subseteq\mathrm{NSPACE}(s)\subseteq\textstyle\bigcup_c\mathrm{DTIME}(2^{cs}).$$

Consequently $\mathsf L\subseteq\mathsf{NL}\subseteq\mathsf P\subseteq\mathsf{NP}\subseteq\mathsf{PSPACE}\subseteq\mathsf{EXP}$.

In plain words. The families of problems are nested in one another: what can be done with very little memory can be done in reasonable time, what can be done in reasonable time can be done with a reasonable memory, and so on.

We know that the chain is not flat: some families are strictly larger than others, thanks to the hierarchy theorems below. But between two neighbouring families, we almost never know whether the nesting is strict. The question “P = NP?” (is finding as easy as checking?) is merely the most famous of these unknowns. It is one of the seven “Millennium Prize Problems”, each endowed with a prize of one million dollars.

$\mathrm{NTIME}(t)\subseteq\mathrm{DSPACE}(t)$. Let $N$ be nondeterministic in time $c\,t(n)$, with at most $d$ possible transitions at each step. A computation is determined by the sequence of its choices, a word of length $c\,t(n)$ over $\{1,\dots,d\}$. The deterministic machine computes $t(n)$, then enumerates these words in order on a tape, and, for each, simulates $N$ following these choices, erasing the work tapes between two simulations. It accepts if one of the simulations accepts. Space: the choice word, plus the space of one simulation, which in $c\,t(n)$ steps visits at most $c\,t(n)$ cells per tape; so $O(t(n))$. To simulate the input tape of $N$, which is not read-only, first copy it onto a work tape ($n\le t(n)$ cells).

$\mathrm{NSPACE}(s)\subseteq\bigcup_c\mathrm{DTIME}(2^{cs})$. Let $N$ be nondeterministic in space $s(n)$. By the lemma, its configuration graph on an input $x$ (vertices: configurations; arcs: possible steps) has at most $2^{c_Ms(n)}$ vertices, each described by a word of length $O(s(n))$. $N$ accepts $x$ if and only if an accepting configuration is reachable from the initial configuration. A deterministic machine computes $s(n)$, then performs a breadth-first search of this graph, writing the configurations already reached on a tape. Each of the at most $2^{c_Ms(n)}$ steps of the search examines one configuration, generates its successors (a bounded number), and compares each with the list; all this costs time polynomial in $2^{c_Ms(n)}$ and in $n\le2^{s(n)}$, hence $2^{O(s(n))}$.

Consequences. $\mathsf{NL}\subseteq\mathrm{DTIME}(2^{O(\log n)})=\bigcup_k\mathrm{DTIME}(n^k)=\mathsf P$; $\mathsf{NP}\subseteq\bigcup_k\mathrm{DSPACE}(n^k)=\mathsf{PSPACE}$; $\mathsf{PSPACE}\subseteq\bigcup_k\mathrm{DTIME}(2^{O(n^k)})=\mathsf{EXP}$. The other inclusions are immediate (a deterministic machine is a special case of a nondeterministic one).

The two simulations of the proof are those that real programs use when they must explore all possibilities: backtracking (trying each sequence of choices reusing the same memory, like SAT solvers) saves space; breadth-first search with memorization of visited states (like model checkers) saves time. No method is known, in general, that saves both.

Gaining constants

A machine faster by a fixed factor does not change the class of a problem: a constant factor can always be gained by grouping cells together. This is why we care only about the way time grows, not about constants.

Theorem
Linear speedup theorem (Hartmanis and Stearns, 1965)

Let $L$ be a language decided by a $k$-tape machine $M$ in time $t(n)\ge n$. For every $\varepsilon>0$, $L$ is decided by a $(k+1)$-tape machine in time at most $\varepsilon\,t(n)+n+9$.

Likewise, if $L$ is decided in space $s(n)$, it is decided in space $\lceil\varepsilon\,s(n)\rceil$ for every $\varepsilon>0$ (linear space compression).

In plain words. One can always make a machine two, ten or a hundred times faster, by having it process several cells at once.

This is what modern computers do, processing 64 binary digits at once instead of one. Constant factors therefore say nothing about the deep difficulty of a problem: what matters is the way time grows when the data grow. The only limit: all the data must be read at least once.

Fix an integer $m$, chosen below. The new machine $M'$ codes a block of $m$ consecutive cells of $M$ by a single symbol (an $m$-tuple of symbols of $M$). Its state remembers the state of $M$ and, for each tape, the position of $M$’s head in the current block (a number between $0$ and $m-1$).

Preparation. $M'$ reads the input on its tape 1 and writes it, compressed into blocks of $m$, on its tape 2 ($n+1$ steps), then brings the head of tape 2 back to the start ($\lceil n/m\rceil+1$ steps). From then on tape 2 plays the role of $M$’s input tape, and tapes $3,\dots,k+1$ that of its other tapes (empty, hence already “compressed”).

Simulating $m$ steps of $M$ in 6 steps of $M'$. (a) In 4 steps (left, right, right, left), $M'$ reads on each tape the current block and its two neighbours, and remembers them in its state: it knows $3m$ cells around each head. (b) In $m$ steps, a head of $M$ moves at most $m$ cells; so it stays within these three blocks. $M'$ thus knows, through its transition table, the result of $m$ steps of $M$ (or the halt of $M$ before). (c) Only the current block and a single one of its neighbours can have changed: to reach the left block and then the right one, a head would have to cover more than $m$ cells. In 2 steps, $M'$ rewrites the current block, moves if necessary to the modified neighbour and rewrites it, and ends on the block where $M$’s head is.

Total. $n+2+\lceil n/m\rceil+1+6\lceil t(n)/m\rceil\le n+9+(n+6t(n))/m\le n+9+7t(n)/m$, since $n\le t(n)$. With $m\ge7/\varepsilon$, we get $\varepsilon\,t(n)+n+9$.

Space. Same coding by blocks of $m\ge1/\varepsilon$ cells on the work tapes, without changing the number of steps: $s(n)$ visited cells of $M$ occupy at most $\lceil s(n)/m\rceil+1$ blocks. (The $+1$ disappears by remembering the contents of the last block started in the state, or by choosing $m$ slightly larger.)

The price of speedup is the size of the machine: the alphabet goes from $|A|$ to $|A|^m$ symbols, and the transition table grows accordingly. This is the trade-off between machine word width and processor speed. Blum (1967) showed far worse: there are decidable problems with no fastest algorithm, for which every algorithm can be sped up, not by a constant, but for example by a logarithm, indefinitely (Blum’s speedup theorem, quoted for information).

Nondeterminism and space

A “nondeterministic” machine is a machine that would always guess the right choice. For memory, this magic power gains only a square factor: this is Savitch’s theorem.

Theorem
Savitch’s theorem (1970)

For every space-constructible function $s(n)\ge\log_2n$,

$$\mathrm{NSPACE}(s)\subseteq\mathrm{DSPACE}(s^2).$$

In particular, $\mathsf{PSPACE}=\mathsf{NPSPACE}$, and $\mathsf{NL}\subseteq\mathrm{DSPACE}(\log^2n)$: reachability in a graph with $N$ vertices is decided in space $O(\log^2N)$.

In plain words. Imagine a magic machine that would always guess the right path. For memory, it has almost no advantage over an ordinary machine that methodically tries everything: the latter needs only a memory “squared”.

For time, nobody knows how to do without the magic without an enormous cost: that is precisely the P = NP question. For memory, it is possible because memory can be reused. To find out whether one can travel from Paris to Rome in a thousand stages, one tries each city as the middle stage; one checks the first half of the journey, erases, then checks the second half with the same memory. Time, on the other hand, cannot be reused: a second spent is lost. The resulting algorithm is very slow but very frugal.

Let $N$ be nondeterministic in space $s(n)$ accepting $L$. Modifying $N$ if necessary, assume that before accepting it erases its work tapes and brings its heads back to the start: there is then a single accepting configuration $c_{\mathrm{acc}}$. By the lemma, a configuration is written on $O(s(n))$ cells, and there are at most $2^{c\,s(n)}$ of them, with $c=c_N$.

For two configurations $u,v$ and an integer $i$, write $\mathrm{ACC}(u,v,i)$ for: “$v$ is reachable from $u$ in at most $2^i$ steps”. Then $\mathrm{ACC}(u,v,0)$ is equivalent to “$u=v$ or $v$ follows $u$ in one step”, which can be checked directly, and, for $i\ge1$,

$$\mathrm{ACC}(u,v,i)\iff\exists w\ \big[\mathrm{ACC}(u,w,i-1)\wedge\mathrm{ACC}(w,v,i-1)\big],$$

where $w$ ranges over configurations (a path of length at most $2^i$ splits into two paths of length at most $2^{i-1}$). The deterministic machine computes $s(n)$, then evaluates $\mathrm{ACC}(c_{\mathrm{init}},c_{\mathrm{acc}},c\,s(n))$: since there are at most $2^{c\,s(n)}$ configurations, a path without repetition has at most that many steps, and $N$ accepts $x$ if and only if this statement is true.

The recursive evaluation uses a stack written on a work tape. Each level of the stack contains $u$, $v$, $i$, the configuration $w$ being tried and an indication of the current subcall (first or second): $O(s(n))$ cells. To try the $w$, enumerate them as words of length $O(s(n))$, ignoring those that are not configurations. The depth of the stack is $c\,s(n)+1$. The total space is therefore $O(s(n)^2)$, and linear space compression gives $s(n)^2$.

Consequences. $\mathsf{NPSPACE}=\bigcup_k\mathrm{NSPACE}(n^k)\subseteq\bigcup_k\mathrm{DSPACE}(n^{2k})=\mathsf{PSPACE}$. For reachability: a graph with $N$ vertices, given by its adjacency matrix, is an input of length $n=N^2$; the nondeterministic search algorithm uses space $O(\log n)$, whence deterministic space $O(\log^2n)=O(\log^2N)$.

In complexite.py, the function savitch decides reachability in a 16-vertex graph with a stack of depth $4=\log_216$, each level remembering three vertices, at the cost of 40,319 recursive calls; breadth-first search does the same job visiting each arc once, but remembers up to all the vertices. It is also known (result quoted) that $\mathsf{NL}=\mathrm{co}\mathsf{NL}$: a nondeterministic logarithmic-space algorithm can certify that there is no path (Immerman and Szelepcsényi, independently, 1987-1988).

More resources, more problems

With more time or more memory, strictly more problems can be solved. This is not obvious, and the proof uses, once again, the diagonal argument.

Theorem
Space hierarchy theorem (Stearns, Hartmanis, Lewis, 1965)

Let $s_1,s_2\ge\log_2n$, with $s_2$ space-constructible and $s_1(n)/s_2(n)\to0$. Then $\mathrm{DSPACE}(s_1)\subsetneq\mathrm{DSPACE}(s_2)$.

In particular $\mathsf L\subsetneq\mathsf{PSPACE}$, and, with Savitch’s theorem, $\mathsf{NL}\subsetneq\mathsf{PSPACE}$.

In plain words. With substantially more memory, one solves problems that could not be solved with less.

This seems obvious, but it has to be proved, and the proof is again Cantor’s diagonal. A machine that has a little more memory than all the machines of a family can imitate them all, and do, on a well-chosen input, the opposite of each. It therefore solves a problem that no machine of the family solves.

Code each deterministic machine $M$ (with one work tape, which changes space only by a constant) by a word $\langle M\rangle$, so that a word of the form $\langle M\rangle10^j$ decomposes unambiguously. The machine $D$, on an input $w$ of length $n$:

  1. computes $s_2(n)$ and marks off $s_2(n)$ cells on its work tapes;
  2. if $w$ is not of the form $\langle M\rangle10^j$, rejects;
  3. simulates $M$ on $w$, coding each symbol of $M$ by a block of fixed length $\ell_M$ and keeping a binary step counter; if the simulation leaves the marked cells, or if the counter exceeds $2^{s_2(n)}$, $D$ rejects;
  4. if $M$ accepts, $D$ rejects; if $M$ rejects, $D$ accepts.

$D$ always halts and uses space $O(s_2(n))$: it decides a language $L_D\in\mathrm{DSPACE}(s_2)$, by linear compression. Suppose $L_D$ is decided by a machine $M$ in space $a\,s_1(n)$. Since $s_1/s_2\to0$, there is $j$ such that, for $w=\langle M\rangle10^j$ and $n=|w|$, we have $\ell_M\,a\,s_1(n)\le s_2(n)$ and $2^{c_M a s_1(n)}\le2^{s_2(n)}$, where $c_M$ is the constant of the configuration lemma. Then the simulation fits in the marked space, and $M$, which halts, does so before the counter overflows. So $D$ does the opposite of $M$ on $w$: $w\in L_D\iff w\notin L(M)=L_D$. Contradiction.

Consequences. $\mathsf L=\mathrm{DSPACE}(\log n)\subsetneq\mathrm{DSPACE}(n)\subseteq\mathsf{PSPACE}$. By Savitch, $\mathsf{NL}\subseteq\mathrm{DSPACE}(\log^2n)\subsetneq\mathrm{DSPACE}(n)\subseteq\mathsf{PSPACE}$.

The step counter of step 3 is indispensable: without it, $D$ could loop forever simulating a machine that loops in bounded space, and would decide nothing. This is the quantitative version of the halting problem: in bounded space, halting becomes decidable, because the number of configurations is finite.

Theorem
Time hierarchy theorem (Hartmanis and Stearns, 1965)

Let $t_1(n)\ge n$ and $t_2$ time-constructible, with $t_1(n)^2/t_2(n)\to0$. Then $\mathrm{DTIME}(t_1)\subsetneq\mathrm{DTIME}(t_2)$. In particular $\mathsf P\subsetneq\mathsf{EXP}$.

(Hennie and Stearns, 1966: the hypothesis $t_1(n)\log t_1(n)/t_2(n)\to0$ suffices; result quoted.)

In plain words. With substantially more time, one solves problems that could not be solved in less time.

In particular, there are problems that can be solved in exponential time but not in reasonable time. The frontier of feasibility therefore has a meaning. Natural examples are known: deciding who wins at chess on a larger and larger board is one of them. But for the problems of NP, such as the giant Sudoku, nobody has managed to give the same kind of proof.

We diagonalize against one-tape machines: if $L\in\mathrm{DTIME}(t_1)$, a one-tape machine decides it in time $O((n+t_1(n))^2)=O(t_1(n)^2)$ (one-tape simulation). A three-tape machine $U$ simulates a one-tape machine $M$, whose description is written on a tape, in $d_M$ steps per step of $M$: tape 1 holds the tape of $M$ (each symbol coded by a block of fixed length), tape 2 the description of $M$, tape 3 its current state; a step of $M$ consists in scanning the description to find the transition, then applying it. The constant $d_M$ depends only on the length of the description.

The machine $D$, on $w$ of length $n$, computes $t_2(n)$ in binary and writes it on a “budget” tape. If $w$ is of the form $\langle M\rangle10^j$, it simulates $M$ on $w$ with $U$, decrementing the budget at each of its own steps. It rejects if $M$ accepts, and accepts if $M$ rejects or if the budget runs out. Decrementing a binary counter costs a constant number of operations on average (over $N$ decrements, the borrows take fewer than $2N$ steps in all), so $D$ works in time $O(t_2(n))$: $L_D\in\mathrm{DTIME}(t_2)$ (the classes are defined up to a constant, which linear speedup justifies).

If $L_D$ were in $\mathrm{DTIME}(t_1)$, it would be decided by a one-tape machine $M$ in time $T(n)=O(t_1(n)^2)$. For $w=\langle M\rangle10^j$ with $j$ large enough, the number of steps $D$ needs to carry the simulation through, $O(d_M\,T(n)+n)$ including budget decrements, would be less than $t_2(n)$, since $t_1^2/t_2\to0$: the simulation would run to completion, and $D$ would do the opposite of $M$ on $w$. Contradiction.

$\mathsf P\subsetneq\mathsf{EXP}$. We have $\mathsf P\subseteq\mathrm{DTIME}(2^n)$, since $n^k=O(2^n)$ for every $k$, and $\mathrm{DTIME}(2^n)\subsetneq\mathrm{DTIME}(2^{3n})\subseteq\mathsf{EXP}$ by the theorem, with $t_1(n)=2^n$, $t_2(n)=2^{3n}$ and $t_1(n)^2/t_2(n)=2^{-n}\to0$.

The factor between $t_1$ and $t_2$ (here a square, or a logarithm with the Hennie-Stearns simulation) is the cost of universal simulation: a fixed machine must be able to imitate all the others. For random-access machines, whose universal simulation has constant overhead, the hierarchy is finer still.

Reductions and NP-completeness

Some problems are the “hardest” of NP: if one of them could be solved quickly, all the others could be too. The first one discovered is SAT, which asks whether a logical formula can be made true. Thousands of practical problems are in this situation.

Theorem
Oracles do not settle P versus NP (Baker, Gill, Solovay, 1975)

There is an oracle $A$ such that $\mathsf P^A=\mathsf{NP}^A$, and an oracle $B$ such that $\mathsf P^B\ne\mathsf{NP}^B$. (The relative classes are defined with oracle machines, each query costing one step.)

In plain words. The proof methods that worked so well in computability will not suffice to settle the question “P = NP?”. They work just as well in imaginary worlds where the answer is yes as in others where it is no.

Imagine that all machines receive the same outside help, an “oracle” that instantly answers certain questions. Arguments by imitation and by diagonalization remain valid with any oracle. Now an oracle is known with which P = NP, and another with which P ≠ NP. An argument that works in both worlds therefore cannot settle the question. This is the first of the known “barriers”: ideas of another kind will be needed, and this is one reason for the difficulty of the problem.

The oracle $A$. Take for $A$ the language of true quantified Boolean formulas, which is PSPACE-complete (below). We have $\mathsf{NP}^A\subseteq\mathsf{NPSPACE}=\mathsf{PSPACE}$: a nondeterministic polynomial-time machine asks queries of polynomial length, and each is answered in polynomial space; the last equality is Savitch’s theorem. And $\mathsf{PSPACE}\subseteq\mathsf P^A$, since every language of $\mathsf{PSPACE}$ reduces to $A$ in polynomial time. So $\mathsf{NP}^A\subseteq\mathsf P^A$.

The oracle $B$. For every set $B$ of words over $\{0,1\}$, let $L_B=\{1^n:B\text{ contains a word of length }n\}$. We have $L_B\in\mathsf{NP}^B$: guess a word $w$ of length $n$ and ask the oracle whether $w\in B$. We build $B$ in stages so that $L_B\notin\mathsf P^B$. Let $M_0,M_1,\dots$ be an enumeration of oracle machines equipped with a clock, machine $M_i$ halting in at most $n^i$ steps; every polynomial-time oracle machine is equivalent to one of them. At stage $i$, choose $n$ larger than the lengths chosen and than all lengths of queries asked at previous stages, and such that $n^i<2^n$, and run $M_i$ on $1^n$ with the oracle built so far (which contains no word of length $\ge n$). If $M_i$ accepts, add no word of length $n$ to $B$, so $1^n\notin L_B$. If $M_i$ rejects, add to $B$ a word of length $n$ that $M_i$ did not query; there is one, since $M_i$ asked at most $n^i<2^n$ queries. Then $1^n\in L_B$. In both cases, the oracle’s answers to $M_i$’s queries do not change (later stages add only longer words), and $M_i^B$ is wrong on $1^n$. No $M_i$ decides $L_B$ with oracle $B$: $L_B\in\mathsf{NP}^B\setminus\mathsf P^B$.

Definition
Polynomial reduction, complete problems

$A\le_pB$ if there is a function $f$ computable in polynomial time such that $x\in A\iff f(x)\in B$. For a class $\mathcal C$, $B$ is $\mathcal C$-hard if $A\le_pB$ for every $A\in\mathcal C$, and $\mathcal C$-complete if moreover $B\in\mathcal C$.

In plain words. A problem A reduces to a problem B if each question of A can be quickly transformed into a question of B that has the same answer. A problem is complete for a family if it is the hardest of this family: all the others reduce to it.

If a single NP-complete problem could be solved quickly, all of them could. This is exactly the situation of the halting problem for semi-decidable problems (completeness of halting), with a time constraint in addition.

$\le_p$ is transitive: if $f$ and $g$ are computable in time $p$ and $q$, then $|f(x)|\le p(|x|)$ (no more than one symbol is written per step), and $g\circ f$ is computed in time $p(n)+q(p(n))$. If $B\in\mathsf P$ and $A\le_pB$, then $A\in\mathsf P$. So if a single NP-complete problem is in $\mathsf P$, then $\mathsf P=\mathsf{NP}$.

Reductions are at the heart of practice: a timetabling, routing or placement problem is translated into an instance of SAT or of integer linear programming, which highly optimized solvers handle. These solvers are exponential in the worst case, but routinely solve industrial instances with millions of variables.

Theorem
Cook-Levin theorem (1971, 1973)

The problem $\mathrm{SAT}$ (is a given propositional formula satisfiable?) is NP-complete. It remains so when restricted to formulas in conjunctive normal form (conjunctions of disjunctions of literals).

In plain words. The SAT problem consists in finding out whether a logical formula can be made true by choosing well the value true or false of each of its variables. It is the hardest of the problems of NP: a fast method for SAT would give one for all.

The idea is that every fast verification can be written as a logical formula. “There is a solution” becomes “there is a choice of true and false that makes this formula true”. The big table of the computation, line by line, translates into a long list of logical constraints between neighbouring cells.

Since then, thousands of problems have been shown NP-complete: colouring a map with three colours, finding the shortest tour of a travelling salesman, filling a knapsack as well as possible, making a timetable, solving a giant Sudoku. They are all linked: if one is easy, they all are.

$\mathrm{SAT}\in\mathsf{NP}$: guess an assignment and evaluate the formula. Let $L\in\mathsf{NP}$, accepted by a one-tape nondeterministic machine $N$ in time $p(n)$ (one reduces to one tape by the simulation, which works for nondeterministic machines, while remaining polynomial; take $p(n)\ge n$). Assume that $N$, once in the accepting state $q_a$, stays there without changing anything. Let $x$ have length $n$, $p=p(n)$. A computation of $p$ steps visits only cells $-p,\dots,p$. Introduce propositional variables:

  • $X_{i,j,a}$: “at step $i$, cell $j$ contains $a$” ($0\le i\le p$, $|j|\le p$, $a\in A$);
  • $H_{i,j}$: “at step $i$, the head is on cell $j$”; $Q_{i,q}$: “at step $i$, the state is $q$”.

The formula $\Phi_x$ is the conjunction of:

  1. for each $i$: exactly one $Q_{i,q}$, exactly one $H_{i,j}$ and, for each $j$, exactly one $X_{i,j,a}$ true (“at least one” is a disjunction, “at most one” the conjunction of the $\neg(u\wedge v)$);
  2. the initial row: $Q_{0,q_0}$, $H_{0,0}$, $X_{0,j,x_j}$ for $0\le j<n$, and $X_{0,j,B}$ for the other $j$;
  3. for each $i<p$, $j$, $a$: $(\neg H_{i,j}\wedge X_{i,j,a})\Rightarrow X_{i+1,j,a}$ (a cell away from the head does not change);
  4. for each $i<p$, $j$, $q$, $a$: $(H_{i,j}\wedge Q_{i,q}\wedge X_{i,j,a})\Rightarrow\bigvee\big(Q_{i+1,q'}\wedge X_{i+1,j,b}\wedge H_{i+1,j+d}\big)$, the disjunction ranging over the transitions $(q,a)\to(q',b,d)$ of $N$ that do not take the head outside cells $-p,\dots,p$ (an empty disjunction is false);
  5. $Q_{p,q_a}$.

An assignment satisfying 1 describes a sequence of $p+1$ configurations; 2 imposes the initial configuration on $x$; 3 and 4 impose that each configuration follows the previous one by a transition of $N$; 5 imposes acceptance. So $\Phi_x$ is satisfiable if and only if $N$ has an accepting computation on $x$ (a computation that accepts before step $p$ is extended by staying in $q_a$). $\Phi_x$ has $O(p^2)$ variables and $O(p^3)$ elementary conditions (the most numerous are the “at most one” on head positions), each of bounded size or $O(p)$: it is written in time polynomial in $n$. So $L\le_p\mathrm{SAT}$.

Conjunctive normal form. Constraints 1, 2, 3 and 5 are already clauses. For 4, introduce a new variable $C_\tau$ for each possible transition $\tau$, and write the clauses $\neg H_{i,j}\vee\neg Q_{i,q}\vee\neg X_{i,j,a}\vee\bigvee_\tau C_\tau$, then, for each $\tau=(q',b,d)$, the three clauses $\neg H_{i,j}\vee\neg Q_{i,q}\vee\neg X_{i,j,a}\vee\neg C_\tau\vee\ell$ with $\ell\in\{Q_{i+1,q'},X_{i+1,j,b},H_{i+1,j+d}\}$. Every assignment satisfying the original formula extends (make true the $C_\tau$ of the transition used), and conversely.

The function formule_cook_levin in complexite.py writes these clauses for a small nondeterministic machine (which “guesses” a cell containing 1). On input $0010$ and 5 steps, the formula has 326 variables and 1,041 clauses. A small SAT solver, included in the file, checks that the formula is satisfiable exactly when the machine accepts, on the 127 words of length at most 6.

Proposition
Complete problems for the other classes

(Results quoted.) Reachability in a directed graph is NL-complete for logarithmic-space reductions. Validity of quantified Boolean formulas ($\forall x_1\exists x_2\cdots\,\phi$) is PSPACE-complete (Stockmeyer and Meyer, 1973). Satisfiability of the formula $\exists y_1\forall y_2\cdots$ with $k$ alternations is complete for level $\Sigma^p_k$ of the polynomial hierarchy.

In plain words. Each family of problems has its “hardest” problems: finding a path in a network, winning at certain games, and so on.

Difficulty is often measured by the alternation of “there exists” and “for all”. NP is “there exists a solution”. A two-player game is “there exists a move for me such that, for every move of the opponent, there exists a move for me such that…”. The more alternations, the harder the problem, and games require as many alternations as there are moves.

Membership of these problems in their class is easy. Reachability is in $\mathsf{NL}$ (above). For quantified formulas, evaluate $\forall x\,\phi$ and $\exists x\,\phi$ recursively by trying $x=0$ then $x=1$ with the same space, whence space proportional to the size of the formula. Hardness is proved as in Savitch’s theorem: the formula $\mathrm{ACC}(u,v,i)$ is written with a single recursive call, thanks to a universal quantifier over the two halves of the journey, which gives a formula of polynomial size.

The next chapter studies other resources: randomness, approximation and quantum computing. Solvers for quantified Boolean formulas (QBF) exist, but remain far less efficient than SAT solvers: the gap between $\mathsf{NP}$ and $\mathsf{PSPACE}$, if it exists, already shows in practice.

What an exhaustive search costs

Trying all possibilities has a physical cost: thermodynamics imposes a minimal energy to erase information. And yet, software solves SAT problems with millions of variables every day: the difficulty of the worst case is not that of real cases.

A problem of $\mathsf{NP}$ can always be solved by exhaustive search: for a formula with $n$ variables, try the $2^n$ assignments. Theory says this is “exponential”; physics says what it costs. The two results that follow are physical laws, quoted and not proved here; the computations, however, are redone.

Proposition
Games and polynomial space

In the game of generalized geography, one is given a directed graph and a starting vertex; two players take turns moving a token along an arc to a vertex never visited, and the player who cannot move loses. Deciding whether the first player has a winning strategy is in $\mathsf{PSPACE}$; it is even PSPACE-complete (Schaefer, 1978, result quoted). Board games generalized to $n\times n$ whose games can be exponentially long leave $\mathsf{PSPACE}$: chess (Fraenkel and Lichtenstein, 1981) and go with the Japanese ko rule (Robson, 1983) are EXP-complete (results quoted).

In plain words. Deciding who wins a two-player game in which a token is moved from city to city without ever visiting the same place twice requires a reasonable memory, but, it seems, an enormous time.

To know whether I have a winning strategy, I must consider each of my moves, then each reply of the opponent, then each of my next moves, and so on. The tree of possible games is immense, but it can be explored branch by branch, erasing what has been fully examined: the memory stays small. It is the same kind of reasoning as for the levels of the arithmetical hierarchy, but with finitely many moves and games of limited length.

A game lasts at most as many moves as the graph has vertices, $m$. Evaluate the position recursively: the player to move wins if one of their moves leads to a losing position for the opponent. The recursion stack has depth at most $m$, and each level remembers the position (the current vertex and the set of visited vertices, $O(m)$ bits) and the move being tried: the space is $O(m^2)$, polynomial. The time, on the other hand, can be exponential, as for quantified formulas.

Proposition
Landauer’s principle and the price of an enumeration

Landauer’s principle (1961). Erasing one bit of information in a system in contact with an environment at temperature $T$ dissipates at least the energy $k_BT\ln2$, where $k_B=1.380\,649\times10^{-23}$ J/K is Boltzmann’s constant. (Physical law, verified experimentally by Bérut et al., 2012.)

At the temperature of the cosmic background, $T=2.725$ K, the lowest available without spending energy on cooling, this gives $2.61\times10^{-23}$ J per bit. An irreversible computation that runs through $2^n$ candidates erasing at least one bit per candidate therefore spends at least $2^n\times2.61\times10^{-23}$ J:

World energy consumption for one year (about $6\times10^{20}$ J)$6\times10^{20}$ J144
Total radiation of the Sun for one year$1.2\times10^{34}$ J188

Mass of the stars of the Milky Way (about $6\times10^{10}$ solar masses)$1.1\times10^{58}$ J267

Thus enumerating the $2^{200}$ words of 200 bits costs at least $4.2\times10^{37}$ J, about 3,500 years of the Sun’s entire radiation; enumerating the words of 256 bits takes more than the mass of the Sun; beyond about 310 bits, all the visible matter of the universe would not suffice.

Margolus-Levitin bound (1998). Even a reversible computation, which escapes Landauer’s principle, cannot go arbitrarily fast: a system of average energy $E$ passes through at most $4E/h$ distinct states per second ($h=6.626\times10^{-34}$ J·s, Planck’s constant). All the ordinary matter of the observable universe, during the 13.8 billion years of its history, would run through no more than $3.5\times10^{121}\approx2^{403}$ states.

In plain words. Erasing information costs a minimal amount of energy: it is a physical law. Trying one by one all the keys of a secret code of 256 binary digits would require more energy than the Sun will ever produce.

The difference between reasonable time and exponential time is therefore not a mathematician’s subtlety. Beyond a few hundred binary digits, an algorithm that tries all possibilities is not merely slow: it is physically impossible, whatever the technology. No progress in computers will change this: doubling computing power only makes it possible to try keys one binary digit longer.

The security of communications on the Internet rests on this observation. A 128-bit key is out of reach in practice for lack of time. A 256-bit key is protected by the laws of physics themselves.

The computations. $k_BT\ln2=1.380\,649\times10^{-23}\times2.725\times0.693\,1=2.608\times10^{-23}$ J. The maximal $n$ of each row is the integer part of $\log_2(E/2.608\times10^{-23})$. For example, for visible matter, $E=1.5\times10^{53}\times(2.998\times10^8)^2=1.35\times10^{70}$ J, and $\log_2(1.35\times10^{70}/2.608\times10^{-23})=308.0$. For $2^{200}$: $2^{200}=1.61\times10^{60}$, whence $4.19\times10^{37}$ J; the Sun radiates $3.83\times10^{26}$ W, that is, $1.21\times10^{34}$ J per year. For Margolus and Levitin: $4\times1.35\times10^{70}\times4.35\times10^{17}/6.626\times10^{-34}=3.5\times10^{121}$, and $\log_2$ of this number is $403.8$. Seth Lloyd (2002) obtained by a similar computation about $10^{120}$ operations for the computing capacity of the observable universe.

What these bounds assume. (1) Landauer’s principle concerns only erasure: Bennett (1973) showed that every computation can be made reversible, at the cost of extra space, and a reversible computation has no known minimal energy cost. This is why the second bound, which concerns the number of states and not erasure, is necessary. (2) These bounds apply to exhaustive search. They say nothing about a cleverer algorithm: if $\mathsf P=\mathsf{NP}$, a formula with 1,000 variables could be solved without running through the $2^{1000}$ assignments. (3) A quantum computer can, by Grover’s algorithm (1996), search among $2^n$ candidates in about $2^{n/2}$ steps, which amounts to halving $n$ in the table (result quoted).

Link with the theory. Linear speedup gains only constants, and the time hierarchy guarantees that there are decidable problems requiring exponential time: for them, no algorithm escapes the table above. For SAT, the question is open: it is exactly $\mathsf P$ versus $\mathsf{NP}$.

A binary counter going from $0$ to $2^n-1$ changes two bits per increment on average ($2^{n+1}-n-2$ changes in all); a current processor spends on the order of $10^{-10}$ J per instruction (a hundred watts for about $10^{12}$ instructions per second), several thousand billion times the Landauer bound. With one instruction per candidate, the barrier of annual world consumption is reached around $n=102$, not 144.

Proposition
SAT solvers: fast in practice, exponential in the worst case

Measurements made for this manual with the CaDiCaL 1.5 solver (on one core of a 2.1 GHz Xeon processor; program sat_experiences.py):

(Results quoted.) Every resolution refutation of the pigeonhole principle with $n+1$ pigeons and $n$ holes has size exponential in $n$ (Haken, 1985); random 3-SAT formulas are hardest around 4.26 clauses per variable (Selman, Mitchell and Levesque, 1996).

In plain words. SAT-solving software is astonishingly fast on real-life problems. But there are formulas, sometimes very simple ones, on which its computation time explodes.

The contrast with the previous paragraph is striking. Trying all possibilities for a formula with 200 variables is physically impossible, and yet a modern solver manages it in a quarter of a second. It does not try everything: it reasons, learns from its failures, and eliminates huge regions of possibilities at once. This is what makes it possible to use SAT every day, to verify processor circuits, plan deliveries or prove theorems.

But the difficulty does not disappear, it moves. A formula with 132 variables that says “12 pigeons cannot be put into 11 holes, one per hole” resists the solver, whereas a child settles it by counting. The solver cannot count, and it has been proved that its way of reasoning cannot establish this principle quickly. That every method has a weak spot of this kind is exactly the P ≠ NP conjecture.

What the solver does. Modern solvers (called CDCL, for conflict-driven clause learning) extend the search algorithm with unit propagation of the file complexite.py: when a partial assignment makes a clause false (a conflict), they derive by resolution a new clause, which forbids the cause of the conflict, and add it to the formula; they then backtrack several levels at once. When the formula is unsatisfiable, the sequence of learned clauses forms a resolution refutation, whose size is of the order of the number of conflicts. Haken’s theorem therefore bounds from below the number of conflicts on pigeonhole formulas: this is what is observed, with a factor of about 8 to 10 for each added pigeon (6,383, 37,288, 319,668, 2,657,952 conflicts).

Growth on random formulas. From 100 to 300 variables, the median time is multiplied by about 2,400, that is, $2^{11.2}$ for 200 more variables: a growth of the order of $2^{n/18}$ over this range. If it continued, a random formula with 1,000 variables at the threshold would take a few million years; this is an extrapolation, not a theorem.

Why queens are easy. The $n$-queens formula has an enormous number of solutions and a local structure that unit propagation exploits: each queen placed immediately eliminates hundreds of squares. Industrial formulas (circuit verification, planning) have similar structures, and solvers such as CaDiCaL or Kissat routinely handle ones with millions of variables (experimental result from the SAT competitions, quoted).

The program sat_experiences.py requires the Python package python-sat, which contains several solvers; python3 sat_experiences.py 1, 2 or 3 runs only one of the three experiments (the third takes about a minute). Times vary from one machine to another, but the ratios between rows are stable. For the pigeonhole principle, solvers equipped with stronger reasoning than resolution (counting, symmetries, “cutting planes”) settle it in polynomial time: a more powerful proof system moves the frontier, without removing it.

News: VP ≠ VNP, a proof produced by AIs (November 2026)

Section written on 26 November 2026, three days after the announcements. It describes a very recent result, which has not yet been reviewed by mathematicians. In this field, the situation is changing very quickly: each remark is therefore dated, and what is written here may be outdated within a few weeks.

The P = NP question has an “algebraic” cousin, posed by Leslie Valiant in 1979: one no longer computes with 0s and 1s, but with additions and multiplications of numbers. Two formulas look very much alike: the determinant of a table of numbers, which one learns to compute in the first year of university, and the permanent, which is written almost the same way, with + signs everywhere. The determinant is computed quickly; for the permanent, only very slow methods are known. Valiant conjectured that there is no fast method. On 23 November 2026, two artificial intelligence laboratories published, a few hours apart, a proof of this conjecture.

Definition
Arithmetic circuits, VP, VNP, permanent

Fix a field $\mathbb K$. An arithmetic circuit is a directed acyclic graph whose sources are labelled by variables $x_1,\dots,x_n$ or constants of $\mathbb K$, and whose other vertices are $+$ or $\times$ gates; it computes a polynomial. Its size is its number of vertices. A family of polynomials $(f_n)$ is p-bounded if the number of variables and the degree of $f_n$ are bounded by a polynomial in $n$.

  • $\mathsf{VP}$ is the class of p-bounded families computed by circuits of size polynomial in $n$.
  • $\mathsf{VNP}$ is the class of families $f_n(\vec x)=\sum_{\vec e\in\{0,1\}^{m(n)}}g_n(\vec x,\vec e)$, where $(g_n)$ is in $\mathsf{VP}$ and $m(n)$ is polynomial: an exponential sum of values of an easy polynomial, the algebraic analogue of “there exists a witness”.
  • The determinant and the permanent of an $m\times m$ matrix of variables $X=(x_{ij})$ are $$\det X=\sum_{\sigma\in\mathfrak S_m}\varepsilon(\sigma)\prod_{i=1}^m x_{i\sigma(i)},\qquad \operatorname{per}X=\sum_{\sigma\in\mathfrak S_m}\prod_{i=1}^m x_{i\sigma(i)}.$$

The determinant is in $\mathsf{VP}$ (by division-free algorithms, such as Berkowitz’s, 1984). Valiant (1979) showed that, if the characteristic of $\mathbb K$ is not $2$, the permanent is $\mathsf{VNP}$-complete under projections: every family of $\mathsf{VNP}$ is obtained from the permanent of a matrix of polynomial size by replacing its entries with variables or constants. He conjectured that $\mathsf{VP}\ne\mathsf{VNP}$, that is, that the permanent has no circuits of polynomial size. (Classical definitions and results, quoted for information.)

In plain words. The difficulty of an algebraic formula is measured by the minimal number of additions and multiplications needed to compute it. VP gathers the formulas that can be computed with a reasonable number of operations; VNP those that can be written as a sum of a gigantic number of easy terms. The permanent is the hardest formula of VNP.

The determinant and the permanent are sums of products, one for each way of choosing one number per row and per column in the table; for a table of 20 rows, there are more than two billion billion terms. The determinant gives half of the terms a minus sign, and these signs allow great simplifications: Gaussian elimination, learned in secondary school to solve systems of equations, computes it in a few thousand operations. The permanent has no minus signs, and all known tricks fail. Counting certain configurations in physics, or counting the ways of forming couples in a group, amounts to computing a permanent.

Announced result
VP ≠ VNP (proofs published by Anthropic and OpenAI on 23 November 2026, not yet reviewed)

Announced statement. Over every field of characteristic other than $2$, the $m\times m$ permanent has no arithmetic circuit of polynomial size; more precisely, it requires circuits of size $2^{\Omega((\log m)^{4/3})}$ (Anthropic’s proof). In particular $\mathsf{VP}\ne\mathsf{VNP}$.

Status as of 26 November 2026. Announced result, accompanied by formal proofs in Lean, but reviewed by no mathematician; no journal publication. To be read with this status in mind: it is not yet a theorem accepted by the community.

In plain words. Two artificial intelligences, one from Anthropic and the other from OpenAI, have each produced a proof that the permanent cannot be computed with a reasonable number of operations. The proofs are written in a language that the computer checks, but no human has yet read them in full.

What happened (23 and 24 November 2026). On 23 November, Anthropic posted on its public code page a paper, a formal proof and a note stating that the result “was discovered by an internal research Claude model”, that the paper and the formal proof were written by AIs, and that “no human mathematician has verified the proof”. A few hours later, OpenAI posted in turn a paper entitled “VP and VNP are different”, with a slightly weaker bound, stating that it had obtained the result as early as 6 November. On 24 November, the specialist Lance Fortnow spoke of the “most important complexity result of the year”, and Scott Aaronson judged that the formal proofs exceed the usual standard of rigour of a journal.

Why one may believe it, and why caution is needed (26 November 2026). The formal proof was checked by Lean, proof-checking software of the kind described in the chapter Logic and types. This is the ideal situation described in the chapter Computability and AI: the machine that searches need not be believed, only the checker counts. But the checker only verifies that the proof proves the statement as written in Lean. Humans must still make sure that this formal statement says what we think it says, and Anthropic’s note itself warns that nothing checks this point automatically. This is exactly the limit of specification.

What it does not say. The result does not settle the P = NP question. Arithmetic circuits are allowed only addition and multiplication; an ordinary computer can do many other things (compare, test, fetch a specific digit), and nothing prevents it a priori from computing the permanent faster. Fortnow concludes that P versus NP “remains out of reach, for human and machine alike”.

The two proofs (according to the repositories and the reports of 24 November 2026). Anthropic’s bound is $2^{\Omega((\log m)^{4/3})}$ for the permanent in characteristic other than $2$ (in characteristic $2$, where the permanent coincides with the determinant, the statement concerns the Hamiltonian cycle polynomial); that of OpenAI’s paper of 23 November is $2^{\Omega((\log m)^{5/4})}$, and a second OpenAI manuscript, posted on 24 November, announces stronger bounds. These bounds are more than polynomial but less than exponential: the best known upper bound remains of the order of $2^m$ (Ryser’s formula). According to Fortnow, Anthropic’s proof uses a variant of Strassen’s asymptotic spectrum and distinguishes two cases, one handled by a rank argument, the other by diagonalization; it uses practically no algebraic geometry, and its link with the geometric complexity theory (GCT) programme is not clear. Aaronson notes that the techniques of the two proofs seem close.

Verification. Anthropic’s repository contains a statement file that uses only the Mathlib library, the proof, and a script that has everything rechecked by a second, independent kernel; only Lean’s three standard axioms should appear. An appendix of the paper matches each statement of the text with its Lean statement. OpenAI presents its manuscripts as “raw research data” rather than finished papers. As of 26 November 2026, no independent line-by-line verification has been published.

Boolean consequence. As Fortnow recalls, the Boolean analogue of $\mathsf{VP}\ne\mathsf{VNP}$ would be that the functions of $\#\mathsf P$ do not have Boolean circuits of polynomial size and depth $O(\log^2 n)$, which is weaker than $\mathsf{NP}\not\subseteq\mathsf P/\mathrm{poly}$; and the algebraic result does not even imply this analogue, since arithmetic circuits have no access to Boolean operations.

Remark
Why these remarks are dated

The remarks of this section are dated because they describe a state of knowledge that changes from week to week: independent verifications, possible corrections, new bounds, publication in a journal. They will be updated as the community makes up its mind.

In plain words. A mathematical proof becomes an accepted theorem only after it has been read and checked by others. For this result, this work is just beginning: that is why each remark bears its date.

The episode also illustrates something new. Until now, computer verification came after human discovery, to confirm it. Here, both the discovery and the formal proof come from a machine, and it is human reading that comes last. The theorems of this manual guarantee that checking a formal proof is mechanical and safe; they say nothing about the question “is what the machine proved really what we wanted to know?”, which remains a human matter.

★Exercise 1 — Clique and independent set

A clique of a graph is a set of pairwise adjacent vertices, an independent set a set of pairwise non-adjacent vertices. Show that CLIQUE $=\{(G,k):G$ has a clique of size $k\}$ reduces polynomially to INDEPENDENT $=\{(G,k):G$ has an independent set of size $k\}$, and conversely.

Solution

Let $\overline G$ be the complement graph (same vertices, an edge between $u\ne v$ if and only if there is none in $G$). A set is a clique of $G$ if and only if it is independent in $\overline G$. The function $(G,k)\mapsto(\overline G,k)$ is computed in time $O(n^2)$ on the adjacency matrix, and realizes both reductions. Both problems are in NP (a certificate is the set of vertices); they are NP-complete (classical result of Karp, 1972, quoted here for information).

★Exercise 2 — The price of a key, at Landauer’s rate

At room temperature ($T=300$ K), what is the minimal energy, according to Landauer’s principle, to run through the $2^{64}$, $2^{128}$ and $2^{256}$ keys of a cipher, erasing one bit per key tried? Compare with annual world consumption (about $6\times10^{20}$ J) and with the mass-energy of the Sun (about $1.8\times10^{47}$ J).

Solution

$k_BT\ln2=1.380\,649\times10^{-23}\times300\times0.693\approx2.87\times10^{-21}$ J per bit. For $2^{64}\approx1.8\times10^{19}$ keys: about $0.053$ J, a trifle. For $2^{128}\approx3.4\times10^{38}$: about $9.8\times10^{17}$ J, one six-hundredth of a year’s world consumption, at perfect thermodynamic efficiency, which is very far from being reached (current processors dissipate billions of times more per operation). For $2^{256}$: about $3.3\times10^{56}$ J, about two billion times the mass-energy of the Sun. Doubling the length of a key does not double the effort: it squares it.

★★Exercise 3 — From SAT to 3-SAT

Show that SAT (in conjunctive normal form) reduces polynomially to 3-SAT, where each clause has at most three literals.

Solution

Replace each clause $C=(\ell_1\vee\cdots\vee\ell_k)$ with $k\ge4$ by the $k-2$ clauses

$$(\ell_1\vee\ell_2\vee z_1)\wedge(\neg z_1\vee\ell_3\vee z_2)\wedge\cdots\wedge(\neg z_{k-4}\vee\ell_{k-2}\vee z_{k-3})\wedge(\neg z_{k-3}\vee\ell_{k-1}\vee\ell_k),$$

with new variables $z_1,\dots,z_{k-3}$ specific to $C$. If an assignment satisfies $C$, say through $\ell_j$, set $z_i$ true for the clauses before the one containing $\ell_j$ and false after: all the new clauses are satisfied. Conversely, if the new clauses are satisfied but no $\ell_j$ is true, the first forces $z_1$, the second $z_2$, …, and the last $\neg z_{k-3}$: contradiction. The resulting formula is therefore satisfiable if and only if the original is, and its size is linear. With the Cook-Levin theorem, 3-SAT is NP-complete. (2-SAT, on the other hand, is in P.)

★★Exercise 4 — If P = NP

Show that if $\mathsf P=\mathsf{NP}$, then $\mathsf{NP}=\mathrm{co}\mathsf{NP}$.

Solution

$\mathsf P$ is closed under complement: swap the accepting and rejecting states of a deterministic machine that always halts in polynomial time. So $\mathrm{co}\mathsf P=\mathsf P$. If $\mathsf P=\mathsf{NP}$, then $\mathrm{co}\mathsf{NP}=\mathrm{co}\mathsf P=\mathsf P=\mathsf{NP}$. The swapping argument does not work for a nondeterministic machine: “there is a computation that rejects” is not the negation of “there is a computation that accepts”.

★★★Exercise 5 — An NP-complete problem in coNP

Show that if an NP-complete problem $L$ belongs to $\mathrm{co}\mathsf{NP}$, then $\mathsf{NP}=\mathrm{co}\mathsf{NP}$.

Solution

First, $\mathsf{NP}$ is closed under polynomial reduction: if $A\le_pB$ via $f$ and $B\in\mathsf{NP}$, a machine for $A$ computes $f(x)$ (in polynomial time, so $|f(x)|$ is polynomial in $|x|$) then runs the machine for $B$. Since $x\in\overline A\iff f(x)\in\overline B$, $\mathrm{co}\mathsf{NP}$ is also closed under reduction.

Let $A\in\mathsf{NP}$. Since $L$ is NP-complete, $A\le_pL$, and $L\in\mathrm{co}\mathsf{NP}$ gives $A\in\mathrm{co}\mathsf{NP}$: $\mathsf{NP}\subseteq\mathrm{co}\mathsf{NP}$. Conversely, if $B\in\mathrm{co}\mathsf{NP}$, then $\overline B\in\mathsf{NP}\subseteq\mathrm{co}\mathsf{NP}$, so $B\in\mathsf{NP}$. This is why no problem is known that is both NP-complete and in $\mathrm{co}\mathsf{NP}$: finding one would be a breakthrough. Factoring is in $\mathsf{NP}\cap\mathrm{co}\mathsf{NP}$, and this is an argument (unproved) for believing that it is not NP-complete.
