Gödel’s theorem might lead one to believe that every mathematical theory is undecidable. It is not so. If we give up multiplication, all questions about the integers that speak only of addition and comparison can be settled by a machine (Presburger, 1929). More surprisingly, all questions of elementary geometry, and more generally about the real numbers with addition and multiplication, can be too (Tarski, 1948).

What tips a theory over into the undecidable is not its apparent difficulty, but its ability to describe a computation. The real numbers are “too smooth” to code a Turing machine; the integers with multiplication are not.

The incompleteness theorem and the decision problem give the impression that logic is undecidable as soon as it becomes interesting. This is not so. Rich mathematical theories are decidable: a machine can settle any of their statements. This chapter presents the most important ones, with two methods of proof (quantifier elimination and automata), then the dividing line between decidable and undecidable theories.

Theories and methods

A theory is the set of sentences that are true in a structure (the integers, the reals…). It is decidable if a machine can say, for each sentence, whether it is true. The main method consists in eliminating the “there exists” and “for all” of each sentence, replacing it with a simpler equivalent sentence that is checked directly.

Fix a first-order language (constant, function and relation symbols). The theory of a structure $\mathcal M$ is the set $\mathrm{Th}(\mathcal M)$ of sentences true in $\mathcal M$. More generally, the theory generated by a set of axioms $\Gamma$ is the set of sentences provable from $\Gamma$, that is (by completeness) true in all models of $\Gamma$. A theory is decidable if the set of codes of its sentences is decidable, complete if it contains, for every sentence $\phi$, $\phi$ or $\neg\phi$.

Notation: $\mathrm{Th}(\N,+,\times)$ is true arithmetic, $\mathrm{Th}(\N,+)$ (with $0$, $1$ and $<$) is Presburger arithmetic, $\mathrm{Th}(\R,+,\times)$ (with $0$, $1$ and $<$) is the theory of the real numbers.

In plain words. The theory of a mathematical domain (the integers, the reals, the lines of the plane) is the set of all true sentences about it. It is decidable if a program can tell, of any sentence, whether it is true or false.

A decidable theory is a mechanical oracle for truth: one asks the question, the machine answers, without genius or intuition. For the integers with addition and multiplication, the incompleteness theorem says that this oracle does not exist. This chapter shows that it does exist for important domains, and looks for what makes the difference.

$\mathrm{Th}(\N,+,\times)$ is not decidable; it is not even semi-decidable.

In plain words. No program can tell, of every sentence about the whole numbers written with addition and multiplication, whether it is true. No program can even write the list of all true sentences.

With addition and multiplication, the sentence “such a program halts” can be written as a statement about numbers. An oracle for truth about the integers would therefore solve the halting problem, which is impossible.

By the MRDP theorem, there is a polynomial $P$ such that $e\in K\iff\exists\vec y\ P(e,\vec y)=0$. The sentence $\exists\vec y\ (P^+(\underline e,\vec y)=P^-(\underline e,\vec y))$, where $P^+$ and $P^-$ collect the monomials with positive and negative coefficients, is computed from $e$ and is true in $\N$ if and only if $e\in K$. A decision procedure for $\mathrm{Th}(\N,+,\times)$ would therefore decide $K$. Likewise for the complement of $K$, with the negation of this sentence: $\mathrm{Th}(\N,+,\times)$ is not semi-decidable, since $\overline K$ is not.

A theory $\mathsf T$ eliminates quantifiers if every formula is equivalent, in $\mathsf T$, to a quantifier-free formula with the same free variables. If this formula is computed from the first one, and if the quantifier-free sentences of $\mathsf T$ can be decided, then $\mathsf T$ is decidable. To eliminate quantifiers, it suffices to eliminate $\exists x$ in front of a conjunction of atomic formulas and negations of atomic formulas.

In plain words. If every sentence can be replaced by an equivalent sentence with no “there exists” and no “for all”, the theory becomes decidable: all that remains is a simple check, a computation.

This is the method used in secondary school to solve a system: the unknowns are eliminated one by one. “There is a number x such that a × x + b = 0” is replaced by a condition that speaks only of a and b (“a is not zero, or else a and b are both zero”). If the variable can always be made to disappear, every question comes down to a computation on known numbers.

Quantifiers are eliminated from the inside out, replacing $\forall x$ by $\neg\exists x\neg$. In front of a quantifier-free formula, put it in disjunctive normal form $\bigvee_i C_i$ (each $C_i$ a conjunction of literals), use $\exists x\bigvee_iC_i\equiv\bigvee_i\exists x\,C_i$, and eliminate $\exists x$ in front of each $C_i$, first pulling out the literals in which $x$ does not occur. For a sentence, one obtains a quantifier-free, hence variable-free, sentence, which is decided by hypothesis.

The theory $\mathsf{DLO}$ of dense total orders with neither least nor greatest element eliminates quantifiers; it is complete and decidable. In particular, $(\mathbb Q,<)$ and $(\R,<)$ satisfy the same sentences.

In plain words. The questions about the order of fractions (“between two fractions, there is always another”, “there is no largest fraction”) can all be decided by a program.

The lesson is surprising. The logic that speaks of a relation between two objects is undecidable in general. But if this relation is required to be a “dense” order like that of the fractions, everything becomes decidable again. Such an order is too regular, too similar to itself everywhere, for a computation to be drawn in it. What matters is not the language, but what the domain allows one to describe.

Presburger arithmetic

Without multiplication, the integers become surprisingly docile: every question that speaks only of addition, comparison and divisibility by fixed numbers can be settled by an algorithm.

The theory $\mathrm{Th}(\N,0,1,+,<)$ is decidable.

In plain words. Every sentence about the whole numbers that uses only addition and comparison can be declared true or false by a program.

With addition, a lot can already be said: “every number is even or odd”, “every amount of at least 8 euros can be paid with coins of 3 and 5 euros”. But two unknowns cannot be multiplied together. Now it is multiplication that makes it possible to store a whole list of numbers in a single number, and hence to write a computation. Without it, arithmetic can no longer speak about itself, and it becomes decidable.

The proof given here is due to Büchi (1960). A number is written in binary, and addition proceeds from right to left with a carry, as at school. A very simple machine, which needs to remember only the carry, can check an addition: it is a finite automaton.

Encoding. An $n$-tuple $(x_1,\dots,x_n)$ is written as a word over the alphabet $\{0,1\}^n$: the $k$-th letter consists of the $k$-th bits of the $x_i$, least significant bits first. An $n$-tuple has infinitely many encodings, which differ by zero letters $(0,\dots,0)$ appended at the end. One shows, by induction on $\phi(x_1,\dots,x_n)$, that there is a deterministic finite automaton $\mathcal A_\phi$ accepting exactly the encodings of the $n$-tuples satisfying $\phi$ (all of them or none, for each $n$-tuple), and that it is computed from $\phi$.

Connectives. For $\neg\phi$, swap accepting and non-accepting states; for $\phi\wedge\psi$ and $\phi\vee\psi$, take the product automaton (after putting the two automata on the same variables, an extra track being ignored). The property “all encodings or none” is preserved.

Quantifier. For $\exists x_n\,\phi$, erase the track of $x_n$: one obtains a nondeterministic automaton that guesses the bits of $x_n$, which is then determinized. One difficulty: the witness $x_n$ may have more bits than $x_1,\dots,x_{n-1}$. So every state from which a sequence of zero letters leads to an accepting state is declared accepting. The resulting automaton accepts an encoding of $(x_1,\dots,x_{n-1})$ if and only if there is $x_n$ such that $\phi(x_1,\dots,x_n)$, and it then accepts all its encodings.

Conclusion. For a sentence ($n=0$), the alphabet has a single letter, the empty $0$-tuple, and the sentence is true if and only if the initial state of $\mathcal A_\phi$ is accepting.

The program presburger.py carries out this proof in fewer than 170 lines. It first checks its automata against a direct computation, then decides the sentences: “every integer is even or odd” (true), “every $n\ge8$ can be written $3a+5b$” (true), the same for $n\ge7$ (false, because of $7$), “there is $x$ with $2x=5$” (false). The procedure is very costly in the worst case: each alternation of quantifiers can make the number of states explode. Result quoted for information: this is unavoidable, since every decision procedure for Presburger arithmetic requires, for some sentences of length $n$, at least $2^{2^{cn}}$ steps (Fischer and Rabin, 1974). It is nevertheless used every day: SMT solvers (such as Z3) decide the formulas of linear integer arithmetic that arise in program verification and compilation (array indices, loop bounds).

There is no formula $\mu(x,y,z)$ of the language $\{0,1,+,<\}$ such that, for all $x,y,z\in\N$, $(\N,+)\models\mu(x,y,z)\iff z=xy$.

In plain words. With addition alone, multiplication cannot be defined. Otherwise, the theory of addition would be as undecidable as that of multiplication, which is not the case.

We are of course used to seeing multiplication as repeated addition: 3 × 4 = 4 + 4 + 4. But “repeat x times” is not a sentence that can be written with addition alone when x is an unknown. Decidability serves here as a measuring instrument: it proves that a language is too poor to express a notion.

If such a formula existed, every sentence of the language $\{0,1,+,\times,<\}$ could be translated into a sentence of the language $\{0,1,+,<\}$ true in $\N$ if and only if the first one is: replace each product by a new variable, existentially quantified and constrained by $\mu$ (for example $P(s\times t)$ becomes $\exists z\,(\mu(s,t,z)\wedge P(z))$, starting with the innermost products). One would decide $\mathrm{Th}(\N,+,\times)$, which is impossible. Result quoted for information: the sets of integers definable in $(\N,+)$ are exactly the eventually periodic sets (Ginsburg and Spanier, 1966, for the multivariable version: the semilinear sets), which shows directly that the set of squares is not definable.

The real numbers and geometry

For the real numbers, Tarski showed that every question formulated with addition, multiplication and comparison can be decided. All of Descartes’s geometry, which translates into equations over the reals, is therefore decidable in principle.

The theory $\mathrm{Th}(\R,0,1,+,\times,<)$ eliminates quantifiers and is decidable. (Result quoted for information, the general proof being long; a case and a consequence are proved below.)

In plain words. Every sentence about the real numbers written with addition, multiplication and comparison can be declared true or false by a program. School geometry (points, lines, circles) is therefore decidable too.

The contrast is striking. Over the whole numbers, addition and multiplication make the theory undecidable. Over the real numbers, with exactly the same operations, everything is settled by a computation. Elementary geometry benefits, since it can be translated into coordinates: every statement about triangles and circles is decided mechanically. This was Tarski’s dream.

The reason is that the reals are too “continuous” for the integers to be told apart in them: with addition, multiplication and comparison, one cannot write “x is a whole number”. Without the integers, no computations. It is enough to add the sine function, which vanishes exactly at the multiples of π, for the integers to reappear and for everything to become undecidable again.

An example of elimination. For all reals $a,b,c$:

$$\exists x\ (ax^2+bx+c=0)\iff(a\ne0\wedge b^2-4ac\ge0)\vee(a=0\wedge b\ne0)\vee(a=0\wedge b=0\wedge c=0).$$

If $a\ne0$, this is the solution of quadratic equations; if $a=0$ and $b\ne0$, $x=-c/b$ works; if $a=b=0$, the equation is $c=0$. The right-hand side no longer contains $x$. The general method (Tarski) extends this computation to any system of polynomial equations and inequalities, thanks to generalizations of Sturm’s theorem, which count the real roots of a polynomial in an interval.

Consequence: $\N$ is not definable in $\R$. A quantifier-free formula with one free variable $x$ (and no parameter) is a Boolean combination of conditions $p(x)=0$ and $p(x)>0$, with $p$ a polynomial. Each one defines a finite union of points and intervals (a nonzero polynomial has finitely many roots, between which it keeps a constant sign), and these finite unions are closed under Boolean operations. By quantifier elimination, every definable subset of $\R$ is therefore a finite union of points and intervals. $\N$ is not: it is infinite and contains no interval other than single points.

Results quoted for information. The best general methods (cylindrical algebraic decomposition, Collins, 1975) have a cost doubly exponential in the number of variables, and it is known that quantifier elimination cannot do much better (Davenport and Heintz, 1988). They are implemented in computer algebra systems (Mathematica, QEPCAD, Redlog) and are used in robotics (motion planning) and in the verification of hybrid systems. Open question: is the theory of the reals with, in addition, the exponential function decidable? Macintyre and Wilkie (1996) proved that it is, if a conjecture of number theory (Schanuel’s conjecture) is true.

The table that follows gathers the known theories, decidable or not. The border runs where a theory becomes able to code a computation.

In plain words. The table arranges the known theories in two columns, decidable and undecidable. A theory becomes undecidable as soon as it can describe the working of a machine.

In the right-hand column, each time, a computation can be written: either by recovering the integers with addition and multiplication, or by drawing a grid in which each cell depends on its neighbours. In the left-hand column, the domains are too poor (the integers without multiplication) or too regular (the reals) for that.

The border therefore does not separate fields of mathematics, such as algebra and geometry. It separates powers of expression: as soon as a theory can describe what a computer does, no computer can decide it any more.

Multiplication by a constant is repeated addition: it is allowed. It is the multiplication of two variables that is out of reach.

Following the proof of Presburger’s theorem (least significant bits first), build the automaton recognizing the pairs $(x,y)$ such that $x=2y$. How many states does it have? Also describe it directly.

The atom is $x-2y=0$: $a=(1,-2)$, $c=0$. From state $q$, the letter $(b_x,b_y)$ gives $s=q-b_x+2b_y$, and one moves to $s/2$ if $s$ is even, to the sink otherwise. From $0$: $(0,0)\mapsto0$, $(0,1)\mapsto1$, $(1,\cdot)\mapsto$ sink. From $1$: $(1,0)\mapsto0$, $(1,1)\mapsto1$, $(0,\cdot)\mapsto$ sink. The accepting state is $0$. Three states: $0$, $1$ and the sink.

Direct reading: multiplying by 2 means shifting the bits by one position. The state remembers the bit of $y$ read at the previous step (initially $0$), and the bit of $x$ must equal it. At the end, the last bit of $y$ must have been copied: accept if the state is $0$. The program presburger.py builds the same automaton with automate(('eq', {'x': 1, 'y': -2}, 0)).

Show that every integer $n\ge8$ can be written $3a+5b$ with $a,b\in\N$, and that $7$ cannot. More generally, for coprime $p,q$, the statement “every $n\ge s$ can be written $pa+qb$” is a Presburger sentence: what can be deduced about computing the least value of $s$ that works?

$8=3+5$, $9=3\cdot3$, $10=5\cdot2$, and if $n$ can be written so, so can $n+3$: every $n\ge8$ can be written. $7$ cannot: $b=0$ gives $7=3a$, $b=1$ gives $2=3a$, both impossible. For given $p,q$ and $s$, the sentence is decided by the Presburger procedure; the least $s$ is found by trying $s=0,1,2,\dots$, which terminates since such an $s$ exists (it is in fact known to be $pq-p-q+1$, a result of Sylvester, 1884; here $15-3-5+1=8$). The program presburger.py confirms both statements for $3$ and $5$.

Show that $\mathrm{Th}(\mathbb Z,0,1,+,\times)$ is undecidable. You may assume Lagrange’s theorem: every natural number is a sum of four squares.

By Lagrange, $\N$ is definable in $\mathbb Z$ by $\nu(x)=\exists a\,\exists b\,\exists c\,\exists d\ (x=a\times a+b\times b+c\times c+d\times d)$. To every sentence $\phi$ of arithmetic associate the sentence $\phi^\nu$ obtained by relativizing the quantifiers: $\exists x\,\psi$ becomes $\exists x\,(\nu(x)\wedge\psi^\nu)$, $\forall x\,\psi$ becomes $\forall x\,(\nu(x)\Rightarrow\psi^\nu)$. By induction on $\phi$, $\phi$ is true in $\N$ if and only if $\phi^\nu$ is true in $\mathbb Z$ (the operations of $\mathbb Z$ extend those of $\N$, and $0,1\in\N$). The translation is computable, so a decision procedure for $\mathrm{Th}(\mathbb Z,+,\times)$ would yield one for $\mathrm{Th}(\N,+,\times)$, which does not exist (theorem). For $\R$, this method fails: $\N$ is not definable there (Tarski’s theorem). For $\mathbb Q$, it succeeds, but the definition of $\mathbb Z$ in $\mathbb Q$ (Julia Robinson) is much harder.
