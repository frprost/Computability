A very simple machine

To model what a human computer does, Alan Turing proposed a very simple mathematical model in 1936. There are many variants of it, all equivalent as regards what they compute; we follow Martin Davis’s presentation with quadruples (Computability and Unsolvability, 1958). A machine consists of three elements:

  1. a tape, infinite in both directions, divided into cells, each cell carrying a symbol; the cells are blank (symbol $B$) except for finitely many of them;
  2. a read-write head, placed on a cell, and an internal state, taken from a finite set;
  3. a program: a finite list of instructions, the quadruples.

An instruction $q_i, S_j, \dots$ applies when the machine is in state $q_i$ and reads the symbol $S_j$. It is of one of two types: write a symbol in place of the one read, or move one cell to the left ($L$) or to the right ($R$); in both cases it gives the new state. The machine performs steps as long as an instruction applies; it halts as soon as none applies. For the computation to be deterministic, there must be only one instruction per (state, symbol) pair.

The machine of the figure, started on the tape 1 1 1, erases the bar it reads, moves right, starts again… and halts when it reads a blank in state $q$ (no instruction begins with $q, B$). It therefore erases a block of bars. Try it:

Formal definition

We fix two disjoint countably infinite sets: the states $Q=\{q_0,q_1,\dots\}$ and the symbols $S=\{S_0,S_1,\dots\}$, as well as two marks $L,R\notin Q\cup S$. We write $B=S_0$ (the blank) and $1=S_1$ (the bar, sometimes written $|$).

A Turing machine $Z$ is a nonempty finite set $P_Z$ of quadruples of one of the three forms

$$ q_i\,S_j\,S_k\,q_l \qquad q_i\,S_j\,R\,q_l \qquad q_i\,S_j\,L\,q_l $$

which is consistent: two distinct quadruples of $P_Z$ never begin with the same pair $q_i\,S_j$.

Everything is finite: the alphabet actually used, the states, the program. Only the tape is unlimited, but at each moment it carries only finitely many non-blank symbols: this is the “unbounded finiteness” of the motivations. Consistency is the mathematical form of determinism: each situation corresponds to at most one action.

We write $E_Z\subset Q$ and $S_Z\subset S$ for the (finite) sets of states and symbols that appear in $P_Z$. Fixing “canonical” sets $Q$ and $S$ in advance makes it possible to say that the set of all machines is countable, and to code them by integers (chapter Equivalence).

In the simulator, a program is written one quadruple per line, for example q0 1 B q1; symbols are arbitrary words (B, 1, X…), and L, R are reserved for moves. The simulator rejects an inconsistent program.

An instantaneous description is a word $\alpha=\gamma\,q_i\,S_j\,\delta$ with $\gamma,\delta\in S^*$: the tape carries $\gamma S_j\delta$ (and blanks elsewhere), the machine is in state $q_i$ and the head reads $S_j$. We say that $\alpha$ yields $\beta$ by $Z$, written $\alpha\vdash_Z\beta$, in the following cases:

  1. $q_i\,S_j\,S_k\,q_l\in P_Z$ and $\beta=\gamma\,q_l\,S_k\,\delta$;
  2. $q_i\,S_j\,R\,q_l\in P_Z$ and $\beta=\gamma S_j\,q_l\,S_k\,\delta'$ if $\delta=S_k\delta'$, or $\beta=\gamma S_j\,q_l\,B$ if $\delta$ is empty;
  3. $q_i\,S_j\,L\,q_l\in P_Z$ and $\beta=\gamma'\,q_l\,S_k\,S_j\delta$ if $\gamma=\gamma' S_k$, or $\beta=q_l\,B\,S_j\delta$ if $\gamma$ is empty.

$\alpha$ is terminal if no quadruple of $P_Z$ begins with $q_i\,S_j$. A computation is a finite sequence $\alpha_1\vdash_Z\alpha_2\vdash_Z\dots\vdash_Z\alpha_p$ where $\alpha_p$ is terminal; we write $\alpha_p=\mathrm{Res}_Z(\alpha_1)$, the resultant. If no computation starts from $\alpha_1$, $\mathrm{Res}_Z(\alpha_1)$ is undefined.

An instantaneous description is a complete snapshot of the machine: nothing else influences what follows. The computation is a film, frame by frame, and the rule that passes from one frame to the next is purely local: it looks only at the state and the cell read.

Descriptions that differ only by blanks added at the ends describe the same situation, just as $3$, $3.0$ and $3.00$ denote the same number; we reason on the minimal description. Since $P_Z$ is consistent, a description has at most one successor: the relation $\vdash_Z$ is functional, and $\mathrm{Res}_Z$ is a partial function.

The simulator displays the successive instantaneous descriptions in the form 1 1 [q3] B 1, the state being written just before the symbol read. This is exactly the word $\gamma\,q_i\,S_j\,\delta$ of the definition.

Computed functions

The integer $x$ is represented by the word $\overline{x}=1^{x+1}$ ($x+1$ bars). An $n$-tuple $(x_1,\dots,x_n)$ is represented by $\overline{x_1}\,B\,\overline{x_2}\,B\cdots B\,\overline{x_n}$. For a word $\alpha$, we write $\langle\alpha\rangle$ for the number of bars it contains.

We put $x+1$ bars rather than $x$ to distinguish the argument $0$ from the absence of an argument: the tape for $(0,0)$ is 1 B 1, that for $()$ is entirely blank. On output, on the contrary, bars are counted without offset: $\langle\alpha\rangle=y$ codes $y$. This asymmetry, inherited from Davis, simplifies the successor machine (see below); other conventions are possible and give the same class of functions.

With every machine $Z$ and every integer $n$ we associate the partial function $\Psi^{(n)}_Z:\N^n\to\N$:

$$\Psi^{(n)}_Z(x_1,\dots,x_n)\simeq\big\langle \mathrm{Res}_Z\big(q_0\,\overline{x_1}B\cdots B\overline{x_n}\big)\big\rangle,$$

undefined when the resultant is. A function $f:\N^n\to\N$ is Turing-computable if there is $Z$ such that $f=\Psi^{(n)}_Z$. We write $\mathcal T$ for this class.

The machine starts in state $q_0$, with the head on the first bar of the input. If it never halts, the function has no value at that point: non-termination is the only way for a machine to “not answer”. Every halt, on the contrary, produces an answer.

The same machine computes one function for each arity $n$. The same function is computed by infinitely many machines (one can always add useless instructions, for example involving a state that is never reached).

The examples of the next section are all executable. The result displayed is $\langle\alpha\rangle$, the total number of bars when the machine halts, as in the definition.

Example programs

The machine $P=\{\,q_0\,B\,B\,q_0\,\}$ computes $x\mapsto x+1$.

On the input $\overline{x}$, the head reads a bar in state $q_0$; no quadruple begins with $q_0\,1$, the machine halts immediately, and the tape carries $x+1$ bars. (The quadruple $q_0BBq_0$ serves only to make $P$ nonempty; it is never executed.)

A library common to the three models

The same twelve functions are defined in the three models of this manual (see also the chapters Recursive functions and λ-calculus). The simplest are computed by hand-written machines, whose correctness is proved by an invariant: a description of the tape and the state, true at the beginning of each round of the loop. For power, factorial and quotient, we use the machine produced by the compiler from the recursive definition: this is the most direct link between the two models. All the machines have been tested by simulation, the output being compared with the specification (inputs up to 5 or 7 depending on the case).

Functions, sets, predicates, languages

Computability can be presented through functions (from $\N^n$ to $\N$), through sets (a set $A\subseteq\N$ is decidable if its characteristic function $\chi_A$ is Turing-computable), through predicates (a property $p$ of integers is decidable if the function equal to $1$ when $p(x)$ holds and $0$ otherwise is computable) or through languages (a language $L\subseteq\Sigma^*$ is decidable if a machine reading a word $w$ answers in finite time whether $w\in L$). These four presentations are equivalent, in the sense that each translates into the others through computable codings.

“Computing a function”, “recognizing a property”, “sorting correct words from incorrect ones”: three apparently different jobs (the accountant, the judge, the spell-checker) which are in fact the same. The key is that several numbers can always be coded by one, and a word by a number: asking a yes/no question about finite objects amounts to computing a function with values in $\{0,1\}$, and conversely computing $f$ amounts to answering the questions “is $f(x)$ equal to $y$?”.

Coding pairs. Cantor’s bijection $\langle x,y\rangle=\tfrac12\big((x+y)^2+3x+y\big)$ and its inverses $\pi_1,\pi_2$ are primitive recursive; iterating it, every $n$-tuple is coded by an integer. Sets and predicates are therefore the same thing (a predicate is the characteristic function of the set of $x$ that satisfy it), and a set of $n$-tuples reduces to a set of integers.

Coding words. If $\Sigma=\{a_1,\dots,a_k\}$, code the word $w=a_{l_1}\cdots a_{l_n}$ by $\mathrm{code}(w)=\prod_{i=1}^n p_i^{\,p_{l_i}}$, where $p_j$ is the $j$-th prime. Uniqueness of prime factorization makes this coding injective and decodable in a primitive recursive way (this is the method of Gödel numbering). Then $w\in L\iff\mathrm{code}(w)\in\{\mathrm{code}(v)\mid v\in L\}$, and a language is decidable if and only if the set of codes of its words is. The map $\Sigma^*\to\N$ given by shortlex order (length, then alphabetical order) also works; it is even a bijection, whereas the prime coding does not reach all integers.

From sets to functions. Conversely, a total function $f$ is computable if and only if its graph $G_f=\{\langle x,f(x)\rangle\mid x\in\N\}$ is decidable. If $f$ is computable, decide $\langle x,y\rangle\in G_f$ by computing $f(x)$; if $G_f$ is decidable, compute $f(x)$ by searching for the first $y$ such that $\langle x,y\rangle\in G_f$ (a search that terminates because $f$ is total).

Oracle machines

To study degrees of undecidability (chapter Arithmetical hierarchy), a machine is allowed to query a fixed set $A\subseteq\N$, a “black box” that instantly answers the question “$n\in A$?”.

Let $A\subseteq\N$. A machine relative to the oracle $A$ may contain, in addition to the three usual forms, quadruples of the form $q_i\,S_j\,q_k\,q_l$. If $\alpha=\gamma\,q_i\,S_j\,\delta$ and $q_i\,S_j\,q_k\,q_l\in P_Z$, then

$$\alpha\vdash_{Z^A}\gamma\,q_k\,S_j\,\delta \text{ if } \langle\alpha\rangle\in A,\qquad \alpha\vdash_{Z^A}\gamma\,q_l\,S_j\,\delta \text{ if } \langle\alpha\rangle\notin A.$$

We define as above $\Psi^{(n)}_{Z^A}$ and the class $\mathcal T^A$ of $A$-computable functions. One proves that $\mathcal T^A=P^A$, the functions recursive relative to $A$ (relative equivalence).

An oracle is a hypothesis: “if we knew how to answer such and such an impossible question, what more could we compute?”. We thus discover that the impossible has degrees: even with an oracle for the halting problem, some questions remain unanswered.

The machine asks the question about the number of bars present on the tape; the contents of the tape are not modified, only the next state depends on the answer. A machine without oracle quadruples computes the same function for every $A$: $\mathcal T\subseteq\mathcal T^A$, and $\mathcal T^A=\mathcal T$ if $A$ is computable (replace each oracle query by the computation of $\chi_A$).

For every $A\subseteq\N$, the characteristic function $\chi_A$ is $A$-computable: $\chi_A\in\mathcal T^A$.

This is almost a tautology, but it fixes the meaning of the word: an oracle is an answer given for free, and what costs is only the work around the question. It also shows that the hierarchy of degrees is “full”: any set, however complicated, becomes computable as soon as it is given as an oracle.

The question concerns $\langle\alpha\rangle$, the number of bars on the tape. On the input $\overline x=1^{x+1}$, there are $x+1$ bars: first erase one, then query the oracle, which receives exactly $x$; then erase the whole block, and write a bar if and only if the answer was positive. The following machine $Z$ works:

$$\begin{array}{llll} q_0\,1\,B\,q_1 & q_1\,B\,R\,q_2 & q_2\,1\,q_3\,q_4 & q_2\,B\,q_3\,q_4\\ q_3\,1\,B\,q_5 & q_5\,B\,R\,q_3 & q_3\,B\,1\,q_6 & \\ q_4\,1\,B\,q_7 & q_7\,B\,R\,q_4 & & \end{array}$$

After $q_0\,1\,B\,q_1$ and $q_1\,B\,R\,q_2$, the head is on the first of the $x$ remaining bars (or on a blank if $x=0$), and $\langle\alpha\rangle=x$. The two oracle quadruples cover the two possible symbols. If $x\in A$, the loop $q_3,q_5$ erases the bars towards the right, then $q_3\,B\,1\,q_6$ writes a bar and the machine halts in $q_6$ (no quadruple begins with $q_6$): $\Psi^{(1)}_{Z^A}(x)=1$. If $x\notin A$, the loop $q_4,q_7$ erases everything and the machine halts in $q_4$ on a blank: $\Psi^{(1)}_{Z^A}(x)=0$. So $\Psi^{(1)}_{Z^A}=\chi_A$.

The same machine, for another oracle $B$, computes $\chi_B$: it is a single machine, “uniform in the oracle”.

Check by simulation of the machine above for the 63 sets $A\subseteq\{0,\dots,5\}$ of size at most 6 and $x\le 7$: the result is always $\chi_A(x)$.

Variants of the model: external universality

We distinguish three forms of universality of Turing machines: external universality (reasonably modifying the model does not change what it computes, below), internal universality (a single machine simulates all the others, see Universality) and universality in terms of models of computation (the Church-Turing thesis).

The machine can be given more capabilities: write and move in a single step (quintuples, the model of the busy beavers), several tapes, several heads on the same tape, a nondeterministic program, or any combination of these. Capabilities can also be removed: a tape infinite on one side only, an alphabet reduced to $\{B,1\}$, a number of states bounded once and for all (a universal machine suffices). For each of these models we follow the same scheme (instantaneous descriptions, computation step, resultant, computed function), and obtain exactly the class $T$ of Turing-computable functions. The simulations change computation time by at most a polynomial factor (see Cost of simulation), but never the set of computable functions. Here is the simplest case treated in detail.

A quintuple machine (or “mobile” machine) is a finite consistent set of quintuples $q_i\,S_j\,S_k\,X\,q_l$ with $X\in\{L,R,I\}$: reading $S_j$ in state $q_i$, it writes $S_k$, moves left, right or stays put ($I$), and goes to state $q_l$. Defining instantaneous descriptions, computations and computed functions $\Psi^{(n)}$ in the same way, we obtain a class $T_m$ of functions, and $T_m=T$.

Whether the machine does one or two things per step changes nothing about what it can compute: only the number of steps. This is the simplest case of a general phenomenon. As soon as the programs of one model can be compiled into another, the two models have the same power; the whole equivalence of models of computation rests on compilers of this kind.

$T\subseteq T_m$: a quadruple machine is a quintuple machine that uses only part of its possibilities. Replace $q_i\,S_j\,S_k\,q_l$ by $q_i\,S_j\,S_k\,I\,q_l$, and $q_i\,S_j\,X\,q_l$ ($X=L,R$) by $q_i\,S_j\,S_j\,X\,q_l$. An induction on the length of computations shows that the two machines have the same resultants.

$T_m\subseteq T$: a quintuple $q_i\,S_j\,S_k\,I\,q_l$ becomes the quadruple $q_i\,S_j\,S_k\,q_l$. For $q_i\,S_j\,S_k\,X\,q_l$ with $X=L$ or $R$, one must first write, then move, going through a new intermediate state $r$, specific to this quintuple: $q_i\,S_j\,S_k\,r$ and $r\,S_k\,X\,q_l$. The machine obtained is consistent, and each step of the quintuple machine is simulated by one or two steps.

The compiler in action on the 2-state machine of the busy beaver chapter ($A\,B\,1\,R\,B$; $A\,1\,1\,L\,B$; $B\,B\,1\,L\,A$; $B\,1\,1\,R\,h$): each quintuple gives a writing quadruple and a moving one, with one intermediate state per quintuple.

A B 1 r1     r1 1 R B      # A B 1 R B
A 1 1 r2     r2 1 L B      # A 1 1 L B
B B 1 r3     r3 1 L A      # B B 1 L A
B 1 1 r4     r4 1 R h      # B 1 1 R h

Here the intermediate states $r_1,r_2$ have the same target state $B$ and read the same symbol $1$: with a single state “$B^w$”, we would have had both $B^w\,1\,R\,B$ and $B^w\,1\,L\,B$. This is exactly the pitfall pointed out above.

Some restrictions, on the other hand, lose computable functions:

  • a head that moves in only one direction (the machine becomes a finite automaton reading its input);
  • a single symbol used (the tape stays blank: one can neither give an input nor read a result);
  • a tape of bounded size (the number of configurations is finite, and the machine is a finite automaton);
  • a memory organized as a single stack (pushdown automata).

The first three points are proved below. The last one requires the theory of context-free languages: it is proved later (pushdown automata and grammars, pumping lemma), and nothing in the intermediate chapters depends on it.

On the other hand, randomness adds nothing: a probabilistic machine whose answer is correct with probability greater than $1/2$ computes only computable functions.

What gives Turing machines their power is therefore neither the size of the alphabet, nor the number of states, nor the richness of the instructions: it is the possibility of going back over what has been written, in an unbounded memory. Remove either of these two things and we fall into strictly weaker models, but ones for which many properties can be decided (see the summary in the chapter Languages and grammars).

One-way head. Suppose the machine has no quadruple moving left. A cell that has been left is then never read again. When the head arrives on a cell in state $q$ and reads $s$ there, the machine applies writing quadruples on the spot, deterministically, until: it leaves to the right in a state $q'$, or halts, or loops on the spot (a (state, symbol) pair repeats). Write $\delta(q,s)\in E\cup\{\text{halt},\text{loop}\}$ for this outcome, which depends only on $q$ and $s$. On the input $w=s_1\cdots s_\ell$, the state on leaving cell $j$ is therefore obtained by reading $w$ with the deterministic finite automaton with transition function $\delta$ (the two outcomes $\text{halt}$ and $\text{loop}$ being absorbing). After the input, the head reads only blanks, and the sequence of states $q,\delta(q,B),\delta(\delta(q,B),B),\dots$ reaches the halt within at most $|E|$ cells or never reaches it. The set of inputs on which the machine halts is therefore recognized by a finite automaton: it is regular (recognized by a finite automaton; these languages are studied in the chapter Languages and grammars, but the following argument does not need them). For inputs $\overline x=1^{x+1}$, a finite automaton over one letter has an ultimately periodic sequence of states, so the set of $x$ on which the machine halts is ultimately periodic: such a machine does not semi-decide, for example, the decidable set of squares, whose gaps grow.

Probabilistic machines. A probabilistic machine has, for each (state, symbol) pair, zero, one or two quadruples; when there are two, it tosses a coin, independently at each step. It computes $f$ if, for every $x$, the probability of halting with the result $f(x)$ exceeds $1/2$ when $f(x)$ is defined, and if, when $f(x)$ is not defined, no result has probability greater than $1/2$. Such an $f$ is computable. Write $P(x,y)$ for the probability of halting with the result $y$, and $P_s(x,y)$ for the sum of the $2^{-c}$ over the computations that halt in at most $s$ steps with the result $y$, $c$ being the number of coin tosses of the computation. These computations are disjoint events, finitely many for each $s$, so $P_s(x,y)$ is a computable rational, increasing in $s$, with limit $P(x,y)$. The algorithm searches, for $s=0,1,2,\dots$ and $y\le s$, for a pair with $P_s(x,y)>1/2$, and answers $y$. If $f(x)$ is defined, $P(x,f(x))>1/2$, so such a pair exists; and every answer $y$ satisfies $P(x,y)\ge P_s(x,y)>1/2$, whence $y=f(x)$, since two different results cannot each have probability greater than $1/2$. If $f(x)$ is not defined, no pair works and the algorithm does not halt. Conversely, a deterministic machine is a probabilistic machine that never tosses.

A single symbol. If the alphabet is reduced to the blank, the tape is blank at the start and stays so: the configuration contains no information about the input, and the computation is the same for all arguments. The machine therefore computes a constant function or the nowhere-defined function.

Bounded tape. For a machine whose tape is bounded by $\ell$ cells, there are at most $|E|\cdot\ell\cdot|A|^\ell$ configurations: one can decide whether it halts (a repeated configuration means that it loops). Such a machine cannot even read an input of more than $\ell$ cells: it distinguishes only finitely many arguments, and so does not compute, for example, the successor.

Computation time

The time of a computation is its number of steps (computation step). A machine (with one or several tapes) works in time $t(n)$ if, on every input of length $n$, it halts in at most $t(n)$ steps. We work here on words (for example integers written in binary), since the length of the unary notation $1^{x+1}$ is exponential in that of the binary notation.

$\mathsf P$ is the class of languages decided by a deterministic Turing machine in time $p(n)$ for some polynomial $p$.

A nondeterministic machine may have several quadruples for the same (state, symbol) pair; it accepts an input if at least one of its possible computations halts in an accepting state. $\mathsf{NP}$ is the class of languages accepted by a nondeterministic machine all of whose computations, on an input of length $n$, have at most $p(n)$ steps.

Equivalently, $L\in\mathsf{NP}$ if and only if there are a polynomial $q$ and a language $R\in\mathsf P$ (of coded pairs) such that $x\in L\iff\exists y\ \big(|y|\le q(|x|)\wedge(x,y)\in R\big)$: $y$ is a certificate that can be checked quickly. A language $L\in\mathsf{NP}$ is NP-complete if every language of $\mathsf{NP}$ reduces to it by a function computable in polynomial time.

$\mathsf P$ gathers the problems we know how to solve quickly, $\mathsf{NP}$ those for which we know how to check a proposed solution quickly. Whether the two classes are equal is the most famous open question in computer science. Thanks to the polynomial simulations between models (cost of simulations), these classes do not depend on the reasonable model chosen.

Equivalence of the two definitions. If $N$ is nondeterministic in time $p$, with at most $d$ choices per step, a computation is determined by the sequence of its choices, a word $y$ of length $p(n)$ over $\{1,\dots,d\}$ (coded in binary). The relation “the computation of $N$ on $x$ guided by the choices $y$ accepts” is checked by simulating $p(|x|)$ steps: it is in $\mathsf P$. Conversely, if $x\in L\iff\exists y\,(|y|\le q(|x|)\wedge(x,y)\in R)$ and $R$ is decided in time $r$, a nondeterministic machine writes a word $y$ of length at most $q(|x|)$ by choosing each letter, then runs the machine for $R$: all its computations have at most $O(q(n)+r(n+q(n)))$ steps, which is polynomial. That NP-complete problems exist (for example the satisfiability of propositional formulas) is the Cook-Levin theorem (1971), proved in the chapter Complexity, which also studies computation space and the other classes.

In state $q_0$ on a bar, the machine erases it ($q_1$), advances one cell and returns to $q_0$. It therefore erases the block of bars under the head, from left to right, and halts on the first blank met in $q_0$ (no quadruple begins with $q_0\,B$).

The tape has the form $B\,a^i1^{x-i}\,B\,1^i$ at the beginning of each round. In $q_2$ we skip the $a$’s; on a bar we mark it ($q_3$), cross the rest of the block ($q_4$), the separator, the bars already added ($q_5$), and write a bar; we come back ($q_7$, then $q_8$ through the block) to the last $a$, and start again in $q_2$ just to its right. The $i$-th round covers about $2x$ cells going and as many returning: the time is of the order of $2x^2$ (the simulation gives $3, 12, 25, 42, 63$ steps for $x=0,\dots,4$).
