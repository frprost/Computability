The idea of a universal function

Three forms of universality can be distinguished. External universality: reasonably changing the machine model does not change what it computes (see Variants of the model). Internal universality, the subject of this chapter: a single machine can simulate all the others, if it is given their description. Universality in terms of models of computation: all reasonable models compute the same functions (Church-Turing thesis).

It is no exaggeration to say that the computer was born from this idea. Before it, all calculating machines, from the abacus to Charles Babbage’s difference engine (1822), required a physical modification to change the function computed. With his analytical engine (from 1834 on), Babbage had designed a machine driven by punched cards, borrowed from Jacquard’s looms; in 1843 Ada Lovelace wrote for it the first published program, to compute the Bernoulli numbers. The machine was never completed. Here again, it was the comparison of two different machines, a loom and a calculating machine, that gave birth to the idea.

In computability, the notion appears naturally in the proof of the normal form: to show that a Turing-computable function is recursive, the machine is encoded by an integer $z$, and the resulting formula depends on the machine only through $z$. By making $z$ an argument, one obtains a function that simulates all machines.

Let $\mathcal C$ be a class of functions from $\N$ to $\N$. A function $u:\N^2\to\N$ is universal for $\mathcal C$ if:

  1. for every $g\in\mathcal C$, there is $e\in\N$ such that $g=(x\mapsto u(e,x))$;
  2. for every $e$, the function $x\mapsto u(e,x)$ is in $\mathcal C$.

We say that $u$ enumerates $\mathcal C$, and that an $e$ as in (1) is an index of $g$.

The restriction to arity 1 is inessential, thanks to the coding of $n$-tuples. The two conditions say that the “sections” $u(e,\cdot)$ are exactly the elements of $\mathcal C$.

There is no total computable function $u:\N^2\to\N$ universal for the class $\mathcal R$ of total computable functions.

A “computer” that could only run programs that always halt, and that could run all of them, cannot exist. If we want a universal machine, it must be able, on some programs, never to halt. Universality and the certainty of termination are incompatible.

If $u$ were such a function, $g(x)=u(x,x)+1$ would be computable and total, hence equal to $u(e,\cdot)$ for some $e$; then $u(e,e)=g(e)=u(e,e)+1$, a contradiction. This is the argument from the motivations, now stated precisely.

The partial function $u(z,x)\simeq U\big(\mu y\ T_1(z,x,y)\big)$ is computable and universal for the class of (partial) computable functions of one variable. Hence there is a Turing machine $\mathcal U$ such that, for every machine $Z$ with Gödel number $z$ and every $x$: $\Psi^{(2)}_{\mathcal U}(z,x)\simeq\Psi^{(1)}_Z(x)$.

A single machine, called universal, suffices: it is given as input the description of a machine and a datum, and it behaves like the machine described. The program has become a piece of data like any other. There is no longer any need to build one machine per function: a universal machine and a text are enough. This is exactly what a computer is: a fixed device to which programs are supplied.

Among register machine models one distinguishes the RAM model, in which the program is outside the memory, and the RASP model (random access stored program), in which it is stored in memory like the data. Real computers follow the latter, the so-called “von Neumann architecture” (1945), although the idea is already entirely present in Turing in 1936.

The normal form theorem gives, for every machine $Z$ with code $z$, $\Psi^{(1)}_Z(x)\simeq U(\mu y\,T_1(z,x,y))=u(z,x)$, whence condition (1). Condition (2) follows from the fact that $u$ is recursive, hence so is each $u(z,\cdot)$; if $z$ does not encode a machine, $T_1(z,x,y)$ is always false and $u(z,\cdot)$ is the nowhere-defined function, which is computable. Finally $u$ is recursive, hence Turing-computable: some machine $\mathcal U$ computes it.

The Turing machine simulator of this manual is a universal function: it receives the text of a machine and an input, and reproduces its behaviour. It is written in JavaScript, but the theory guarantees that it could be written as a Turing machine.

Small explicit universal machines have been built: Marvin Minsky (1962) gave one with 7 states and 4 symbols; Yurii Rogozhin (1996) built several, among them one with 4 states and 6 symbols. They do not simulate machines directly, but intermediate systems (“tag” systems) that are themselves universal, which makes their operation very indirect and slow.

Standard numbering of the computable functions

Gödel coding leaves many integers meaningless (not all of them encode a machine). It is more convenient for every integer to be a program.

Let $\eta(0)=\mu z\,\mathrm{TM}(z)$ and $\eta(n+1)=\mu z\,[\mathrm{TM}(z)\wedge z>\eta(n)]$: $\eta(n)$ is the $n$th Gödel number of a machine, in increasing order. We write

$$\varphi^{(k)}_e=\Psi^{(k)}_{Z}\quad\text{where } Z \text{ is the machine encoded by }\eta(e),$$

and $\varphi_e=\varphi^{(1)}_e$. For an oracle $A$, we similarly write $\varphi^{A,(k)}_e$. The integer $e$ is an index (or a program) of $\varphi^{(k)}_e$. We write $W_e=\{x:\varphi_e(x)\conv\}$ for the domain of $\varphi_e$.

From now on “program number $e$” has a precise meaning, for every integer $e$. One can speak of “the set of programs that halt”, of “two equivalent programs”, and ask mathematical questions about programs.
  • $\eta$ is recursive, strictly increasing, and so is its inverse (on its image): going from a Gödel code to an index is effective in both directions. It is even primitive recursive, since the search can be explicitly bounded (between two consecutive machine codes the gap is bounded by a primitive recursive function of $\eta(n)$).
  • Every computable function has infinitely many indices (the “padding” lemma): one can add to a machine quadruples involving a state that is never reached, without changing the function computed, just as one would add lines x := x to a program.
  • The same index denotes a function for each arity and for each oracle.
  • To show that $\eta$ is primitive recursive, the search can be bounded as follows: from a machine with code $z$, one obtains another, with a strictly larger code, by shifting the indices of all its states by one; the code of this shifted machine, a primitive recursive function of $z$, serves as a bound. The smallest machine is $q_0\,B\,R\,q_0$, with Gödel number $\eta(0)=2^{2^7 3^9 5^3 7^7}$.

For every $n\ge1$ (and every oracle $A$), there is an index $z_n$ such that, for all $e,x_1,\dots,x_n$:

$$\varphi^{(n+1)}_{z_n}(e,x_1,\dots,x_n)\simeq\varphi^{(n)}_e(x_1,\dots,x_n).$$

The universal machine itself has a number, and it appears in the list of all machines. It is this self-reference, a list that contains the program able to read the list, that makes possible both computers and the paradoxes of the chapter Undecidability.

$\Phi(e,\vec x)\simeq U(\mu y\,T_n(\eta(e),\vec x,y))$ is recursive (a composition of recursive functions and a minimization), hence Turing-computable, hence equal to $\varphi^{(n+1)}_{z_n}$ for some index $z_n$. With an oracle, the same proof works by adding to Kleene’s predicate the case of oracle quadruples, which consults $\chi_A$.

Exercises

Show that every computable function $f$ of one variable has infinitely many indices: there are infinitely many $e$ such that $\varphi_e=f$.

Let $Z$ be a machine computing $f$, and $q_m$ a state that does not occur in $Z$. For every $k$, the machine $Z_k=Z\cup\{q_{m+j}\,B\,B\,q_{m+j}:0\le j\le k\}$ still computes $f$: the added states are never reached, since no quadruple of $Z$ leads to them. The machines $Z_k$ are pairwise distinct, hence so are their Gödel numbers, and each one is an $\eta(e)$ for a different $e$. This is padding: adding dead code does not change the function computed.

Show that there is no total computable function $f$ such that $f(e)=\varphi_e(e)$ for every $e$ with $\varphi_e(e)\conv$.

Suppose such an $f$ exists. The function $d(e)=f(e)+1$ is total computable, hence $d=\varphi_k$ for some index $k$. Then $\varphi_k(k)=d(k)$ is defined, so $f(k)=\varphi_k(k)=d(k)=f(k)+1$: a contradiction. The universal function $(e,x)\mapsto\varphi_e(x)$ is therefore essentially partial: it cannot be completed into a total computable function, even on the diagonal alone (see also functions with no computable extension).

Show that there is a total computable function $u(e,x)$ universal for the class $\RP$ of primitive recursive functions of one variable, and that $u$ is not primitive recursive.

Enumerate the terms of $\RP$ of arity 1, $f_0,f_1,\dots$, and set $u(e,x)=f_e(x)$, computed by evaluating term number $e$ (see the exercise in chapter 6). It is total, since all functions of $\RP$ are, and universal by construction. If $u$ were primitive recursive, so would be $d(x)=u(x,x)+1$, hence $d=f_k$ for some $k$, and $f_k(k)=u(k,k)+1=f_k(k)+1$: a contradiction.

Compare with the theorem: for $\RP$, the interpreter exists but leaves the class; for the total computable functions, there is not even a total computable interpreter; for the partial computable functions, the interpreter exists and stays within the class.

Show that the set $\{e:W_e\ne\emptyset\}$ is semi-decidable, by describing a procedure explicitly.

One cannot test $\varphi_e(0)$, then $\varphi_e(1)$, etc., since the first computation may not terminate. The computations are interleaved: for $s=0,1,2,\dots$, run $s$ steps of the computation of $\varphi_e(x)$ for each $x\le s$. If one of them halts, halt. Formally, $W_e\ne\emptyset\iff\exists\langle x,y\rangle\ T_1(\eta(e),x,y)$, and the procedure searches for the least pair $\langle x,y\rangle$ satisfying this primitive recursive predicate. If $W_e$ contains some $x$, whose computation has code $y$, the search reaches $\langle x,y\rangle$ and halts; otherwise it does not halt. This interleaving (dovetailing) is the basic technique of the chapter Semi-decidability. The set is not decidable (Rice’s theorem).
