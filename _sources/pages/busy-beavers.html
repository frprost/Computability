In 1962, the Hungarian mathematician Tibor Radó proposed a contest: write, with a fixed number of states, a Turing machine that starts from a blank tape, eventually halts, and writes as many 1s as possible before doing so. These machines are called “busy beavers”, because they work hard before stopping.

For 2 states, the record is 4; for 3 states, 6; for 4 states, 13; for 5 states, the value was established only in 2024, by an online collaboration of researchers and amateurs, with a computer-checked proof. For 6 states, we only know that the record exceeds a tower of powers of 10 of dizzying height. This chapter shows that no program can compute these records in general.

With $n$ states, there are only finitely many possible machines. Some halt, others run forever. Among those that halt, one writes the most 1s: this is the record $\Sigma(n)$. The question looks innocent; it is one of the deepest in computability.

The problem

The busy beaver problem, proposed by Tibor Radó in 1962, gives a very concrete non-computable function, which speaks not of machine indices but of actual machines: among all Turing machines with $n$ states that, started on a blank tape, eventually halt, which one writes the most symbols?

At first sight the question seems solvable: there are finitely many $n$-state machines; it suffices to run them all and keep the best result. But some never halt, and one cannot know, in general, whether a machine that is still running will eventually halt with a better score. This is where non-computability comes from. The proof, however, is not a reduction to the halting problem: it shows directly that the function grows faster than any computable function.

Radó’s model

The machines of the contest have two symbols (0 and 1) and, at each step, write a symbol, move and change state. They can be run in the page with a fast simulator.

A Radó machine with $n$ states uses the symbols $0$ (the blank) and $1$. Its states are the letters $A,B,C,\dots$ (the first $n$), plus a halting state $H$, with no transition. It has exactly one transition for each pair (state $\ne H$, symbol read), that is, $2n$ transitions. We write $A0\to1RB$ for the transition “in state $A$, reading $0$, write $1$, move one square to the right ($R$) and go to state $B$”; the direction is $R$ or $L$. This is a quintuple in the sense of chapter 3, written $A\ 0\ 1\ R\ B$ in the simulators. The machine starts in state $A$ on a blank tape.

  • $\Sigma(n)$ is the largest number of $1$s on the tape at halting time, among the $n$-state machines that halt;
  • $S(n)$ is the largest number of steps performed before halting (the transition to $H$ counting as one step), among the $n$-state machines that halt.

A machine achieving $\Sigma(n)$ is called a busy beaver.

In plain words. We look at all the Turing machines that have a fixed number of states, for example 5, write only 0 or 1, and start on a blank tape. Among those that eventually halt, we look for the champion: the one that writes the most 1s, or the one that makes the most steps before halting.

The Hungarian mathematician Tibor Radó invented this contest in 1962 under the name “busy beaver”: a machine that keeps busy as long as possible before stopping. The number of machines of each size is finite, so there is indeed a champion. Finding it is quite another matter.

Writing and moving at every step changes nothing from the point of view of computability (a step “in place” is simulated by a round trip), but it does change the precise values of $\Sigma$ and $S$, which always depend on the exact model. There are $(4(n+1))^{2n}$ machines with $n$ states: each of the $2n$ transitions chooses a symbol (2 choices), a direction (2) and a target state ($n+1$, counting $H$). For the enumerations of the technological level, partial tables are also used, in which some transitions are missing: a machine reaching a missing transition halts. A partial table represents all its completions that perform the same computation.

The machine $A0\to1RB$, $A1\to1LC$, $B0\to1LA$, $B1\to1RB$, $C0\to1LB$, $C1\to1RH$ halts after 13 steps with six 1s on the tape. We have $\Sigma(3)=6$ and $S(3)=21$.

In plain words. Here is the champion machine with three states: it halts after 13 steps, leaving six 1s on the tape.

It can be followed by hand with the simulator on the page. To be sure that it is the champion, all the other three-state machines must be examined, and it must be proved that those that do not halt will really never halt. This is feasible at this size, but it very quickly becomes an enormous task.

For this manual, the values $\Sigma(2)=4$, $S(2)=6$, $\Sigma(3)=6$, $S(3)=21$ were rechecked by exhaustive enumeration of the $12^4=20{,}736$ two-state machines and the $16^6=16{,}777{,}216$ three-state machines, without using the known values. Each machine is simulated for 200 steps; for each of those that have not halted, the program exhibits a proof of non-halting. The 200-step limit is thus only used for sorting: it is not assumed to be sufficient, which would be circular. Each proof is a set of configurations that contains the initial configuration, is closed under one computation step and contains no halting configuration. For 3 states:

  • 7,571,840 machines halt, in at most 21 steps and with at most six 1s;
  • 2,985,984 have no halting transition;
  • 1,383,152 are settled by backward reasoning: every chain of configurations leading to halting, traced back step by step, becomes inconsistent in fewer than 30 steps;
  • 155,792 repeat a configuration exactly (cycle);
  • 4,679,088 repeat a configuration up to a translation, moving over a blank tape (translated cycle);
  • 1,152 are settled by a closed set of tape windows (n-grams);
  • the last 208, which behave like binary counters, are settled by a closed regular language: the left half of the tape is summarized by a finite automaton with at most 3 states, the right half is kept as is, like a stack. This gives a pushdown system, whose set of reachable configurations is regular and is computed exactly by saturation (see pushdown automata); it contains no halting configuration. This criterion, tried on 3,000 machines that halt, declared none of them non-halting.

Non-computability

If we could compute the record, we could solve the halting problem: to know whether an $n$-state machine halts, it would be enough to let it run a little longer than the record. This is impossible, so the record is not computable. It even grows faster than any computable function.

For every total computable function $f:\N\to\N$, $\Sigma(N)>f(N)$ for all sufficiently large $N$. In particular $\Sigma$ is not computable, and neither is $S$.

In plain words. The record grows faster than any function a program can compute.

It is not only that the record is hard to find. It grows faster than powers, faster than the Ackermann function, faster than any function that can be described by a program. Yet each record is a perfectly definite whole number.

Knowing these records would be a superpower. If we knew that the step record for 30-state machines is such and such a number, we could decide the halting of all these machines: we would run them for that number of steps, and those still running will never halt. Now many great mathematical conjectures, such as Goldbach’s, amount to knowing whether a certain machine of modest size halts.

Let $f$ be total computable. Set $F(x)=\sum_{i=0}^{x}\big(f(i)+i^2\big)$. $F$ is computable, strictly increasing, and $F(x)\ge f(x)$, $F(x)\ge x^2$. Let $M_F$ be a Radó machine with $n$ states which, starting from $x$ consecutive strokes (head on the first one), halts leaving these $x$ strokes, a blank, then $F(x)$ strokes, head on the first stroke of the result, and which never visits the squares to the left of its input (this can always be required: a tape infinite in one direction computes the same functions).

For every $x$, build a machine $M_x$: $x$ states write $x$ strokes moving right; two states bring the head back to the first one; then two copies of $M_F$ (states shifted) run one after the other. $M_x$ has $x+2+2n$ states, starts from a blank tape and halts with at least $x+F(x)+F(F(x))$ strokes. Hence $$\Sigma(x+2+2n)\ge F(F(x)).$$ For $x$ large enough, $x^2>x+2+2n$, so $F(x)\ge x^2>x+2+2n$, and since $F$ is strictly increasing, $$\Sigma(x+2+2n)\ge F(F(x))>F(x+2+2n)\ge f(x+2+2n).$$ Thus $\Sigma(N)>f(N)$ for all sufficiently large $N$. If $\Sigma$ were computable, we would in particular have $\Sigma(N)>\Sigma(N)$ for large $N$, which is absurd. Finally $S(n)\ge\Sigma(n)$ (at least one step is needed per 1 written), so $S$ also dominates every computable function.

In plain words. The records are known up to the 5-state machines. The last one, 47,176,870 steps, was established in 2024.

It took sixty years and an international collaboration of amateurs and researchers, helped by computers, to settle the case of 5-state machines. For 6 states, machines are known that halt after a number of steps impossible to write down, and others for which we do not know whether they halt; some resemble the Collatz sequence. It is likely that the 6-state record will never be known.

Beyond that, logic itself steps in: from a certain size on (it is known to be below 800), even the axioms of mathematics no longer allow the value of the record to be proved (theorem below).

What it takes to establish a value. Establishing $S(n)=k$ requires two things. The lower bound $S(n)\ge k$ is proved by exhibiting an $n$-state machine and simulating it until it halts at step $k$: a finite computation. The upper bound requires, for each of the $n$-state machines (there are $(4n+4)^{2n}$ of them, a finite number), either simulating it until it halts, which then happens within at most $k$ steps, or proving that it never halts. For $\Sigma(n)$, one also counts the 1 symbols on the tape of the machines that halt. For each $n$, the value is therefore reached by finitely many checks and proofs; but no algorithm provides these proofs for all $n$, otherwise $S$ would be computable, which Radó’s theorem rules out. The following theorem goes further: from some rank on, some of these non-halting proofs do not even exist in ZFC.

Checking $\Sigma(4)=13$ and $S(4)=107$. For 4 states, the $20^8\approx2.6\cdot10^{10}$ tables can no longer be enumerated one by one. They are explored in tree normal form: a machine is defined only on the transitions it actually uses. It is simulated; when it reaches an undefined transition, the tree branches: either it halts there, or one chooses the symbol written, the move and the next state, among the states already used and a single new state. The first move is taken to the right, since the mirror machine makes the same number of steps and writes the same number of 1s. Every 4-state machine thus reduces, up to renumbering of states, to a leaf of the tree performing the same computation. There are 3,995,005 leaves:

  • 249,693 halt, in at most 107 steps and with at most thirteen 1s;
  • 3,136,096 have no possible halting transition left;
  • 315,648 are settled by backward reasoning, 27,556 by a cycle, 257,557 by a translated cycle, 6,386 by a closed set of $n$-grams;
  • 2,066 by the closed regular language described in the 3-state example, with automata of at most 6 states;
  • the last 3 by proofs by hand, given below.

For these leaves, an undefined transition counts as a possible halt: each non-halting proof is therefore valid for all ways of completing the table. The first criterion simulates 1,000 steps, which is only used for sorting: no value of $S$ is assumed. The automaton criterion was also tried on machines that halt, and declared none of them non-halting. Programs: castors_tnf.c and far.c, a C rewrite of castors_far.py, which gives the same results on the 3-state machines.

The last three machines. We write $u\,[X]\,v$ for the configuration in which the tape holds $uv$, the rest being blank, and the head, in state $X$, reads the first letter of $v$. The three proofs follow the same pattern. One finds a family of configurations that transform into one another by “macro-steps”, each of a fixed number of steps, and one checks that the only undefined transition is never used. Each macro-step is checked by following its few transitions by hand, whatever the values of the parameters.

  1. $A0\to1RB$, $A1\to1LD$, $B0\to1RC$, $B1\to0LC$, $C0\to1LA$, $C1\to1RA$, $D1\to0RB$ ($D0$ undefined). For $a\ge2$, $1^a[A]11(01)^b$ leads in 4 steps to $1^{a-2}[A]11(01)^{b+1}$. For $a=1$, the same 4 steps lead to $[A](01)^{b+2}$. Next, $1^c[A]0101$ leads in 6 steps to $1^{c+4}[A]$, and $1^c[A]$ leads in 3 steps to $1^{c+1}[A]11$. Start from $1^a[A]11$ with $a\equiv1\pmod4$. One reaches $1[A]11(01)^{(a-1)/2}$, then $[A](01)^k$ with $k=(a+3)/2$, which is even. One finally reaches $1^{2k}[A]$, then $1^{a+4}[A]11$. The machine reaches $1^{25}[A]11$ at step 291.
  2. $A0\to1RB$, $A1\to0RB$, $B0\to1LB$, $B1\to0LC$, $C0\to0LD$, $D0\to1RD$, $D1\to0RA$ ($C1$ undefined). For $j\ge1$, $1^j0[A]001^m$ leads in 5 steps to $1^{j-1}0[A]001^{m+1}$. For $j=0$, $0[A]001^m$ leads in 8 steps to $1110[A]1^m$. Finally, for $m\ge3$, $1^k0[A]1^m$ leads in 7 steps to $1^{k+3}0[A]1^{m-3}$. Start from $1^k0[A]$ with $k\equiv0\pmod3$: one reaches $0[A]001^k$, then $1110[A]1^k$, then $1^{k+3}0[A]$. The machine reaches $1110[A]$ at step 8.
  3. $A0\to1RB$, $A1\to1LB$, $B0\to1RC$, $B1\to0RD$, $C0\to1LD$, $C1\to1RB$, $D1\to0LA$ ($D0$ undefined). For $j\ge1$, $1^j[A]101^m$ leads in 7 steps to $1^{j-1}[A]101^{m+1}$. For $m\ge3$, $[A]101^m$ leads in 7 steps to $1111[A]001^{m-3}$. For $r\ge3$, $1^c[A]001^r$ leads in 5 steps to $1^{c+3}[A]001^{r-3}$. Finally, $1^c[A]001$ leads in 6 steps to $1^{c+2}[A]101$. Start from $1^k[A]101$ with $k\equiv0\pmod3$ and $k\ge3$. One reaches $[A]101^{k+1}$, then $1111[A]001^{k-2}$. Since $k-2\equiv1\pmod3$, one reaches $1^{k+1}[A]001$, then $1^{k+3}[A]101$. The machine reaches $111[A]101$ at step 12.

In all three cases, one returns to a configuration of the same family, with a larger parameter that keeps the same congruence. The machine therefore never halts. The macro-steps and the complete cycles were also checked by program for small values of the parameters (castor4_dernieres.py). The proofs themselves hold for all values.

Assume ZFC is consistent. There is an integer $N$ such that, for every $n\ge N$ and every integer $k$, ZFC does not prove the statement “$S(n)=k$”. The same holds for $\Sigma$, with another integer $N'$.

In plain words. From a certain number of states on, the axioms on which all of mathematics rests no longer allow the exact value of the record to be proved, even in principle.

It is not only a matter of numbers too large to be computed. No proof will ever establish them. The reason is simple: knowing the record means knowing which machines of that size halt. Now one can build a machine of modest size that searches for a contradiction in mathematics and halts if it finds one. Knowing that it does not halt would mean proving that mathematics does not contradict itself, which it cannot do by itself (second incompleteness theorem). Chaitin’s number Ω contains the same information in compressed form.

The axioms of ZFC form a decidable set. There is therefore a Radó machine $M$ that enumerates all formal proofs in ZFC, and halts as soon as it finds one of $0\ne0$. Let $N$ be its number of states. ZFC proves “$M$ does not halt $\iff$ ZFC is consistent”: this is the translation of the definition of $M$. For $n\ge N$, add unreachable states to $M$ to obtain an $n$-state machine that behaves like $M$.

Suppose ZFC proves $S(n)=k$. By the definition of $S$, ZFC then proves that $M$, if it halts, halts within at most $k$ steps.

  • If $M$ actually halts within at most $k$ steps, ZFC is inconsistent, contrary to the hypothesis.
  • Otherwise, the statement “$M$ does not halt within $k$ steps” is a finite check, true, and ZFC proves it. Every true bounded statement is provable in PA (Σ-completeness), and ZFC proves all theorems of PA. ZFC therefore proves that $M$ does not halt, that is, that ZFC is consistent. This contradicts the second incompleteness theorem. It applies to every theory containing PA whose axioms form a primitive recursive set. This is the case of ZFC, once arithmetic is translated into von Neumann integers (points (1) and (2)).

For $\Sigma$. Let $M'$ be a machine that runs step by step the same search as $M$ and that, after each simulated step, adds a 1 to a counting zone placed on the left, which it never erases. $M'$ halts if and only if $M$ halts. If it halts after $t$ simulated steps, at least $t$ squares contain a 1. Let $N'$ be its number of states. If ZFC proves $\Sigma(n)=k$ for some $n\ge N'$, ZFC proves that $M$, if it halts, does so within at most $k$ steps, and one concludes as above.

Explicit values. The proof gives no precise value of $N$: one would have to write the machine $M$. This is what Yedidia and Aaronson (2016) did, with a machine of 7,918 states, under a hypothesis slightly stronger than the consistency of ZFC. Others followed, going below 800 states for ZF (Riebel, 2023). This also holds for ZFC, since PA proves that ZF and ZFC are equiconsistent (Gödel, 1938). These results concern $S$; the machine $M'$ requires a few more states. These machines are produced by compilers and are not rechecked here.

Exercises

Simulate the Radó machine $A0\to1RB$, $A1\to1LB$, $B0\to1LA$, $B1\to1RH$ on a blank tape. How many steps does it make, and how many 1s does it leave?

Write the tape with the square being read in brackets. Start: $A$, $[0]$. Then: $A0\to1RB$ gives $1[0]$ in $B$; $B0\to1LA$ gives $[1]1$ in $A$; $A1\to1LB$ gives $[0]11$ in $B$; $B0\to1LA$ gives $[0]111$ in $A$; $A0\to1RB$ gives $1[1]11$ in $B$; $B1\to1RH$: halt on $11[1]1$. Six steps, four 1s. These are the values $S(2)=6$ and $\Sigma(2)=4$ (known values).

How many Radó machines with $n$ states are there (in the sense of the definition)? Compute for $n=1,2,3,4$.

There are $2n$ transitions to fix (one per pair state, symbol read). Each chooses a symbol to write (2 choices), a direction (2 choices) and a next state among the $n$ states and $H$ ($n+1$ choices): $4(n+1)$ possibilities. Hence $(4n+4)^{2n}$ machines: $64$, $20{,}736$, $16{,}777{,}216$ and $25{,}600{,}000{,}000$ for $n=1,2,3,4$. In practice, this number is greatly reduced by symmetry (left-right exchange, renumbering of states) and by keeping only one transition to $H$; but the growth remains more than exponential, and each machine must be proved to halt or not.

Show that $\Sigma(n+1)\ge\Sigma(n)+1$ and $S(n)\ge\Sigma(n)$.

Let $M$ be an $n$-state machine that halts leaving $\Sigma(n)$ ones. In its transition to $H$, replace the state $H$ by a new state $N$, with $N1\to1RN$ and $N0\to1RH$. Once in $N$, the machine moves right over 1s; since the tape carries only finitely many 1s, it finds a 0, writes a 1 there and halts. It has $n+1$ states and leaves $\Sigma(n)+1$ ones, whence $\Sigma(n+1)\ge\Sigma(n)+1$.

Each step writes at most one symbol, hence adds at most one 1; a machine that leaves $k$ ones on an initially blank tape makes at least $k$ steps: $S(n)\ge\Sigma(n)$.

(a) Show that if $S(n)$ is known, one can decide, for each Radó machine with $n$ states, whether it halts on a blank tape. (b) Deduce, without going through $\Sigma$, that $S$ is bounded by no computable function.

(a) Simulate the machine for $S(n)$ steps. If it has not halted, it will never halt, since every $n$-state machine that halts does so within at most $S(n)$ steps.

(b) The same argument works with any upper bound: if $f$ is computable and $f(n)\ge S(n)$ for all $n$, simulating $f(n)$ steps decides halting on a blank tape for $n$-state machines. Yet this problem is undecidable: to every Turing machine $Z$ and every input $x$, one (computably) associates a Radó machine that first writes $x$ on the blank tape, then simulates $Z$; it halts if and only if $Z$ halts on $x$. A decider for halting on a blank tape would therefore decide $K$. This is Radó’s argument, and the reason why each new value of $S$ requires solving mathematical problems, such as variants of the Collatz conjecture (known values).
