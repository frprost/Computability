Definition

$$A(0,n)=n+1,\qquad A(m+1,0)=A(m,1),\qquad A(m+1,n+1)=A\big(m,\,A(m+1,n)\big).$$

Wilhelm Ackermann, a student of Hilbert, built a function of this kind in 1928 to show that there are computable, total functions, defined by a perfectly clear recursion, which nevertheless escape the primitive recursion scheme. The two-argument version above is due to Rózsa Péter (1935).

The recursion is double: it is on the pair $(m,n)$ ordered lexicographically, and the inner call $A(m+1,n)$ supplies the second argument of the outer call, so that the number of calls cannot be bounded in advance.

The equations define a unique total function $A:\N^2\to\N$, and this function is computable.

One shows by induction on $m$ that, for every $m$, there is a unique function $A_m:\N\to\N$ satisfying the equations of row $m$: $A_0(n)=n+1$; and if $A_m$ is defined, $A_{m+1}$ is defined by (simple) recursion on $n$: $A_{m+1}(0)=A_m(1)$, $A_{m+1}(n+1)=A_m(A_{m+1}(n))$. This is a well-founded recursion on the lexicographic order of $\N^2$: each call is on a strictly smaller pair ($(m,1)<(m+1,0)$, $(m+1,n)<(m+1,n+1)$ and $(m,\cdot)<(m+1,n+1)$), and this order has no infinite descending sequence. Computability follows from Church’s thesis (the program below), or from an explicit definition by minimization: one searches for the least code of a finite “computation tree” consistent with the equations.

An iterative program, with an explicit stack:

ackermann(m, n) :
    stack := [m]
    while stack not empty :
        m := pop(stack)
        if m = 0 :             n := n + 1
        else if n = 0 :        push(stack, m - 1) ; n := 1
        else :                 push(stack, m - 1) ; push(stack, m) ; n := n - 1
    return n

In the λ-calculus, thanks to Church numerals (which are iterators), the function fits on one line: $\mathsf{ACK}=\lambda m.\,m\,(\lambda f.\lambda n.\,n\,f\,(f\,\mathbf 1))\,\mathsf S$. Indeed $A_{m+1}(n)=A_m^{\,n+1}(1)$: iterate $A_m$. The λ-calculus, which allows higher-order iteration (iterating a function that is itself an iteration), thus naturally goes beyond primitive recursion.

Ch. Boitet’s lecture notes present the function $\alpha:\N^3\to\N$ defined by

$$\alpha(0,x,y)=x+y,\qquad \alpha(1,0,y)=0,\qquad \alpha(z+2,0,y)=1,\qquad \alpha(z+1,x+1,y)=\alpha\big(z,\ \alpha(z+1,x,y),\ y\big).$$

Then $\alpha(1,x,y)=x\,y$, $\alpha(2,x,y)=y^x$, and $\alpha(3,x,y)=y^{y^{\cdot^{\cdot^{y}}}}$ (a tower of $x$ exponents, equal to $1$ for $x=0$).

The first argument selects the operation: $z=0$ addition, $z=1$ multiplication (iterated addition), $z=2$ exponentiation (iterated multiplication), $z=3$ the tower (iterated exponentiation), and so on. Ackermann thus builds an infinite ladder of operations, each iterating the previous one; Péter’s version above keeps only its diagonal, with base $2$ fixed.

By induction on $x$, for fixed $z$: $\alpha(1,x+1,y)=\alpha(0,\alpha(1,x,y),y)=\alpha(1,x,y)+y$, whence $\alpha(1,x,y)=xy$; $\alpha(2,x+1,y)=\alpha(1,\alpha(2,x,y),y)=\alpha(2,x,y)\cdot y$, whence $\alpha(2,x,y)=y^x$; $\alpha(3,x+1,y)=y^{\alpha(3,x,y)}$. Examples: $\alpha(3,2,3)=3^3=27$ and $$\alpha(4,3,2)=\alpha(3,\alpha(4,2,2),2)=\alpha(3,4,2)=2^{2^{2^2}}=65536,$$ since $\alpha(4,1,2)=\alpha(3,1,2)=2$ and $\alpha(4,2,2)=\alpha(3,2,2)=4$. Well-definedness is proved as for $A$, by induction on $(z,x)$ in lexicographic order. That $\alpha$ is not primitive recursive is proved below, by reducing $\alpha$ to $A$ through an exact identity.

The function $A$ is recursive (and total): it is obtained from primitive recursive functions by a single minimization.

Encode the state of the iterative program above, the stack $[m_1,\dots,m_k]$ and the current value $n$, by a single integer $c=\langle\mathrm{gn}(m_1,\dots,m_k),n\rangle$, where $\mathrm{gn}$ is the coding of sequences by prime powers. One step of the program, $c\mapsto\mathrm{Step}(c)$, is primitive recursive: it reads the top of the stack, tests whether it is zero and whether $n$ is zero, and rewrites the code (length, top, truncation and appending are primitive recursive). By primitive recursion, $E(t,c)=\mathrm{Step}^t(c)$ is too. Then $$A(m,n)=\pi_2\Big(E\big(\mu t\,[\,\mathrm{length}(\pi_1(E(t,c_0)))=0\,],\ c_0\big)\Big),\qquad c_0=\langle\mathrm{gn}(m),n\rangle.$$ Minimization is the only non-primitive operation; it terminates because the stack empties (well-definedness). It cannot be replaced by a bounded minimization: the number of steps is bounded by no primitive recursive function of $(m,n)$, otherwise $A$ would be primitive recursive.

Every “exotic” recursion thus reduces to a “while” loop over a stack, encoded in an integer: this is exactly what a processor running a recursive program does. The stack can grow without any predictable bound, and this is where “for” loops fail.

Growth

$$A(0,n)=n+1,\quad A(1,n)=n+2,\quad A(2,n)=2n+3,\quad A(3,n)=2^{n+3}-3,\quad A(4,n)=\underbrace{2^{2^{\cdot^{\cdot^{2}}}}}_{n+3}-3.$$

Each row iterates the previous one: addition, multiplication, exponentiation, tower of exponentials… $A(4,2)=2^{65536}-3$ has 19,729 digits; $A(4,3)$ has more digits than there are atoms in the observable universe. Yet the program computing it fits in five lines, and it always terminates.

Identity (2) shows that the two Ackermann functions are the same ladder of operations, seen in two ways: Péter’s function is Ackermann’s ladder in base $2$, shifted by $3$. Row $z$ of $\alpha$ (addition, multiplication, exponentiation, tower…) is exactly row $z+1$ of $A$. So it is no accident of Péter’s definition that $A$ escapes “for” loops: it is the iteration of operations itself that goes too fast.

(1) For $z\ge1$, by induction on $z$: $\alpha(1,1,2)=\alpha(0,\alpha(1,0,2),2)=0+2=2$, and $\alpha(z+1,1,2)=\alpha(z,\alpha(z+1,0,2),2)=\alpha(z,1,2)=2$ since $\alpha(z+1,0,2)=1$ for $z\ge1$. Next $\alpha(0,2,2)=4$ and, for every $z$, $\alpha(z+1,2,2)=\alpha(z,\alpha(z+1,1,2),2)=\alpha(z,2,2)$, whence $\alpha(z,2,2)=4$ by induction. Finally $\alpha(z+1,3,2)=\alpha(z,\alpha(z+1,2,2),2)=\alpha(z,4,2)$. (This is the first question of the exercise in the lecture notes, here for every $z$.)

Exercises

Show that $A(1,n)=n+2$ and $A(2,n)=2n+3$, then compute $A(2,3)$ and $A(3,1)$.

By induction on $n$. $A(1,0)=A(0,1)=2$ and $A(1,n+1)=A(0,A(1,n))=A(1,n)+1$, whence $A(1,n)=n+2$. Then $A(2,0)=A(1,1)=3$ and $A(2,n+1)=A(1,A(2,n))=A(2,n)+2$, whence $A(2,n)=2n+3$. Thus $A(2,3)=9$, and $A(3,1)=A(2,A(3,0))=A(2,A(2,1))=A(2,5)=13$. One recovers the table of the first rows: each row iterates the previous one.

Show that, for all $m,n$: $A(m,n)>n$ and $A(m,n+1)>A(m,n)$.

We argue by induction on $m$, and for fixed $m$ by induction on $n$.

$A(m,n)>n$. For $m=0$, $A(0,n)=n+1$. Assume it for $m$ (and every $n$). Then $A(m+1,0)=A(m,1)>1>0$, and if $A(m+1,n)>n$, that is $A(m+1,n)\ge n+1$, then $A(m+1,n+1)=A(m,A(m+1,n))>A(m+1,n)\ge n+1$.

Monotonicity. For $m=0$, it is clear. For $m+1$: $A(m+1,n+1)=A(m,A(m+1,n))>A(m+1,n)$, by the first point applied to $m$. These two inequalities are the basic lemmas of the domination proof.

Hence $A(m,n)=v$ if and only if there is a justified subset of $[0,m]\times[0,v]^2$ containing $(m,n,v)$.
