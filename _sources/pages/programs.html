The technological level of the manual describes complete machines: every instruction is written out. These machines often have thousands of instructions, and nobody would check them by hand. So they have been programmed. The programs are gathered here; there is no need to know how to program to run them, just follow the installation instructions.

Download the programs (programs.zip)

Installing and running

The programs need only Python 3 (version 3.8 or later), with no additional library.

  1. Install Python. On Linux and macOS, it is usually already present: type python3 --version in a terminal. Otherwise, or on Windows, download it from python.org (on Windows, tick “Add Python to PATH” during installation).
  2. Unzip programs.zip: this gives a folder programs.
  3. Open a terminal in this folder (on Windows: right-click in the folder, “Open in Terminal”; on macOS: right-click, “New Terminal at Folder”).
  4. Run the checks: python3 tests.py (on Windows: py tests.py). After about ten seconds, the program displays “Everything as expected.”

Each file run without arguments (python3 compiler.py) displays its usage instructions.

The files

Each program corresponds to a chapter. The first three suffice to see a Turing machine compute and to build a machine automatically from a formula.
FileWhat it doesChapter
machines.pySimulator of quadruple Turing machines. Reads .tm files (one quadruple per line) and displays, on request, each step of the computation.Turing machines
examples/*.tmThe machines of chapter 3: addition, subtractions, constants, projections, multiplication, sign, equality.Examples
recursive.pyRecursive functions: the six building blocks $C$, $S$, $A$, $\sigma$, $\rho$, $\mu$, the evaluation of a term, a library (operations, comparisons, quotient, Cantor pairs…), and convenient writing by general substitution.Recursive functions
compiler.pyThe compiler from recursive functions to Turing machines: it writes the complete machine, runs it, compares the result.Equivalence
turing_to_recursive.pyThe converse direction: a Turing machine becomes a recursive term with a single minimization (Kleene normal form), checked step by step.Equivalence
lambda_calculus.pyNormal-order reducer of λ-terms, Church numerals, and compiler from recursive functions to the λ-calculus.λ-calculus, Equivalence
universal.pyA universal function $U(e,x)$ written with the six building blocks, then, by compiling it, a universal Turing machine (about 30 million quadruples).Universality
recursion.pyThe s-m-n theorem on Turing machines; Kleene’s fixed point; a program that prints its own text.s-m-n and recursion
halting.pyThe diagonal argument, executed: four candidate “halting deciders”, and the program that defeats each of them.Undecidability
stacks.pyTwo-stack automata: the translation of a Turing machine, the two stacks playing the two halves of the tape, checked step by step.Other models
counters.pyCounter machines: the tape stored in two numbers (in binary for blanks and strokes), then only two counters thanks to prime numbers; an interpreter that runs machines of 1027 steps.Other models
post.pyPost’s correspondence problem: the list of dominoes of a Turing machine, the solution drawn from its computation, and a breadth-first search.Other models
post_logic.pyFrom dominoes to logic: a sentence with one binary relation and one binary function, valid if and only if the dominoes have a solution (TPTP format for automated provers).Logic and types
tests.pyChecks all the preceding claims.

A few commands

python3 machines.py examples/addition.tm 2 3 --trace
python3 recursive.py "rho[A(1,1), sigma[S, A(3,2)]]" 2 3
python3 compiler.py mult 2 3 --output mult.tm
python3 machines.py mult.tm 2 3
python3 turing_to_recursive.py examples/proper_subtraction.tm 5 2
python3 lambda_calculus.py --compile fact 3
python3 universal.py
python3 universal.py --machine
python3 recursion.py
python3 halting.py
python3 stacks.py examples/addition.tm 1 1 --trace
python3 counters.py examples/addition.tm 2 1
python3 post.py
python3 post_logic.py

The syntax of terms is that of the chapter Recursive functions: C(k,m) for the constant $m^{(k)}$, S, A(k,i) for $A^{(k)}_i$, sigma[g, h1, ..., hk], rho[g, h], mu[g]; the Greek letters σ, ρ, μ are accepted, as well as the names of the library (python3 recursive.py --list).

The other programs of the manual

The verification programs of the more advanced chapters (busy beavers, complexity, Presburger, Kolmogorov, quantum randomness…) are in the folder assets/code/ of the site; each one is run with python3 file.py (or compiled with cc for the C files) and checks what it claims.
