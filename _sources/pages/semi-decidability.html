The notion of semi-decidability

The halting problem has a peculiarity: it is not decidable, but if a program halts, we will eventually find out; it suffices to run it. If the program does not halt, we may wait for an eternity without ever being able to conclude. This asymmetry defines a central class of problems.

A set $A\subseteq\N$ is semi-decidable (or recursively enumerable, “r.e.”) if it is the domain of a computable function: $A=W_e=\{x:\varphi_e(x)\conv\}$ for some index $e$. In other words, some program halts on the elements of $A$ and does not halt on the others.

Many questions of everyday life have this form. “Is this person guilty?”: a proof of guilt, if there is one, may eventually be found, but the absence of proof does not prove innocence; this is why the law makes innocence the default answer. “Is this scientific theory false?”: an experiment may refute it, but no series of experiments proves it definitively (this is Popper’s falsifiability criterion). “Is this mathematical statement provable?”: one can enumerate all proofs and recognize the right one if it exists, but the absence of a proof after a billion attempts says nothing.

In all these cases, “yes” is observable and “no” is not. Semi-decidability is the mathematical form of this situation.

When speaking of languages, these sets are also called Turing-recognizable. Every decidable set is semi-decidable (the program answers, then loops if the answer is “no”). $K=\{e:\varphi_e(e)\conv\}$ is semi-decidable ($K$ is the domain of $e\mapsto u(e,e)$) but not decidable: the class of semi-decidable sets is strictly larger.

For $A\subseteq\N$, the following are equivalent:

  1. $A$ is the domain of a computable function;
  2. $A$ is the range of a (partial) computable function;
  3. $A=\emptyset$ or $A$ is the range of a total computable function ($A$ can be enumerated, possibly with repetitions);
  4. there is a decidable predicate $R$ such that $x\in A\iff\exists y\ R(x,y)$ ($\Sigma_1$ form).

“Enumerable” takes on its full meaning: a semi-decidable set is a set whose list can be drawn up by a mechanical procedure, which runs forever and makes each element appear sooner or later. We do not know when a given element will appear, nor whether a missing element will eventually come: we only know that every element of $A$ will appear in the list.

(1)⇒(4): $x\in W_e\iff\exists y\ T_1(e,x,y)$ (normal form). (4)⇒(1): $x\mapsto\mu y\,R(x,y)$ is computable with domain $A$. (4)⇒(3): if $A\ne\emptyset$, fix $a\in A$ and set $g(\langle x,y\rangle)=x$ if $R(x,y)$, $a$ otherwise: $g$ is total with range $A$. (3)⇒(2) is immediate. (2)⇒(4): if $A$ is the range of $\varphi_e$, then $x\in A\iff\exists\langle z,y\rangle\ \big(T_1(e,z,y)\wedge U(y)=x\big)$, and the two quantifiers are contracted into one using the pairing function.

The implication (2)⇒(3) rests on a fundamental technique, dovetailing: one cannot run $\varphi_e(0)$ to the end and then $\varphi_e(1)$, since the first computation may never finish. The computations are therefore interleaved:

for t = 0, 1, 2, ... :                       // increasing time budget
    for z = 0, ..., t :
        run φ_e(z) for t steps
        if the computation has halted with result x (for the first time) :
            output x

Every computation that terminates eventually gets enough time, and no infinite computation blocks the others. Operating systems do exactly this when they share the processor among several programs.

A set $A$ is decidable if and only if $A$ and its complement $\overline A=\N\setminus A$ are both semi-decidable.

If one has both a “yes” detector and a “no” detector, one obtains a decider: it suffices to run them in parallel; one of the two will eventually answer. Undecidability arises exactly when one of the two sides is unobservable.

If $A$ is decidable, so is $\overline A$, and both are semi-decidable. Conversely, if $A=W_a$ and $\overline A=W_b$, to decide $x$ run $\varphi_a(x)$ and $\varphi_b(x)$ in parallel, one step of each in turn; exactly one of them halts, and we answer according to which.

$\overline K=\{e:\varphi_e(e)\ind\}$ is not semi-decidable. Semi-decidable sets are therefore not closed under complement (they are closed under union and intersection).

“This program will never halt” is not even observable in the long run. One can observe a halt; one can never observe, by observation alone, an absence of halting.

$K$ is semi-decidable; if $\overline K$ were too, $K$ would be decidable by Post’s theorem. For union and intersection: run the two semi-deciders in parallel and halt as soon as one (resp. both) has halted.

For every semi-decidable set $A$, $A\le_m K$. We say that $K$ is $\Sigma_1$-complete (or r.e.-complete).

Let $A=W_a$. By s-m-n, there is a total recursive $f$ such that $\varphi_{f(x)}(y)\simeq\varphi_a(x)$ for all $y$ (the program $f(x)$ ignores its input and runs $\varphi_a$ on $x$). Then $f(x)\in K\iff\varphi_{f(x)}(f(x))\conv\iff\varphi_a(x)\conv\iff x\in A$.

The halting problem is the hardest of the semi-decidable problems: knowing how to solve it would make it possible to solve all the others. It plays for computability the role that NP-complete problems play for complexity.

A partial function $f$ is computable if and only if its graph $\{\langle x,y\rangle: f(x)=y\}$ is semi-decidable. A total function is computable if and only if its graph is decidable.

If $f$ is computable, $\langle x,y\rangle$ is in the graph if and only if the computation of $f(x)$ terminates with $y$: semi-decidable. Conversely, if the graph is $\{\langle x,y\rangle:\exists t\,R(x,y,t)\}$ with $R$ decidable, then $f(x)\simeq\pi_1\big(\mu\langle y,t\rangle\,R(x,y,t)\big)$. For total $f$, if the graph is semi-decidable it is decidable: to test $f(x)=y$, compute $f(x)$ (which terminates) and compare.

Enumerations, projections, indices

The results of this section come from Ch. Boitet’s lecture notes (part B, chapter III), which follow H. Rogers (1967). They show that one can pass effectively from one presentation of a semi-decidable set to another, but not always from a presentation to a more informative one.

A relation $R\subseteq\N^k$ is called semi-decidable if $\{\langle x_1,\dots,x_k\rangle:(x_1,\dots,x_k)\in R\}$ is.

  1. Every semi-decidable relation $R\subseteq\N^k$ is the projection of a decidable (even primitive recursive) relation $S\subseteq\N^{k+1}$: $\vec x\in R\iff\exists y\ (\vec x,y)\in S$.
  2. The projection $\mathrm{Pr}_j(R)=\{(x_1,\dots,x_{j-1},x_{j+1},\dots,x_k):\exists x_j\ (x_1,\dots,x_k)\in R\}$ of a semi-decidable relation is semi-decidable.
  3. (Enumeration of relations) There is a recursive relation $R\subseteq\N^3$ such that, for every $z$, $W_z=\{x:\exists w\ R(z,x,w)\}$.

A semi-decidable set is a set defined by “there exists a verifiable witness”. Adding further “there exists” does not take us out of the class: two searches for witnesses merge into one, by searching for pairs. It is this robustness that makes it such a natural notion, and the first step of the arithmetical hierarchy.

(1) If $\langle\vec x\rangle\in W_m$, take $S(\vec x,y)$: “$\varphi_m(\langle\vec x\rangle)$ halts in fewer than $y$ steps”, primitive recursive. (2) If $Q=\mathrm{Pr}_k(R)$ and $R(\vec x,x_k)\iff\exists x_{k+1}S(\vec x,x_k,x_{k+1})$, then $Q(\vec x)\iff\exists z\ S(\vec x,\pi_1(z),\pi_2(z))$: two quantifiers are contracted into one using the pairing function, and $Q$ is the domain of $\vec x\mapsto\mu z\,S(\vec x,\pi_1(z),\pi_2(z))$. (3) $R(z,x,w)$: “$\varphi_z(x)$ halts in fewer than $w$ steps”.

  2. An infinite set is decidable if and only if it is the range of a strictly increasing total computable function.
  3. Every infinite semi-decidable set contains an infinite decidable subset.

Enumerating a set in order is stronger information than enumerating it in any order: if the list is increasing and we have gone past $x$ without meeting it, we know that $x$ will never appear. This is the difference between a sorted directory and a pile of index cards.

(1) and (2), forward direction: if $A$ is decidable and infinite, $f(0)=\mu y\,[\chi_A(y)=1]$, $f(k+1)=\mu y\,[\chi_A(y)=1\wedge y>f(k)]$; if it is finite and nonempty, repeat its largest element. Conversely, if $f$ is nondecreasing and $A=\mathrm{Im}\,f$ is infinite, to decide $x$ compute $f(0),f(1),\dots$ until the first $f(y)>x$, which happens since $A$ is infinite: $\chi_A(x)=\overline{\mathrm{sg}}\big(\prod_{y\le g(x)}|x-f(y)|\big)$ with $g(x)=\mu y\,[f(y)>x]$; if $A$ is finite, it is decidable anyway. (3) If $f$ enumerates $A$, set $g(0)=f(0)$ and $g(x+1)=f\big(\mu y\,[f(y)>g(x)]\big)$: $g$ is strictly increasing, with range contained in $A$, and this range is infinite hence decidable by (2).
  1. There are primitive recursive functions $f,g$ such that, for every $x$, $\mathrm{Im}\,\varphi_{f(x)}=\mathrm{Dom}\,\varphi_x$ and $\mathrm{Dom}\,\varphi_{g(x)}=\mathrm{Im}\,\varphi_x$.
  2. One can moreover require $\varphi_{f(x)}$ to be injective with domain an initial segment of $\N$ (all of $\N$ or an interval $[0,n]$): every semi-decidable set can be enumerated without repetition, uniformly in its index.
  3. The inverse image of a semi-decidable set under a partial computable function is semi-decidable: if $A=W_m$, then $\psi^{-1}(A)$ is the domain of $\varphi_m\circ\psi$.

(1) can be read off the proofs of the characterization theorem: each transformation is a program taking $x$ as a parameter, and the s-m-n theorem makes it a primitive recursive function of the indices. For $g$: $\theta(x,y)\simeq y$ if $y$ appears in the range of $\varphi_x$ at some stage of the dovetailing, $\ind$ otherwise. (2) Modify the dovetailing so as to output only new elements.

A set can be given by three kinds of indices:

  • an r.e. index $x$ of a semi-decidable set $A$: $A=W_x=\mathrm{Dom}\,\varphi_x$;
  • a characteristic index $x$ of a decidable set $A$: $\varphi_x$ is the characteristic function of $A$, and we write $A=C_x$;
  • a canonical index $x$ of a finite set $A$: $x=\sum_{i\in A}2^i$, and we write $A=D_x$ (the binary expansion of $x$ gives the list of elements).

One passes uniformly from canonical indices to characteristic indices, and from these to r.e. indices: there are total computable $f_1,f_2$ with $D_x=C_{f_1(x)}$ and $C_x=W_{f_2(x)}$. But not in the other direction: there is no partial computable function $\psi$ such that $\psi(x)\conv$ and $C_x=D_{\psi(x)}$ whenever $C_x$ is finite, nor any $\psi$ such that $\psi(x)\conv$ and $W_x=C_{\psi(x)}$ whenever $W_x$ is decidable.

Knowing that a set is finite does not give its list; knowing that it is decidable does not give a decision algorithm. One may have a program answering “is $n$ in the set?” without being able to say how many elements the set has, even when that number is finite. The information “there exists” is weaker than the information “here it is”.

Lemma: $x\mapsto|D_x|$ is computable (it is the number of 1s in the binary expansion of $x$), but no partial computable $\psi$ satisfies “if $\varphi_x=\chi_A$ with $A$ finite, then $\psi(x)=|A|$”. Indeed, let $\eta(x,z)=1$ if $\varphi_x(x)$ halts in exactly $z$ steps, $0$ otherwise; by s-m-n, $\lambda z.\eta(x,z)=\varphi_{g(x)}$ with $g$ total, and $\varphi_{g(x)}$ is the characteristic function of a one-element set if $x\in K$, of the empty set otherwise. Then $\psi\circ g$ would be total and characteristic of $K$.

The first point of the theorem follows (otherwise $|D_{\psi(x)}|$ would give the cardinality). For the second, let $h_1$ be total with $\varphi_{h_1(x)}(y)\simeq0$ if $y=0$ and $x\in K$, $\ind$ otherwise: $W_{h_1(x)}$ is $\{0\}$ or $\emptyset$, always decidable; $\psi\circ h_1$ would be total and $x\mapsto\varphi_{\psi(h_1(x))}(0)$ would characterize $K$.

A set $A\subseteq\N$ is single-valued if the set of pairs $\{(x,y):\langle x,y\rangle\in A\}$ is the graph of a (partial) function.

  1. (Uniformization) There is a total computable $f$ such that, for every $z$: $W_{f(z)}$ is single-valued, $W_{f(z)}\subseteq W_z$, $W_{f(z)}$ has the same domain as $W_z$, and $W_{f(z)}=W_z$ if $W_z$ is already single-valued.
  2. (Selection) There is a partial computable $\psi$ such that, for every $z$: $\psi(z)$ is defined if and only if $W_z$ contains an index $w$ with $W_w\ne\emptyset$, and in that case $\psi(z)$ is such an index.

From a semi-decidable relation “$y$ is an acceptable answer for $x$”, one can mechanically extract a function that chooses an answer for each $x$ that has one: keep the first answer found by the dovetailing. This is an effective “axiom of choice”, valid because the sets involved are enumerable.

(1) Enumerate $W_z$ without repetition and keep a pair $\langle x,y\rangle$ only if no pair $\langle x,y'\rangle$ was enumerated before it; the resulting set is semi-decidable, uniformly in $z$. (2) $\{\langle z,w\rangle:w\in W_z\wedge\exists u\ u\in W_w\}$ is semi-decidable by projection; apply (1) to it and take for $\psi$ the function whose graph it is.

The set $U=\{z : W_z \text{ is single-valued}\}$ is not semi-decidable. Its complement, on the other hand, is semi-decidable; in particular $U$ is not decidable.

The previous theorem can produce single-valued indices: from any $z$, $f(z)$ is one. But it is impossible to recognize them all. Being single-valued is an absence (“never two answers to the same question”), and an absence cannot be observed in finite time; the failure of single-valuedness, on the contrary, is visible as soon as two incompatible pairs have appeared.

The complement is semi-decidable. $z\notin U$ if and only if $\exists x\,\exists y\,\exists y'\ (y\ne y'\wedge \langle x,y\rangle\in W_z\wedge\langle x,y'\rangle\in W_z)$: this is the projection of a semi-decidable set, hence a semi-decidable set (projection theorem).

$U$ is not semi-decidable. We reduce the complement $\overline K$ of the halting problem to $U$. The partial function $\theta(x,t)=0$ if $t=\langle 0,0\rangle$, $\theta(x,t)=\Phi_x(x)\cdot 0$ if $t=\langle 0,1\rangle$, and $\theta(x,t)$ undefined otherwise, is computable. By the s-m-n theorem, there is a total computable $g$ with $\Phi_{g(x)}(t)\simeq\theta(x,t)$, whence

$$W_{g(x)}=\begin{cases}\{\langle 0,0\rangle\} & \text{if } x\notin K,\\ \{\langle 0,0\rangle,\langle 0,1\rangle\} & \text{if } x\in K.\end{cases}$$

The first set is single-valued, the second is not (two values at $0$). Hence $x\in\overline K\iff g(x)\in U$. If $U$ were semi-decidable, so would be $\overline K=g^{-1}(U)$ (semi-decide $g(x)\in U$), which contradicts the corollary: $\overline K$ is not semi-decidable.

Finally $U$ is not decidable, otherwise it would be semi-decidable. For undecidability alone one could also conclude by Rice’s theorem, since “being single-valued” is a non-trivial property of $W_z$; the reduction above gives more, namely non-semi-decidability.

The reduction is uniform and entirely explicit: the machine with index $g(x)$ reads $t$, halts at once if $t=\langle 0,0\rangle=0$ (with Cantor’s pairing, $\langle 0,1\rangle=1$), simulates $\Phi_x(x)$ and then halts if $t=1$, and loops in all other cases. In pseudo-code:

def phi_g(x):            # the machine with index g(x), as a function of t
    def m(t):
        if t == 0: return 0                     # <0,0>
        if t == 1: universal(x, x); return 0    # <0,1> : only if x ∈ K
        while True: pass                        # undefined elsewhere
    return m

Exercises

Show that the union and the intersection of two semi-decidable sets are semi-decidable. Why does the union require a little more care?

Let $A=\mathrm{dom}\,\varphi_a$ and $B=\mathrm{dom}\,\varphi_b$. For $A\cap B$, compute $\varphi_a(x)$, then $\varphi_b(x)$, and halt if both computations terminate. For $A\cup B$, one cannot do the same: if $\varphi_a(x)$ does not terminate, one would never reach $\varphi_b(x)$. The two computations are therefore run alternately, one step of each in turn, halting as soon as one of them halts. Formally, $x\in A\cup B\iff\exists y\,\big(T_1(\eta(a),x,y)\vee T_1(\eta(b),x,y)\big)$, the projection of a decidable predicate (projection theorem).

Show that if $A\le_mB$ and $B$ is semi-decidable, then $A$ is semi-decidable. Deduce that if $\overline K\le_mB$, then $B$ is not semi-decidable.

Let $f$ be total computable with $x\in A\iff f(x)\in B$, and $B=\mathrm{dom}\,\varphi_b$. Then $A=\mathrm{dom}(\varphi_b\circ f)$: compute $f(x)$ (which terminates), then $\varphi_b(f(x))$. If $\overline K\le_mB$ with $B$ semi-decidable, $\overline K$ would be semi-decidable, which is false (corollary).

Let $\mathrm{Tot}=\{e:\varphi_e\text{ is total}\}$. Show that neither $\mathrm{Tot}$ nor its complement is semi-decidable.

Complement. By s-m-n, there is a total computable $h$ with $\varphi_{h(e)}(x)\simeq\varphi_e(e)$ for all $x$. If $e\in K$, $\varphi_{h(e)}$ is total; otherwise it is nowhere defined. Hence $e\in\overline K\iff h(e)\in\overline{\mathrm{Tot}}$: $\overline K\le_m\overline{\mathrm{Tot}}$.

$\mathrm{Tot}$ itself. We need a function that is total exactly when $e\notin K$. By s-m-n, let $g$ be total computable with $\varphi_{g(e)}(x)=0$ if the computation of $\varphi_e(e)$ has not halted within $x$ steps, and $\varphi_{g(e)}(x)\ind$ otherwise (simulate $x$ steps, then loop if the computation has halted). If $e\notin K$, $\varphi_{g(e)}$ is the zero function, total. If $e\in K$, with a computation of $s$ steps, $\varphi_{g(e)}(x)\ind$ for $x\ge s$. Hence $\overline K\le_m\mathrm{Tot}$.

By the previous exercise, neither is semi-decidable. We recover the fact that $\mathrm{Tot}$ lies beyond the first level of the arithmetical hierarchy.

Let $A=\{e:\varphi_e(e)=0\}$ and $B=\{e:\varphi_e(e)=1\}$. Show that they are semi-decidable and disjoint, but that there is no decidable set $C$ with $A\subseteq C$ and $B\cap C=\emptyset$.

$A$ and $B$ are semi-decidable: compute $\varphi_e(e)$ and compare the result with $0$ (resp. $1$). They are disjoint, since $\varphi_e(e)$ has at most one value.

Suppose $C$ is decidable, $A\subseteq C$ and $B\cap C=\emptyset$. The function $g(e)=1$ if $e\in C$, $g(e)=0$ otherwise, is total computable; let $k$ be an index of $g$. If $k\in C$, then $\varphi_k(k)=1$, so $k\in B$, contradicting $B\cap C=\emptyset$. If $k\notin C$, then $\varphi_k(k)=0$, so $k\in A\subseteq C$: a contradiction. Such a pair is called recursively inseparable. Pairs of this kind are used to show that theories are undecidable, and the idea reappears in Rosser’s theorem (incompleteness).
