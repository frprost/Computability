Equivalence of the models of computation

Turing machines, recursive functions and the λ-calculus compute exactly the same functions. This chapter proves it, and the page contains a compiler that actually carries out the translation of recursive functions into Turing machines.

Three ways of computing, devised independently (a machine, formulas, functions of functions), compute exactly the same things. This is proved by translating each into the others, as one translates a program from one language into another.

Turing described computation by a machine, Church by functions applied to one another, Gödel and Kleene by formulas built from simple bricks. These three ideas were born almost at the same time, in the 1930s, among researchers trying to answer the same question: what is a computation?

This chapter proves that they describe exactly the same thing. The method is that of a translator: we show that any formula can be automatically transformed into a machine that computes the same thing, and any machine into a formula. In computer science, such a translator is called a compiler. This is exactly what a computer does when it transforms a program written by a human into elementary instructions for its processor.

That three such different paths lead to the same place is the best reason to think that this place, the class of computable functions, is not an arbitrary invention but a natural notion.

Outline of the proof

The proof consists of four translations: from formulas to machines, from machines to formulas, from formulas to the λ-calculus, and from the λ-calculus to formulas. If each language translates into another, they all have the same power.

This chapter is the technical counterpart of Church’s thesis. We take the recursive functions $\PR$ as reference and show four inclusions:

$$\PR\subseteq\mathcal T\subseteq\PR \qquad\text{and}\qquad \PR\subseteq\Lambda\subseteq\PR,$$

where $\mathcal T$ denotes the Turing-computable functions and $\Lambda$ the λ-definable functions. Each inclusion is a compilation: a program of one model is translated into a program of the other that computes the same function. We may always restrict ourselves to functions from $\N^n$ to $\N$, thanks to codings.

Recursive functions are Turing-computable

We want to build, for each formula, a Turing machine that computes the same thing. The trick is to organize the tape like a stack of plates: the numbers are placed one after another, and one always works on those at the top. For each basic brick and each combination recipe, we write a small piece of machine; for a whole formula, the pieces are assembled like Lego bricks. A program carries out this assembly automatically: for multiplication, it writes a machine of 2,759 rules, which computes correctly.

Theorem
Every recursive function is Turing-computable

For every recursive function $f:\N^n\to\N$, there is a Turing machine $Z_f$ such that $\Psi^{(n)}_{Z_f}=f$ (with equality of the domains of definition as well).

In plain words. Every function built with the bricks and recipes of the chapter Recursive functions can be computed by a Turing machine. Better: the machine is built automatically from the formula.

Chaining, repeating a known number of times, searching until found: these three recipes are all carried out by a machine that can only read, write and move by one cell. There is therefore no “elementary” mathematical operation that escapes the most basic mechanics.

The proof is a compiler, in the exact sense in which computer scientists use the word: a program that takes a high-level description and translates it into elementary instructions. The machines produced are enormous (thousands of rules for multiplication), just as the code produced by a real compiler is much longer than the program written by the human.

We prove a stronger statement, suited to composition. Fix a stack discipline: the tape contains a sequence of blocks $\overline{a_1}\,B\,\overline{a_2}\,B\cdots B\,\overline{a_r}$ (blocks of bars separated by a single blank, nothing beyond), and we call $E$ the cell two cells after the last bar (where a new block would begin). We say that a machine $M$ pushes $f$ (of arity $n$) if, starting at $E$ in its initial state with a tape whose last $n$ blocks code $\vec x$:

  • if $f(\vec x)\conv$, it reaches its final state at $E$, with the same tape extended by a block $\overline{f(\vec x)}$, without having modified the previous blocks;
  • if $f(\vec x)\ind$, it never reaches its final state.

Since final states have no instruction, two machines can be chained by identifying the final state of the first with the initial state of the second (after renaming the states to make them disjoint). We have auxiliary machines, parameterized by constants $j\ge1$ known at compile time (built explicitly at the technological level):

  • $\mathsf{Copy}_j$: pushes a copy of the $j$th block counted from the end;
  • $\mathsf{Delete}_j$: deletes the $j$th block from the end and closes up the following ones;
  • $\mathsf{Push}_m$: pushes the block $\overline m$; $\mathsf{Incr}$: adds a bar to the last block; $\mathsf{Decr}_j$: removes one from the $j$th;
  • $\mathsf{Zero?}_j$: ends in one of two states according to whether the $j$th block codes 0 or not.

We then show, by induction on the construction of $f$, that there is a machine that pushes $f$:

  • Base functions. $m^{(k)}$: $\mathsf{Push}_m$. Successor: $\mathsf{Copy}_1$ then $\mathsf{Incr}$. Projection $A^{(k)}_i$: $\mathsf{Copy}_{k-i+1}$.
  • Substitution $\sigma[g,h_1,\dots,h_k]$ of arity $m$: for $j=1,\dots,k$, push a copy of the $m$ arguments ($m$ times $\mathsf{Copy}_{m+j-1}$), run the machine of $h_j$, then delete the $m$ copies ($m$ times $\mathsf{Delete}_2$); the tape then carries $\vec x,y_1,\dots,y_k$. Run the machine of $g$ on the last $k$ blocks, then delete $y_1,\dots,y_k$. If some $h_j(\vec x)$ is undefined, the machine of $h_j$ does not terminate, and neither does the whole: the composite is undefined, as it should be.
  • Recursion $\rho[g,h]$: push a counter $c:=y$, an index $i:=0$ and $a:=g(\vec x)$, then loop: if $c=0$, delete $c$ and $i$, and $a$ is the result; otherwise decrement $c$, compute $r=h(i,a,\vec x)$ on copies, and replace $(i,a)$ by $(i+1,r)$.
  • Minimization $\mu[g]$: push $z:=0$; loop: compute $r=g(\vec x,z)$ on copies; if $r=0$, delete $r$ and stop (the block $z$ is the result); otherwise delete $r$, increment $z$ and start again. If $g(\vec x,z)$ is undefined for some $z$ reached, or if $g$ never vanishes, the loop does not terminate.

Finally, the required machine $Z_f$ first goes to $E$, pushes $f(\vec x)$, deletes the $n$ argument blocks, and removes one bar from the result: exactly $f(\vec x)$ bars remain, which is the output convention of $\Psi^{(n)}$.

The compiler

The simulator below applies the proof literally: it compiles the chosen term into a complete Turing machine (in the quadruple format of chapter 3, symbols $B$, $1$ and an auxiliary mark $X$), runs it on the input, and compares the result with a direct evaluation of the term. The complete program is displayed: a few hundred to a few thousand quadruples.

All the terms of the catalogue have been tested automatically on grids of inputs (for example $0\le x,y\le4$ for addition, multiplication and truncated subtraction): the compiled machine and the direct evaluation always agree, including on inputs where the function is undefined (the machine does not halt).

Organization

A class Assembler accumulates quadruples and provides fresh state names. Each macro is a method that receives the entry state $e$ and returns its exit state: chaining two macros consists of passing the exit state of the first as the entry state of the second. This is exactly the operation “identify the final state of the first machine with the initial state of the second” of the proof, carried out by simple composition of calls. A jump back to the head of a loop uses link(a, b), which adds the quadruples without effect $a\,s\,s\,b$ for each symbol $s\in\{B,1,X\}$.

def copy(self, e, j):
    """Copy_j: push a copy of the j-th block from the end.
    For each stroke of the source: replace it with X, go to the end, write a stroke there,
    come back to the X, put the stroke back, move on to the next stroke."""
    s = self.go_to_block(e, j)
    c1 = self.fresh("copy")
    self.q(s, I, X, c1)                      # first stroke marked
    e1 = self.go_to_E(c1)
    r = self.fresh("copy")
    self.q(e1, B, I, r)                      # first stroke of the copy, written at E
    self.q(r, I, "L", r)                     # back towards the mark
    self.q(r, B, "L", r)
    r1, r2 = self.fresh("copy"), self.fresh("copy")
    self.q(r, X, I, r1)                      # restore the marked stroke
    self.q(r1, I, "R", r2)                   # next stroke of the source
    d = self.fresh("copy")
    self.q(r2, I, X, d)                      # one more stroke: mark it
    e2 = self.go_to_E(d)                     # E is two cells after the copy in progress
    e3 = self.fresh("copy")
    self.q(e2, B, "L", e3)                   # we step back one cell to extend the copy
    self.q(e3, B, I, r)
    f = self.fresh("copy")
    self.q(r2, B, B, f)                      # end of the source
    return self.go_to_E(f)

def compile(self, e, f):
    """Machine that pushes f, starting in e; returns its exit state."""
    while isinstance(f, Named):
        f = f.term
    if isinstance(f, Const):                 # m^(k): Push_m
        return self.push(e, f.m)
    if isinstance(f, Succ):                  # S: Copy_1 then Incr
        return self.incr(self.copy(e, 1))
    if isinstance(f, Proj):                  # A^(k)_i: Copy_{k-i+1}
        return self.copy(e, f.k - f.i + 1)
    if isinstance(f, Comp):                  # sigma[g, h1..hk]
        m, k, cur = f.arity(), len(f.hs), e
        for j, h in enumerate(f.hs, start=1):
            for _ in range(m):               # copy of the m arguments (y1..y_{j-1} are above)
                cur = self.copy(cur, m + j - 1)
            cur = self.compile(cur, h)       # pushes y_j = h_j(x)
            for _ in range(m):               # deletes the copies, below y_j
                cur = self.delete(cur, 2)
        cur = self.compile(cur, f.g)         # pushes g(y1..yk)
        for _ in range(k):
            cur = self.delete(cur, 2)        # deletes y1..yk
        return cur
    if isinstance(f, Rec):                   # rho[g, h]; stack: y, x2..xk
        kk, cur = f.arity(), e
        cur = self.copy(cur, kk)             # c := y
        cur = self.push(cur, 0)              # i := 0
        for _ in range(kk - 1):
            cur = self.copy(cur, kk + 1)     # copies of x2..xk
        cur = self.compile(cur, f.g)         # a := g(x)
        for _ in range(kk - 1):
            cur = self.delete(cur, 2)
        loop = cur                           # stack: ..., c, i, a
        done, go_on = self.zero(loop, 3)
        end = self.delete(self.delete(done, 3), 2)   # c = 0: a remains
        cur = self.decr(go_on, 3)            # c := c - 1
        cur = self.copy(cur, 2)              # i
        cur = self.copy(cur, 2)              # a
        for _ in range(kk - 1):
            cur = self.copy(cur, kk + 4)     # x2..xk
        cur = self.compile(cur, f.h)         # r := h(i, a, x)
        for _ in range(kk + 1):
            cur = self.delete(cur, 2)        # deletes the copies
        cur = self.copy(cur, 3)              # i
        cur = self.incr(cur)                 # i + 1
        cur = self.copy(cur, 2)              # r
        for _ in range(3):
            cur = self.delete(cur, 3)        # deletes the old i, the old a, and the duplicate r
        self.link(cur, loop)                 # back to the head of the loop
        return end
    if isinstance(f, Mu):                    # mu[g]; stack: x1..xn
        n, cur = f.arity(), self.push(e, 0)  # z := 0
        loop = cur
        for _ in range(n + 1):
            cur = self.copy(cur, n + 1)      # copies of x1..xn, z
        cur = self.compile(cur, f.g)         # r := g(x, z)
        for _ in range(n + 1):
            cur = self.delete(cur, 2)
        yes, no = self.zero(cur, 1)
        end = self.delete(yes, 1)            # r = 0: z is the result
        again = self.incr(self.delete(no, 1))   # otherwise z := z + 1
        self.link(again, loop)
        return end
    raise TypeError("unknown term: %r" % (f,))

def compile(f, rename=True):
    """Turing machine Z_f, in the format of chapter 3: Psi_{Z_f} = f.

    The machine goes to E, pushes f(x), deletes the n arguments, and removes one stroke from the result
    (f(x) strokes then remain, the output convention)."""
    a = Assembler()
    e = a.go_to_E("q0")
    e = a.compile(e, f)
    for _ in range(f.arity()):
        e = a.delete(e, 2)
    t, u, x = a.fresh("last"), a.fresh("last"), a.fresh("last")
    a.q(e, B, "L", t)
    a.q(t, B, "L", u)
    a.q(u, I, B, x)
    quads = a.quads
    if rename:                                   # q0, q1, q2... in order of appearance
        names = {"q0": "q0"}
        for qd in quads:
            for s in (qd[0], qd[3]):
                if s not in names:
                    names[s] = "q%d" % len(names)
        quads = [(names[a_], s, act, names[b_]) for a_, s, act, b_ in quads]
    return Machine(quads)

The quotient uses the remainder inside a loop, which uses equality, which uses two subtractions… and each occurrence is copied. #!/usr/bin/env python3
"""Compiler: recursive functions -> Turing machines (chapter "Equivalence" of the manual).

The program follows the proof of the theorem "every recursive function is Turing-computable"
to the letter. We fix a STACK DISCIPLINE:
  - the tape holds blocks of strokes separated by ONE blank: 1^{a1+1} B 1^{a2+1} B ... B 1^{ar+1};
  - E denotes the cell two cells after the last stroke (where a new block would begin).
A machine PUSHES f if, started at E on a tape whose last n blocks code x1..xn,
it comes back to E with one more block, which codes f(x1..xn), without touching the earlier blocks
(and never comes back if f(x) is undefined).

We build, by induction on the term, a machine that pushes f, out of auxiliary machines
(the "macros"): go_to_E, go_to_block, push, copy, shift, delete, incr, decr, zero.
Each macro receives the state where it begins and returns the state where it ends; chaining two macros
means giving the exit state of the first as the entry state of the second.

Usage:
    python3 compiler.py add 2 3                    compiles, runs, compares with the evaluation
    python3 compiler.py "rho[C(0,1), sigma[mult, sigma[S, A(2,1)], A(2,2)]]" 3
    python3 compiler.py mult 2 3 --output mult.tm  writes the machine to a file
    python3 compiler.py mult --output mult.tm      compiles only
    python3 machines.py mult.tm 2 3                then runs it, independently

MIT licence. Frédéric Prost and Claude.
"""
import sys

from machines import Machine, BLANK as B, STROKE as I
from recursive import Const, Succ, Proj, Comp, Rec, Mu, Named, read_term, evaluate, Diverges, unfold

X = "X"                    # auxiliary mark used by the copy
SYMBOLS = (B, I, X)


class Assembler:
    """Accumulates quadruples and makes up fresh state names."""

    def __init__(self, comment=False):
        self.quads = []
        self.n = 0
        self.comment = comment

    def fresh(self, prefix="s"):
        self.n += 1
        return "%s%d" % (prefix, self.n)

    def q(self, state, read, action, following):
        self.quads.append((state, read, action, following))

    def link(self, a, b):
        """Go from state a to state b without changing anything: a s s b for each symbol s."""
        for s in SYMBOLS:
            self.q(a, s, s, b)

    # ------------------------------------------------------------ moves
    def go_to_E(self, e):
        """End: from a cell of the content (stroke, X or separator), go to E.
        We move right until two consecutive blanks are found; the head stops on the second."""
        b, s = self.fresh("end"), self.fresh("end")
        self.q(e, I, "R", e)
        self.q(e, X, "R", e)
        self.q(e, B, "R", b)
        self.q(b, I, "R", e)
        self.q(b, X, "R", e)
        self.q(b, B, B, s)
        return s

    def go_to_block(self, e, j):
        """Block_j: from E, go to the first stroke of the j-th block counted from the end."""
        c = self.fresh("block")
        self.q(e, B, "L", c)                    # on the separator after the last block
        for t in range(1, j + 1):
            l = self.fresh("block")
            self.q(c, B, "L", l)                # on the last stroke of the block
            self.q(l, I, "L", l)                # we go back up the block
            if t < j:
                c = self.fresh("block")
                self.q(l, B, B, c)              # separator: next block (to the left)
            else:
                s = self.fresh("block")
                self.q(l, B, "R", s)            # we come back to the first stroke
                return s

    # ------------------------------------------------------------ stack operations
    def push(self, e, m):
        """Push_m: write m+1 strokes from E on, then go to the new E."""
        cur = e
        for _ in range(m + 1):
            w, nx = self.fresh("push"), self.fresh("push")
            self.q(cur, B, I, w)
            self.q(w, I, "R", nx)
            cur = nx
        s = self.fresh("push")
        self.q(cur, B, "R", s)
        return s

    def copy(self, e, j):
        """Copy_j: push a copy of the j-th block from the end.
        For each stroke of the source: replace it with X, go to the end, write a stroke there,
        come back to the X, put the stroke back, move on to the next stroke."""
        s = self.go_to_block(e, j)
        c1 = self.fresh("copy")
        self.q(s, I, X, c1)                      # first stroke marked
        e1 = self.go_to_E(c1)
        r = self.fresh("copy")
        self.q(e1, B, I, r)                      # first stroke of the copy, written at E
        self.q(r, I, "L", r)                     # back towards the mark
        self.q(r, B, "L", r)
        r1, r2 = self.fresh("copy"), self.fresh("copy")
        self.q(r, X, I, r1)                      # restore the marked stroke
        self.q(r1, I, "R", r2)                   # next stroke of the source
        d = self.fresh("copy")
        self.q(r2, I, X, d)                      # one more stroke: mark it
        e2 = self.go_to_E(d)                     # E is two cells after the copy in progress
        e3 = self.fresh("copy")
        self.q(e2, B, "L", e3)                   # we step back one cell to extend the copy
        self.q(e3, B, I, r)
        f = self.fresh("copy")
        self.q(r2, B, B, f)                      # end of the source
        return self.go_to_E(f)

    def shift(self, g, k):
        """Shift_k: the head is on a hole (two blanks) followed by k blocks;
        shift these k blocks one cell to the left (the hole is filled)."""
        cur = g
        for _ in range(k):
            a, b, c, d = self.fresh("shift"), self.fresh("shift"), self.fresh("shift"), self.fresh("shift")
            self.q(cur, B, "R", a)
            self.q(a, B, I, b)                   # write a stroke in the hole
            self.q(b, I, "R", b)                 # cross the block
            self.q(b, B, "L", c)
            self.q(c, I, B, d)                   # erase its last stroke: it has moved back one cell
            cur = d
        s = self.fresh("shift")
        self.q(cur, B, "R", s)
        return s

    def decr(self, e, j):
        """Decr_j: remove one stroke from the j-th block (which codes an integer > 0)."""
        s = self.go_to_block(e, j)
        p = self.fresh("decr")
        self.link(s, p)
        self.q(p, I, "R", p)                     # go to the last stroke of the block
        p2, z = self.fresh("decr"), self.fresh("decr")
        self.q(p, B, "L", p2)
        self.q(p2, I, B, z)                      # erase it: a hole of two blanks appears
        return self.shift(z, j - 1)              # glue back the j-1 blocks that follow

    def delete(self, e, j):
        """Delete_j: delete the j-th block from the end, stroke by stroke, gluing back what follows."""
        loop = e
        s = self.go_to_block(loop, j)
        p = self.fresh("del")
        self.link(s, p)
        self.q(p, I, "R", p)
        p2, z = self.fresh("del"), self.fresh("del")
        self.q(p, B, "L", p2)
        self.q(p2, I, B, z)                      # erase the last stroke of the block
        p4 = self.fresh("del")
        self.q(z, B, "L", p4)                    # is there a stroke left to the left?
        z2 = self.fresh("del")
        self.q(p4, I, "R", z2)                   # yes: come back, glue back what follows, start again
        back = self.shift(z2, j - 1)
        self.link(back, loop)
        w = self.fresh("del")
        self.q(p4, B, B, w)                      # no: the block is empty, a hole remains
        if j == 1:
            s1 = self.fresh("del")
            self.q(w, B, "R", s1)
            return s1
        z3 = self.fresh("del")
        self.q(w, B, "R", z3)
        e1 = self.shift(z3, j - 1)               # first shift
        s2 = self.go_to_block(e1, j - 1)         # beginning of the block after the hole
        g1, g = self.fresh("del"), self.fresh("del")
        self.q(s2, I, "L", g1)
        self.q(g1, B, "L", g)
        return self.shift(g, j - 1)              # second shift: the extra separator disappears

    def incr(self, e):
        """Incr: add one stroke to the last block."""
        t, u, v, s = self.fresh("inc"), self.fresh("inc"), self.fresh("inc"), self.fresh("inc")
        self.q(e, B, "L", t)
        self.q(t, B, I, u)
        self.q(u, I, "R", v)
        self.q(v, B, "R", s)
        return s

    def zero(self, e, j):
        """Zero?_j: returns (state if the j-th block codes 0, state otherwise), both at E."""
        s = self.go_to_block(e, j)
        a, z, nz = self.fresh("zero"), self.fresh("zero"), self.fresh("zero")
        self.q(s, I, "R", a)
        self.q(a, B, B, z)                       # a single stroke: the block codes 0
        self.q(a, I, I, nz)
        return self.go_to_E(z), self.go_to_E(nz)

    # ------------------------------------------------------------ the compilation itself
    def compile(self, e, f):
        """Machine that pushes f, starting in e; returns its exit state."""
        while isinstance(f, Named):
            f = f.term
        if isinstance(f, Const):                 # m^(k): Push_m
            return self.push(e, f.m)
        if isinstance(f, Succ):                  # S: Copy_1 then Incr
            return self.incr(self.copy(e, 1))
        if isinstance(f, Proj):                  # A^(k)_i: Copy_{k-i+1}
            return self.copy(e, f.k - f.i + 1)
        if isinstance(f, Comp):                  # sigma[g, h1..hk]
            m, k, cur = f.arity(), len(f.hs), e
            for j, h in enumerate(f.hs, start=1):
                for _ in range(m):               # copy of the m arguments (y1..y_{j-1} are above)
                    cur = self.copy(cur, m + j - 1)
                cur = self.compile(cur, h)       # pushes y_j = h_j(x)
                for _ in range(m):               # deletes the copies, below y_j
                    cur = self.delete(cur, 2)
            cur = self.compile(cur, f.g)         # pushes g(y1..yk)
            for _ in range(k):
                cur = self.delete(cur, 2)        # deletes y1..yk
            return cur
        if isinstance(f, Rec):                   # rho[g, h]; stack: y, x2..xk
            kk, cur = f.arity(), e
            cur = self.copy(cur, kk)             # c := y
            cur = self.push(cur, 0)              # i := 0
            for _ in range(kk - 1):
                cur = self.copy(cur, kk + 1)     # copies of x2..xk
            cur = self.compile(cur, f.g)         # a := g(x)
            for _ in range(kk - 1):
                cur = self.delete(cur, 2)
            loop = cur                           # stack: ..., c, i, a
            done, go_on = self.zero(loop, 3)
            end = self.delete(self.delete(done, 3), 2)   # c = 0: a remains
            cur = self.decr(go_on, 3)            # c := c - 1
            cur = self.copy(cur, 2)              # i
            cur = self.copy(cur, 2)              # a
            for _ in range(kk - 1):
                cur = self.copy(cur, kk + 4)     # x2..xk
            cur = self.compile(cur, f.h)         # r := h(i, a, x)
            for _ in range(kk + 1):
                cur = self.delete(cur, 2)        # deletes the copies
            cur = self.copy(cur, 3)              # i
            cur = self.incr(cur)                 # i + 1
            cur = self.copy(cur, 2)              # r
            for _ in range(3):
                cur = self.delete(cur, 3)        # deletes the old i, the old a, and the duplicate r
            self.link(cur, loop)                 # back to the head of the loop
            return end
        if isinstance(f, Mu):                    # mu[g]; stack: x1..xn
            n, cur = f.arity(), self.push(e, 0)  # z := 0
            loop = cur
            for _ in range(n + 1):
                cur = self.copy(cur, n + 1)      # copies of x1..xn, z
            cur = self.compile(cur, f.g)         # r := g(x, z)
            for _ in range(n + 1):
                cur = self.delete(cur, 2)
            yes, no = self.zero(cur, 1)
            end = self.delete(yes, 1)            # r = 0: z is the result
            again = self.incr(self.delete(no, 1))   # otherwise z := z + 1
            self.link(again, loop)
            return end
        raise TypeError("unknown term: %r" % (f,))

    """Turing machine Z_f, in the format of chapter 3: Psi_{Z_f} = f.

    The machine goes to E, pushes f(x), deletes the n arguments, and removes one stroke from the result

Definition
Regular machines (Boitet’s lecture notes)

A machine $Z$ is called $n$-regular if, starting from $q_0\,\overline{(x_1,\dots,x_n)}$, it halts (when it halts) in a configuration $q_{r(Z)}\,\overline{(y_1,\dots,y_s)}$, where $q_{r(Z)}$ is its state of largest index and begins no quadruple: the head is on the first bar of the result, and the tape contains nothing but the result, written according to the input convention.

We write $Z^{(k)}$ for the machine obtained by replacing each $q_i$ by $q_{i+k}$ (translation of states); two machines translated far enough apart have no state in common, and $Z_1$ then $Z_2$ are chained by identifying the final state of $Z_1$ with the initial state of $Z_2$.

In plain words. A “regular” machine is a machine that tidies its tape before halting: it leaves its result neatly in place, with no traces of scratch work.

To chain two machines, the second must find the data where it expects them. An arbitrary machine leaves a messy tape when it halts. A regular machine is a “well-behaved” machine, which tidies up before handing over.

Theorem
Normalization of a machine, with parameters

For every machine $Z$ and every $m\ge 1$, one can build a machine $N_m(Z)$ such that, for every tape of the form $w\,B\,\overline{x_1}\,B\cdots B\,\overline{x_m}$, where $w$ is a (possibly empty) sequence of blocks separated by a blank, with the head at $E$ (two cells after the last bar):

  • if $\Psi^{(m)}_Z(\vec x)$ is undefined, $N_m(Z)$ does not halt;
  • if $\Psi^{(m)}_Z(\vec x)=y$, $N_m(Z)$ halts, in a state that begins no quadruple, on the tape $w\,B\,\overline y$ (up to a translation), with the head at $E$.

The blocks of $w$ are parameters: they are kept intact. In particular, the machine $Z'=\mathsf{End}\,;\,N_n(Z)\,;\,\mathsf{Start}$ is $n$-regular and $\mathrm{Res}_{Z'}(q_0\,\overline{\vec x})=q_{r(Z')}\,\overline{\Psi^{(n)}_Z(\vec x)}$, both sides being defined or not at the same time.

In plain words. Any machine can be transformed into a regular machine, which computes the same thing and tidies its tape.

A machine found elsewhere, written without any discipline, can therefore be used as a piece of a larger assembly: it is surrounded by a “wrapper” that protects the rest of the tape and cleans up after it. Computer scientists call this isolating a module.

Choose two symbols $\lambda,\rho$ that do not appear in $Z$. The macro $\mathsf{End}$ (go to $E$) is that of the compiler; $\mathsf{Start}$ goes from $E$ to the first bar: $e\,B\,L\,v$, $v\,B\,L\,u$, $u\,|\,L\,u$, $u\,B\,L\,u'$, $u'\,|\,L\,u$, $u'\,B\,R\,u''$, $u''\,B\,R\,f$. $N_m(Z)$ is the union of four machines, with pairwise distinct states.

$Z_1$: placing the markers. From $E$: $e\,B\,L\,a$, $a\,B\,\rho\,a$, $a\,\rho\,L\,b_1$ ($\rho$ is placed just after the last bar); then, for $k=1,\dots,m$: $b_k\,|\,L\,b_k$ and, for $k<m$, $b_k\,B\,L\,b_{k+1}$ (go back over $m$ blocks); finally $b_m\,B\,\lambda\,c$ and $c\,\lambda\,R\,z_0$, where $z_0$ is the initial state of (the translated copy of) $Z$. The tape is then $w\,\lambda\,\overline{x_1}B\cdots B\overline{x_m}\,\rho$, with the head on the first bar of $\overline{x_1}$: $\lambda$ occupies the separating cell between $w$ and the arguments.

$Z_2$: simulating $Z$ between the markers. $Z_2$ contains the quadruples of $Z$ (translated) and, for each state $q$ of $Z$, two small overflow machines that end in $q$, with the head where it was, on a blank:

  • on $\rho$: $q\,\rho\,B\,q_1$, $q_1\,B\,R\,q_2$, $q_2\,B\,\rho\,q_3$, $q_3\,\rho\,L\,q_4$, $q_4\,B\,B\,q$: the marker advances one cell and leaves a blank in its place;
  • on $\lambda$: everything to the left of $\lambda$ (the parameters $w$) must move back one cell. Go to the left end of $w$, recognized by the first double blank: $q\,\lambda\,\lambda\,g$, $g\,\lambda\,L\,g_1$, $g_1\,|\,L\,g_1$, $g_1\,B\,L\,g_2$, $g_2\,|\,L\,g_1$, $g_2\,B\,R\,g_3$, $g_3\,B\,R\,s$; then move each cell one step to the left, from left to right: $s\,|\,B\,s_1$, $s_1\,B\,L\,s_2$, $s_2\,B\,|\,s_3$, $s_3\,|\,R\,s_4$, $s_4\,B\,R\,s$, $s\,B\,R\,s$; on reaching $\lambda$: $s\,\lambda\,B\,t_1$, $t_1\,B\,L\,t_2$, $t_2\,B\,\lambda\,t_3$, $t_3\,\lambda\,R\,t_4$, $t_4\,B\,B\,q$.

(The states $q_1,\dots,g,\dots,t_4$ are specific to each $q$: a Turing machine cannot “return” to a remembered state, so one copy of these quadruples per state is needed.) We have the invariant: at every moment when $Z_2$ is in a state of $Z$, the tape is $w\,\lambda\,\beta\,\rho$, where the word $\beta$ contains all the non-blank cells of the simulated tape of $Z$, with the head at the same place relative to $\beta$. It holds at the start; a quadruple of $Z$ preserves it as long as the head does not read a marker; when it reads one, the overflow machine restores it by inserting a blank where $Z$ would have read a blank. So $Z_2$ simulates $Z$ step by step, and $Z$ halts reading $S$ in state $q$ if and only if $Z_2$ reaches $q$ on $S\ne\lambda,\rho$ with no applicable quadruple.

$Z_3$: signalling the halt. For each pair $(q,S)$ that begins no quadruple of $Z$ ($S$ a symbol of $Z$), add $q\,S\,S\,q_L$, with a common new state $q_L$.

$Z_4$: tidying up. We must now gather the bars of $\beta$, erase everything else and the markers, and add one bar (the output counts $y$ bars, the input requires $y+1$). Writing $\overline S$ for any symbol other than $|,\lambda,\rho$:

  • back to $\lambda$: $q_L\,S\,L\,q_L$ ($S\ne\lambda$), $q_L\,\lambda\,R\,A$;
  • packing: $A\,|\,R\,A$ (move along the already packed block), $A\,\overline S\,\overline S\,F$; $F\,\overline S\,R\,F$ (look for the next bar), $F\,|\,B\,G$ (erase it); $G\,\overline S\,L\,G$, $G\,|\,R\,H$, $G\,\lambda\,R\,H$ (come back after the packed block), $H\,\overline S\,|\,A$ (write the bar there);
  • end: $A\,\rho\,\rho\,C$, $F\,\rho\,\rho\,C$; $C\,\rho\,B\,C_2$; $C_2\,B\,L\,C_2$, $C_2\,\overline S\,B\,C_2$ (erase the auxiliary symbols); $C_2\,|\,R\,C_3$, $C_2\,\lambda\,R\,C_3$; $C_3\,B\,|\,C_4$ (the extra bar); $C_4\,|\,L\,C_4$, $C_4\,\lambda\,B\,C_5$ (the cell of $\lambda$ becomes the separator again); $C_5\,B\,R\,C_6$, then $\mathsf{End}$ from $C_6$.

On leaving the packing loop, the $y=\Psi^{(m)}_Z(\vec x)$ bars of $\beta$ form a block adjacent to $\lambda$, followed by nothing but blanks and auxiliary symbols up to $\rho$. The final sweep erases these and $\rho$, and adds a bar: the tape is $w\,B\,1^{y+1}=w\,B\,\overline y$. If $Z$ does not halt, neither does $Z_2$, and $q_L$ is never reached.

Nesting. When $N_m(Z)$ is itself run inside another normalization (as in the assemblies below), the tape also carries the markers $\lambda',\rho'$ of the outer levels. We take different symbols at each level, and the overflow machines treat them as ordinary cells: when moving $w$ back, the $\lambda'$ it contains are moved back too; when advancing $\rho$, if the next cell carries an outer marker $\rho'$, it is pushed one cell in turn (and so on). The invariants of the outer levels are preserved.

The construction has been programmed and run: machines_regulieres.py builds $N_m(Z)$ quadruple by quadruple and simulates it. To test it, it is applied to three deliberately “dirty” machines, which are not regular:

  • $Z_a$ ($1$ argument) moves two cells to the left of its input to write a bar there, then goes right, writes an $X$ and a bar beyond: $\Psi_{Z_a}(x)=x+3$;
  • $Z_b$ writes three cells to the left (two bars and an $X$): $\Psi_{Z_b}(x)=x+3$, and overflows $\lambda$ at each run;
  • $Z_c$ ($2$ arguments) replaces the separator by $X$, writes a bar two cells to the right then another three cells to the left: $\Psi_{Z_c}(x,y)=x+y+4$, with overflows on both sides.

For each of them, $Z'=\mathsf{End}\,;N_n(Z)\,;\mathsf{Start}$ is checked to be $n$-regular (final state with no quadruple, head on the first bar, tape equal to $\overline{\Psi_Z(\vec x)}$) for all arguments $\le3$. The machines $N_m$ are also tested with parameters and nested on two levels (below). Typical size: $Z_c$ has 14 quadruples, and the complete composition $Z_c(A^{(2)}_2,A^{(2)}_1)$, normalization included, has 1,612.

Theorem
Composition, primitive recursion and minimization of regular machines

If $g,h_1,\dots,h_k$ (resp. $g,h$) are computed by machines, one explicitly builds machines for $\sigma[g,h_1,\dots,h_k]$, for the function defined by primitive recursion from $g$ and $h$, and for $\mu y\,[g(\vec x,y)=0]$. Consequently every (partial) recursive function is computed by a regular machine.

In plain words. Regular machines can be assembled according to the three recipes (chain, repeat, search), and the result is again a regular machine.

Once we know how to tidy up, a machine becomes an instruction that can be called like a function in a program. All the constructions of recursive functions are then recovered.

We work on a stack of blocks, with the head at $E$, using the macros $\mathsf{Copy}_j$, $\mathsf{Delete}_j$, $\mathsf{Push}_m$, $\mathsf{Incr}$, $\mathsf{Decr}_j$, $\mathsf{Zero?}_j$ of the compiler; $\mathsf{Keep}$ deletes all blocks except the last. For a machine $Z_f$ of $f$ of arity $m$, we write $\llbracket f\rrbracket=N_m(Z_f)$: applied to a stack $w,\vec x$, it gives $w,f(\vec x)$. If a program $P$ transforms the stack $\vec x$ into a stack whose last block is $\overline{f(\vec x)}$, then $\mathsf{End}\,;\,P\,;\,\mathsf{Keep}\,;\,\mathsf{Decr}_1$, started in $q_0$ on the first bar of $\overline{\vec x}$, leaves $f(\vec x)$ bars: it is a machine $Z_f$ of $f$ in the sense of $\Psi$, to which $N$ can be applied again.

  • Composition $f=\sigma[g,h_1,\dots,h_k]$, $f$ of arity $n$: for $i=1,\dots,k$, $n$ times $\mathsf{Copy}_{n+i-1}$ then $\llbracket h_i\rrbracket$; the stack is $\vec x,h_1(\vec x),\dots,h_k(\vec x)$. Then $k$ times $\mathsf{Copy}_k$ and $\llbracket g\rrbracket$. If one of the $h_i(\vec x)$ is undefined, $\llbracket h_i\rrbracket$ does not terminate.
  • Primitive recursion $f(\vec x,0)=g(\vec x)$, $f(\vec x,y+1)=h(\vec x,y,f(\vec x,y))$: push a counter $i=0$ then $g(\vec x)$ (copy of $\vec x$ and $\llbracket g\rrbracket$): stack $\vec x,y,i,v$ with $v=f(\vec x,i)$. Loop: if $\mathsf{Zero?}_3$ (that is, the remaining $y$ is zero), exit; otherwise push $\vec x,i,v$ and apply $\llbracket h\rrbracket$, which gives $\vec x,y,i,v,f(\vec x,i+1)$; then push $\vec x,y-1,i+1,f(\vec x,i+1)$ by copies, $\mathsf{Decr}$ and $\mathsf{Incr}$, and start again; the old blocks remain underneath, and $\mathsf{Keep}$ will erase them at the end. On exit the last block is $f(\vec x,y)$. (The case $n=0$, where $g$ is a constant, replaces the call to $g$ by $\mathsf{Push}_c$.)
  • Minimization $f(\vec x)=\mu y\,[g(\vec x,y)=0]$: push $y=0$. Loop: copy $\vec x,y$, apply $\llbracket g\rrbracket$, test $\mathsf{Zero?}_1$; if yes, delete the value and exit with $\mathsf{Keep}$ (what remains is $\overline y$); otherwise delete the value, $\mathsf{Incr}$, and start again. If $g(\vec x,y)$ is undefined for a $y$ tested before the first zero, or if there is no zero, the machine does not halt: this is exactly the semantics of $\mu$.

The base functions (successor: the empty machine; projections: $\mathsf{Copy}$; constants: $\mathsf{Push}$) are handled directly. By induction on the definition of a recursive function, we obtain a machine $P_f$; $\mathsf{End}\,;P_f\,;\mathsf{Keep}\,;\mathsf{Start}$ is $n$-regular and computes $\overline{f(\vec x)}$. Each call $\llbracket\cdot\rrbracket$ is a normalization, with its own markers, inside those of the enclosing levels: this is the nesting case treated above.

The difference with the compiler: there, each submachine is built clean by induction, and markers are never needed; here, any machine can be called, even one that was not written with the stack discipline. This is what the lecture notes require, and it is stronger: a machine found elsewhere, for example a universal machine, can be plugged into an assembly.

Turing-computable functions are recursive

In the other direction, the working of a machine must be described by a formula. The idea is to code each “snapshot” of the machine by a number, then to write a formula that computes the next snapshot from the previous one. A single search then suffices: look for the first moment at which the machine has halted. This is where an idea that would change the world appears: a machine can be described by a number, and therefore read and run by another machine.

This inclusion is the most important one conceptually: to simulate a machine by a function, one must code the machine itself by an integer. This is where the idea of a universal function, that is, of the computer, is born: programs and data are of the same nature, and there is no need to modify a machine physically to change what it computes.

Definition
Gödel numbers of machines and computations

The symbols of the model are coded by odd integers:

symbol$R$$L$$S_i$$q_i$
code $\gamma$35$4i+9$$4i+7$

Thus $\gamma(q_0)=7$, $\gamma(B)=\gamma(S_0)=9$, $\gamma(q_1)=11$, $\gamma(1)=\gamma(S_1)=13$. An instantaneous description or a quadruple is a word, coded by $\mathrm{gn}(a_1\cdots a_n)=\prod_k p_k^{\gamma(a_k)}$; a machine $P_Z=\{M_1,\dots,M_n\}$ is a sequence of quadruples, and its Gödel numbers are the $\prod_k p_k^{\mathrm{gn}(M_{\pi(k)})}$ for all permutations $\pi$; a computation $\alpha_1,\dots,\alpha_p$ is coded by $\prod_k p_k^{\mathrm{gn}(\alpha_k)}$.

In plain words. We give a number to each sign (states, symbols, moves), then code a sequence of signs by a single number, thanks to prime numbers. A rule, a whole machine, a snapshot of the machine, a complete computation each become a number in this way.

These numbers are gigantic (the code of the smallest machine has billions of billions of digits), and nobody computes them. What matters is the principle: a machine is a number, and therefore a piece of data like any other. A program can read another program. This is the idea of the stored-program computer, in which software is only a sequence of numbers stored in memory.

This numbering is that of F. Prost’s course (Introduction à la calculabilité, 2026). M. Davis and Ch. Boitet’s lecture notes swap the roles of states and symbols ($\gamma(S_i)=4i+7$, $\gamma(q_i)=4i+9$); both conventions work, provided the predicates $\mathrm{State}$ and $\mathrm{Symb}$ are adapted. The codes of $R$ and $L$ are the only odd numbers below 7, and states and symbols share the following odd numbers according to their remainder modulo 4: the nature of a letter can be recognized from its code. Examples: $\mathrm{gn}(q_0\,|\,R\,q_1)=2^7\,3^{13}\,5^3\,7^{11}$, and a machine with two quadruples $\{M_1,M_2\}$ has two Gödel numbers, $2^{\mathrm{gn}(M_1)}3^{\mathrm{gn}(M_2)}$ and $2^{\mathrm{gn}(M_2)}3^{\mathrm{gn}(M_1)}$. The code of a word has an odd exponent of 2 (the code of a letter), the code of a sequence of words an even exponent of 2 (the code of a word): the two are never confused.

The successor machine, $\{q_0\,B\,B\,q_0\}$, has a single quadruple, with code $2^{7}\cdot3^{9}\cdot5^{9}\cdot7^{7}=4{,}052{,}449{,}217{,}250{,}000{,}000$. The machine has Gödel number $2^{4{,}052{,}449{,}217{,}250{,}000{,}000}$, an integer with about $1.22\times10^{18}$ digits. The identity machine, $Z_{\mathrm{id}}=\{q_0\,|\,B\,q_1\}$ (it erases a bar: $x+1$ bars become $x$), has Gödel number $2^{2^7\,3^{13}\,5^{9}\,7^{11}}$. These numbers are never computed; only the primitive recursive functions that decompose them are manipulated.

Theorem
Kleene normal form

For every $n$, there are a primitive recursive predicate $T_n(z,x_1,\dots,x_n,y)$ and a primitive recursive function $U(y)$ such that, for every machine $Z$ and every Gödel number $z$ of $Z$:

$$\Psi^{(n)}_Z(x_1,\dots,x_n)\simeq U\big(\mu y\ T_n(z,x_1,\dots,x_n,y)\big).$$

$T_n(z,\vec x,y)$ (Kleene’s predicate) expresses: “$z$ codes a machine $Z$ and $y$ codes a complete computation of $Z$ starting from $q_0\overline{x_1}B\cdots B\overline{x_n}$”; $U(y)$ is the number of bars of the last description of the computation coded by $y$. In particular every Turing-computable function is recursive, and is obtained with a single minimization.

In plain words. Every function computed by a Turing machine can be written with the bricks and recipes of recursive functions, using the recipe “search until found” only once.

Every computation, however long, comes down to a single search: look for the first moment at which the machine halts. Checking that a sequence of snapshots is a correct computation is easy: each passage from one picture to the next is checked, a loop whose length is known. It is finding this sequence that can take unlimited time. The whole difficulty of computation is concentrated in this one search.

The theorem also contains, in germ, the computer: the formula obtained depends on the machine only through its number. A single formula therefore simulates all machines (see Universality).

We build a sequence of primitive recursive functions and predicates (each uses the previous ones and the library; all quantifiers are bounded by the argument, since the components of a code are smaller than it):

  1. $(x)_k$: exponent of $p_k$ in $x$; $\ \ell(x)$: length, the largest $k\le x$ such that $(x)_k>0$.
  2. $\mathrm{GN}(x)$: $x>1$ and $x=\prod_{k\le\ell(x)}p_k^{(x)_k}$ with all $(x)_k>0$ for $k\le\ell(x)$ (no gap).
  3. $x*y$: code of the concatenation, $x\cdot\prod_{i=1}^{\ell(y)}p_{\ell(x)+i}^{(y)_i}$.
  4. $\mathrm{State}(x)\iff\exists i\le x\ (x=4i+7)$; $\ \mathrm{Symb}(x)\iff\exists i\le x\ (x=4i+9)$.
  5. $\mathrm{Quad}(x)$: $\mathrm{GN}(x)$, $\ell(x)=4$, $\mathrm{State}((x)_1)$, $\mathrm{Symb}((x)_2)$, $(x)_3\in\{3,5\}$ or $\mathrm{Symb}((x)_3)$, $\mathrm{State}((x)_4)$.
  6. $\mathrm{TM}(z)$: $\mathrm{GN}(z)$, each $(z)_k$ satisfies $\mathrm{Quad}$, and two distinct components do not begin with the same pair (consistency).
  7. $\mathrm{ID}(x)$: $x$ codes an instantaneous description, that is, a word containing exactly one state, which is not the last letter.
  8. $\mathrm{Init}_n(\vec x)=2^{7}*\mathrm{CB}(x_1)*2^{9}*\mathrm{CB}(x_2)*\cdots*2^9*\mathrm{CB}(x_n)$, where $\mathrm{CB}(x)$ codes $1^{x+1}$: $\mathrm{CB}(0)=2^{13}$, $\mathrm{CB}(x+1)=\mathrm{CB}(x)*2^{13}$.
  9. $\mathrm{Step}(x,y,z)$: $\mathrm{ID}(x)$, $\mathrm{ID}(y)$, $\mathrm{TM}(z)$ and $\alpha\vdash_Z\beta$, where $x,y,z$ code $\alpha,\beta,Z$. This is a disjunction of five cases (writing; move to the right, with or without adding a blank; to the left, with or without adding a blank), each of the form “there are splittings $x=g*2^{r}*3^{s}*d$… bounded by $x$, and a quadruple of $z$ of the right form”.
  10. $\mathrm{Final}(x,z)$: $\mathrm{ID}(x)$ and no quadruple of $z$ begins with the state and the scanned symbol of $x$.
  11. $\mathrm{Comp}(y,z)$: $\mathrm{GN}(y)$, $\mathrm{Step}((y)_k,(y)_{k+1},z)$ for every $k<\ell(y)$, and $\mathrm{Final}((y)_{\ell(y)},z)$.
  12. $T_n(z,\vec x,y)\iff \mathrm{TM}(z)\wedge\mathrm{Comp}(y,z)\wedge (y)_1=\mathrm{Init}_n(\vec x)$.
  13. $U(y)$: number of $k\le\ell(w)$ such that $(w)_k=13$ (the code of the bar), where $w=(y)_{\ell(y)}$.

If $\Psi^{(n)}_Z(\vec x)\conv$, there is a unique computation starting from $\mathrm{Init}_n(\vec x)$; its code $y$ is the only one satisfying $T_n$, and $U(y)$ reads off the result. Otherwise no $y$ satisfies $T_n$ and the minimization diverges.

The predicate $T_n$ is a checker: given a candidate, it mechanically checks each transition. In programming terms, this is the difference between running a program (we do not know how long it will take) and checking the trace of a run (the time is bounded by the length of the trace). The Turing machine simulator produces exactly such traces (“Successive instantaneous descriptions”); $T_n$ checks that a trace is coherent, and $U$ counts the bars of its last line.

Pseudo-code of $\mathrm{Comp}(y,z)$, made entirely of bounded loops:

Comp(y, z):
  if not GN(y): false
  for k from 1 to ℓ(y) - 1:
      if not Step((y)_k, (y)_{k+1}, z): false
  return Final((y)_{ℓ(y)}, z)
Technological workshop — the translation from machine to recursive function, in Python

The file turing_to_recursive.py builds, for a given machine $Z$, a term $f_Z$ made only of $C$, $S$, $A$, $\sigma$, $\rho$ and a single $\mu$, and checks that $f_Z=\Psi_Z$. It follows the proof above, with one difference of coding: instead of prime powers (whose values, as we saw, have billions of digits), it codes a configuration by three integers of reasonable size. Both codings work; what matters is that each stage be primitive recursive.

The coding

  • The symbols are numbered $0$ ($=B$), $1$ ($=$ stroke), $2,\dots$; $b$ is their number. The states are numbered $0$ ($=q_0$), $1,\dots$
  • $d$ codes the right part of the tape, from the scanned cell on, in base $b$, the scanned cell being the units digit; $g$ codes the left part, the cell just left of the head being the units digit.
  • The configuration is the number $c=\langle g,\langle i,d\rangle\rangle$ (Cantor pairs).

With this coding, the three actions are elementary arithmetic. The scanned symbol is $d \bmod b$. Writing the symbol $a$ in place of $s$: $d\mapsto (d\monus s)+a$. Moving right: $g\mapsto g\,b+(d\bmod b)$, $d\mapsto d\ \mathrm{div}\ b$. Moving left: $g\mapsto g\ \mathrm{div}\ b$, $d\mapsto d\,b+(g\bmod b)$. A tape blank to infinity corresponds to zero digits beyond the significant digits: moving left at the edge means reading a 0, that is, a blank.

#!/usr/bin/env python3
"""Translation: Turing machine -> recursive function (chapter "Equivalence", converse direction).

For a given machine Z, we build EXPLICITLY a term f_Z, made only of constants,
successor, projections, substitution, primitive recursion and ONE minimization, such that
f_Z(x1..xn) = Psi_Z(x1..xn) (same domain of definition). This is Kleene's normal form,
with a more economical coding than the prime-power coding of the manual
(both work: what matters is that each stage be primitive recursive).

Coding a configuration (tape, position, state) by ONE integer:
  - the symbols are numbered 0 (= B), 1 (= stroke), 2, ...; b is the number of symbols;
  - d codes the right part of the tape, from the scanned cell on, in base b, the scanned cell being
    the units digit: d = s0 + s1·b + s2·b² + ...
  - g codes the left part, the cell just left of the head being the units digit;
  - the state q_i is coded by its number i;
  - the configuration is the Cantor pair <g, <i, d>>.
A tape carries only finitely many non-blank symbols: g and d are integers.

The functions built (all primitive recursive except the last one):
  scanned(c)     = d mod b                      scanned symbol
  step(c)        = next configuration (c itself if no quadruple applies)
  halt(c)        = 1 if no quadruple applies, 0 otherwise
  iter(t, c)     = step applied t times to c    (primitive recursion on t)
  init(x1..xn)   = initial configuration q0 1^{x1+1} B ... B 1^{xn+1}
  strokes(t, c)  = number of strokes on the tape coded by c (reading at most L digits)
  time(x)        = mu t [ halt(iter(t, init(x))) = 1 ]      the only minimization
  f_Z(x)         = strokes(time(x), iter(time(x), init(x)))

Usage:
    python3 turing_to_recursive.py file.tm 2 3      builds f_Z, evaluates it, compares with Z
    python3 turing_to_recursive.py --example        on the addition machine of chapter 3

MIT licence. Frédéric Prost and Claude.

import sys

import recursive as r

from machines import Machine, BLANK, STROKE


def total(terms):
    """Sum written as a balanced tree of additions (logarithmic depth)."""
    if len(terms) == 1:
        return terms[0]
    m = len(terms) // 2
    return App(r.add, total(terms[:m]), total(terms[m:]))


def cases(conditions_values, default):
    """Definition by disjoint cases: sum of the [condition]·value, plus [no condition]·default.
    (One could write cond(c1, v1, cond(c2, v2, ...)); the sum avoids too deep a nesting.)"""
    conds = [c for c, _ in conditions_values]
    none_ = App(r.neg, total(conds)) if conds else 1
    return total([App(r.mult, c, v) for c, v in conditions_values] + [App(r.mult, none_, default)])


class Translation:
    """All the terms associated with a machine Z."""

    def __init__(self, machine, arity=1):
        self.machine = machine
        self.n = arity
        syms = [BLANK, STROKE] + sorted(machine.symbols() - {BLANK, STROKE})
        states = [machine.initial_state] + sorted(machine.states() - {machine.initial_state})
        self.sym = {s: k for k, s in enumerate(syms)}
        self.state = {q: k for k, q in enumerate(states)}
        self.b = b = len(syms)
        self.symbols, self.states = syms, states

        # --- decoding a configuration c = <g, <i, d>>
        G = r.left
        D = r.right
        self.cg = function(1, lambda c: App(G, c))
        self.ci = function(1, lambda c: App(G, App(D, c)))
        self.cd = function(1, lambda c: App(D, App(D, c)))
        cg, ci, cd = self.cg, self.ci, self.cd
        self.scanned = function(1, lambda c: App(r.rem, App(cd, c), b), "scanned")
        scanned = self.scanned

        def conf(g, i, d):
            return App(r.pair, g, App(r.pair, i, d))

        # --- one computation step: definition by cases, one case per quadruple
        def new(c, quad):
            q, s, a, q2 = quad
            i2 = self.state[q2]
            if a == "R":     # the scanned cell moves to the left part
                return conf(App(r.add, App(r.mult, App(cg, c), b), App(scanned, c)), i2, App(r.quot, App(cd, c), b))
            if a == "L":     # the cell to the left becomes the scanned cell
                return conf(App(r.quot, App(cg, c), b), i2, App(r.add, App(r.mult, App(cd, c), b), App(r.rem, App(cg, c), b)))
            # writing: the units digit of d goes from sym[s] to sym[a]
            return conf(App(cg, c), i2, App(r.add, App(r.monus, App(cd, c), self.sym[s]), self.sym[a]))

        def applies(c, quad):
            return App(r.conj, App(r.eq, App(ci, c), self.state[quad[0]]), App(r.eq, App(scanned, c), self.sym[quad[1]]))

        quads = machine.quadruples
        self.step = function(1, lambda c: cases([(applies(c, qd), new(c, qd)) for qd in quads], c), "step")
        no_quad = lambda c: cases([(applies(c, qd), 0) for qd in quads], 1)
        self.halt = function(1, no_quad, "halt")
        step = self.step
        self.iter = recursion(2, lambda c: c, lambda t, acc, c: App(step, acc), "iter")

        # --- initial configuration: rep(x) = 1 + b + ... + b^x codes 1^{x+1}
        self.rep = recursion(1, lambda: 1, lambda y, acc: App(r.add, App(r.mult, acc, b), 1), "rep")
        rep = self.rep
        n = arity

        def d_init(*xs):
            # d = rep(x1) + b^{x1+2} (rep(x2) + b^{x2+2} ( ... rep(xn)))
            e = App(rep, xs[-1])
            for x in reversed(xs[:-1]):
                e = App(r.add, App(rep, x), App(r.mult, App(r.power, b, App(r.add, x, 2)), e))
            return e
        self.init = function(n, lambda *xs: conf(0, 0, d_init(*xs)), "init")

        # --- reading the result: count the digits equal to 1 (at most L digits)
        # digits(L, m) = pair(m', nb) after L rounds of: m' := m' div b ; nb := nb + [m' mod b = 1]
        one = self.sym[STROKE]
        self.count = recursion(2, lambda m: App(r.pair, m, 0),
                               lambda k, p, m: App(r.pair, App(r.quot, App(r.left, p), b),
                                                   App(r.add, App(r.right, p), App(r.eq, App(r.rem, App(r.left, p), b), one))),
                               "count")
        count = self.count
        nb = lambda L, m: App(r.right, App(count, L, m))
        # useful length: t + the sum of the (x_i + 2) bounds the number of cells visited
        self.strokes = function(n + 2, lambda t, c, *xs: App(r.add, nb(self.length(t, xs), App(cg, c)), nb(self.length(t, xs), App(cd, c))), "strokes")

        init, iter_, halt = self.init, self.iter, self.halt
        self.time = minimization(n, lambda *a: App(r.neg, App(halt, App(iter_, a[-1], App(init, *a[:-1])))), "time")
        time = self.time
        self.f = function(n, lambda *xs: App(self.strokes, App(time, *xs), App(iter_, App(time, *xs), App(init, *xs)), *xs), "f_Z")

    def length(self, t, xs):
        e = t
        for x in xs:
            e = App(r.add, e, App(r.add, x, 2))
        return e

    def code_configuration(self, conf):
        """Code <g, <i, d>> of a configuration of the simulator (to check step by step)."""
        b, p = self.b, conf.position
        d = g = 0
        keys = [k for k, v in conf.tape.items() if v != BLANK]
        hi = max(keys + [p])
        lo = min(keys + [p])
        for k in range(hi, p - 1, -1):
            d = d * b + self.sym[conf.tape.get(k, BLANK)]
        for k in range(lo, p):
            g = g * b + self.sym[conf.tape.get(k, BLANK)]
        return r.cantor(g, r.cantor(self.state[conf.state], d))


def check(machine, args, fast=True, max_steps=2000):
    """Checks, step by step, that step follows the simulator exactly, then evaluates f_Z."""
    T = Translation(machine, len(args))
    c = machine.initial_configuration(*args)
    code = r.evaluate(T.init, args, fast)
    assert code == T.code_configuration(c), "initial configuration"
    while machine.step(c):
        code = r.evaluate(T.step, (code,), fast)
        assert code == T.code_configuration(c), "step %d" % c.steps
        if c.steps > max_steps:
            raise RuntimeError("too long for a check")
    assert r.evaluate(T.halt, (code,), fast) == 1
    return T, r.evaluate(T.f, args, fast), c.number_of_strokes()

Computation relative to an oracle

The translations remain valid when an oracle is added to both languages: a machine that can query a black box translates into a formula that uses the same black box, and conversely.

Everything above relativizes: one adds to the recursive functions the characteristic function $c_A$ of an arbitrary set $A\subseteq\N$ (class $P^A$, see relative recursion), and to the machines the oracle quadruples $q_i\,S_j\,q_k\,q_l$ (class $\mathcal T^A$, see oracle machines). Ch. Boitet’s lecture notes prove the equivalence directly in this form; the two proofs above extend to it without any change of method.

Theorem
Relative equivalence: P^A = 𝒯^A

For every $A\subseteq\N$, the $A$-recursive functions are exactly the functions $A$-computable by a Turing machine: $P^A=\mathcal T^A$. More precisely, for every $n$ there is a predicate $T^A_n(z,\vec x,y)$, primitive recursive relative to $A$, such that for every machine $Z$ (with or without oracle quadruples) and every Gödel number $z$ of $Z$: $$\Psi^{(n)}_{Z^A}(\vec x)\simeq U\big(\mu y\ T^A_n(z,\vec x,y)\big).$$ Moreover $T^A_n$ depends on $A$ only through a finite initial segment of $c_A$: there is a primitive recursive predicate $\hat T_n$ such that $$T^A_n(z,\vec x,y)\iff \hat T_n\big(z,\vec x,y,\ \hat c_A(y)\big),\qquad \hat c_A(y)=\textstyle\prod_{i<y}p_i^{\,c_A(i)}.$$

In plain words. If the same black box is added to Turing machines and to recursive functions, the two languages remain equivalent.

Adding an oracle is like adding to a programming language a library function whose code is unknown but which can be called. The translations between languages do not need to know this code: it suffices to pass the calls on.

$P^A\subseteq\mathcal T^A$. We reuse the stack-discipline compiler. The only new base function is $c_A$; it suffices to build a machine $\mathsf{Oracle}_A$ that pushes $c_A(x)$, where $x$ is the last block. The oracle question concerns the number $\langle\alpha\rangle$ of bars on the whole tape: so the machine temporarily replaces the bars of all the other blocks, and the first bar of the last block, by a mark $X$; exactly $x$ bars remain. It then asks the question “$x\in A$?” by a quadruple $q\,B\,q_{\mathrm{yes}}\,q_{\mathrm{no}}$, then, in each of the two branches, restores the bars and writes the block $\overline 1$ or $\overline 0$ at $E$. The other cases of the induction (substitution, recursion, minimization) do not use the oracle and stay as they are; the function $f\in P^A$ is therefore computed by the compiled machine, equipped with the oracle $A$.

For the left end, we use the fact that blocks are separated by one blank and that each block has at least one bar ($\overline x=1^{x+1}$): two consecutive blanks on the left signal the beginning of the tape.

$\mathcal T^A\subseteq P^A$. We reuse the construction of the normal form, with three modifications:

  1. $\mathrm{Quad}^A(x)$ also accepts the fourth form: $(x)_3$ may be a state ($\mathrm{State}((x)_3)$). The code of the quadruple $q_i\,S_j\,q_k\,q_l$ is $2^{4i+7}\,3^{4j+9}\,5^{4k+7}\,7^{4l+7}$. Consistency (two distinct quadruples do not begin with the same pair) applies to all four forms.
  2. Let $N(x)$ be the number of $k\le\ell(x)$ such that $(x)_k=13$: this is $\langle\alpha\rangle$, the number of bars of the description coded by $x$. The predicate $\mathrm{Step}^A(x,y,z)$ adds to the five cases of $\mathrm{Step}$ a sixth one: there are a splitting $x=g*2^r*3^s*d$ and a quadruple $2^r3^s5^k7^l$ of $z$ such that $$\big(c_A(N(x))=1\ \wedge\ y=g*2^k*3^s*d\big)\ \vee\ \big(c_A(N(x))=0\ \wedge\ y=g*2^l*3^s*d\big).$$
  3. $\mathrm{Final}(x,z)$ does not change: a description is terminal if no quadruple, of whatever form, begins with its state and scanned symbol.

All these predicates are obtained from primitive recursive functions and $c_A$ by composition and primitive recursion: they are primitive recursive relative to $A$, hence in $P^A$. We set $T^A_n(z,\vec x,y)\iff\mathrm{TM}^A(z)\wedge\mathrm{Comp}^A(y,z)\wedge(y)_1=\mathrm{Init}_n(\vec x)$, and the reasoning of the normal form applies word for word: the computation is deterministic, since the oracle’s answer is determined by $A$; so there is at most one complete computation starting from $\mathrm{Init}_n(\vec x)$, and $U$ reads off its result. Thus $\Psi^{(n)}_{Z^A}\in P^A$.

Use principle. In $T^A_n(z,\vec x,y)$, the function $c_A$ is evaluated only at points $N(x)$ where $x=(y)_k$ is a component of $y$; and $N(x)\le\ell(x)<x<y$. So we replace $c_A(i)$ by the exponent $(\hat c_A(y))_i$, which gives a primitive recursive predicate $\hat T_n(z,\vec x,y,w)$ (without oracle), with $T^A_n(z,\vec x,y)\iff\hat T_n(z,\vec x,y,\hat c_A(y))$.

Corollary
Relative enumeration, s-m-n and halting

For $A\subseteq\N$, write $\varphi^{A,(n)}_e=\Psi^{(n)}_{Z^A}$ where $Z$ is the machine with Gödel number $\eta^\ast(e)$, the $e$th integer satisfying $\mathrm{TM}^A$ in increasing order (Gödel numbers of machines, oracle quadruples allowed; the predicate $\mathrm{TM}^A$ does not depend on $A$, and $\eta^\ast$ is primitive recursive for the same reason as $\eta$), and $\varphi^A_e=\varphi^{A,(1)}_e$.

  1. (Enumeration) The function $(e,\vec x)\mapsto\varphi^{A,(n)}_e(\vec x)\simeq U(\mu y\,T^A_n(\eta^\ast(e),\vec x,y))$ is in $P^A$ and universal for the $A$-recursive functions of arity $n$.
  2. (s-m-n) There are primitive recursive functions $s^m_n$, built below, such that for every $A$: $\varphi^{A,(m+n)}_e(\vec y,\vec z)\simeq\varphi^{A,(n)}_{s^m_n(e,\vec y)}(\vec z)$. They do not depend on $A$.
  3. (Relative halting) The jump $A'=\{e:\varphi^A_e(e)\conv\}$ is semi-decidable relative to $A$, but is not decidable relative to $A$.

In plain words. The great theorems of the following chapters (universal machine, self-modifying programs, impossibility of predicting halting) remain true for machines equipped with an oracle.

Even with a black box that answers an impossible question, one cannot predict the halting of the programs that use this box. This gives an infinite ladder of more and more impossible problems: each oracle leaves a problem out of reach, which can in turn serve as an oracle.

(1) follows from the theorem: for every machine $Z$ we have $\Psi^{(n)}_{Z^A}\simeq U(\mu y\,T^A_n(z,\vec x,y))$, and $\eta^\ast$ is primitive recursive. (2) The machine with index $s^m_n(e,\vec y)$ writes $\overline{y_1}B\cdots B\overline{y_m}B$ in front of its input and then runs the machine with index $e$; the writing asks the oracle no question. The code of this machine is computed from $\eta^\ast(e)$ and $\vec y$ by primitive recursive operations on Gödel numbers (concatenation, renaming of states), and one returns to an index by the inverse of $\eta^\ast$. Chapter 9 revisits this construction without oracle (s-m-n theorem). (3) $A'=\mathrm{Dom}\,\lambda e.\varphi^A_e(e)$ is the domain of a function of $P^A$. If $c_{A'}$ were in $P^A$, the function $h(x)=0$ if $\varphi^A_x(x)\ind$, $h(x)$ undefined otherwise, would be in $P^A$ (minimize on $c_{A'}(x)$: $h(x)\simeq\mu y\,[c_{A'}(x)=0]$), so $h=\varphi^A_{x_0}$ for some $x_0$ by (1); then $\varphi^A_{x_0}(x_0)\conv\iff\varphi^A_{x_0}(x_0)\ind$, a contradiction. Chapter 10 revisits this argument without oracle (undecidability of halting).

Recursive functions and the λ-calculus

Formulas also translate into the λ-calculus, where there are only functions. The recipe “repeat $n$ times” becomes the number $n$ itself, since a number there is a repetition. The recipe “search until found” becomes a function that calls itself, thanks to the fixed-point combinator. In the other direction, each computation step of the λ-calculus is coded by a formula.

Theorem
Recursive functions are λ-definable

For every recursive function $f:\N^n\to\N$, there is a λ-term $F$ such that $F\,\mathbf{x_1}\cdots\mathbf{x_n}\twoheadrightarrow_\beta\mathbf{f(\vec x)}$ if $f(\vec x)\conv$, and $F\,\mathbf{x_1}\cdots\mathbf{x_n}$ has no normal form if $f(\vec x)\ind$.

In plain words. Every recursive function can be written in the λ-calculus. And when the function has no value (when the search finds nothing), the computation of the λ-term does not terminate.

A language that knows neither numbers, nor memory, nor loops, only the replacement of a parameter by a value, suffices to compute everything. The “while” loop becomes a function that calls itself.

We proceed in three steps: first the primitive recursive functions, which are total; then the minimization of a total function, the only source of non-termination; finally the general case, thanks to the Kleene normal form. We use the terms of the λ-calculus chapter (proposition and iteration lemma), weak head reduction $\to_t$ and the weak head normalization theorem: a closed term whose weak head reduction is infinite has no normal form.

Step 1: primitive recursive functions. For every primitive recursive $f$, we build $F$ with $F\,\vec{\mathbf x}\twoheadrightarrow\mathbf{f(\vec x)}$ for all $\vec x$, by induction on the definition of $f$.

  • Constants: $\lambda x_1\cdots x_k.\,\mathbf m$. Successor: $\mathsf S$. Projections: $\lambda x_1\cdots x_k.\,x_i$.
  • Substitution $\sigma[g,h_1,\dots,h_k]$: $F=\lambda\vec x.\,G\,(H_1\vec x)\cdots(H_k\vec x)$. Since $H_i\,\vec{\mathbf x}\twoheadrightarrow\mathbf{m_i}$ with $m_i=h_i(\vec x)$, we have $F\,\vec{\mathbf x}\twoheadrightarrow G\,\mathbf{m_1}\cdots\mathbf{m_k}\twoheadrightarrow\mathbf{g(\vec m)}$.
  • Recursion $\rho[g,h]$: iterate on pairs, with $\mathsf{pair},\mathsf{fst},\mathsf{snd}$ from the iteration lemma: $$F=\lambda y\,\vec x.\ \mathsf{snd}\Big(y\,\big(\lambda p.\,\mathsf{pair}\,(\mathsf S(\mathsf{fst}\,p))\,(H\,(\mathsf{fst}\,p)\,(\mathsf{snd}\,p)\,\vec x)\big)\,\big(\mathsf{pair}\,\mathbf0\,(G\,\vec x)\big)\Big).$$ Write $P$ for the term $\lambda p.\cdots$ (with $\vec x:=\vec{\mathbf x}$). It sends $\mathsf{pair}\,\mathbf k\,\mathbf v$, where $v=f(k,\vec x)$, to $\mathsf{pair}\,(\mathsf S\,\mathbf k)\,(H\,\mathbf k\,\mathbf v\,\vec{\mathbf x})\twoheadrightarrow\mathsf{pair}\,\mathbf{k+1}\,\mathbf{f(k+1,\vec x)}$. Since $\mathsf{pair}\,\mathbf0\,(G\vec{\mathbf x})\twoheadrightarrow\mathsf{pair}\,\mathbf0\,\mathbf{f(0,\vec x)}$, point (4) of the iteration lemma gives $F\,\mathbf y\,\vec{\mathbf x}\twoheadrightarrow\mathsf{snd}\,(\mathsf{pair}\,\mathbf y\,\mathbf{f(y,\vec x)})\twoheadrightarrow\mathbf{f(y,\vec x)}$.

Step 2: minimization of a total function. Let $g:\N^{n+1}\to\N$ be total, λ-defined by $G$ in the sense of step 1. With Turing’s combinator $\Theta=A\,A$, $A=\lambda x.\lambda y.\,y\,(x\,x\,y)$, set

$$M=\lambda\vec x.\ \Theta\,W_{\vec x}\,\mathbf0,\qquad W_{\vec x}=\lambda r.\lambda m.\ \mathsf{zero?}\,(G\,\vec x\,m)\ m\ (r\,(\mathsf S\,m)).$$

Fix $\vec x$, write $W$ for $W_{\vec{\mathbf x}}$, and set $N_0=\mathbf0$, $N_{k+1}=\mathsf S\,N_k$: these terms are closed and $N_k\twoheadrightarrow\mathbf k$. For every $k$, with $R=\Theta W N_{k+1}$, we have the weak head steps

$$\Theta W N_k\to_t(\lambda y.\,y(AAy))\,W\,N_k\to_t W(\Theta W)\,N_k\to_t(\lambda m.\cdots)\,N_k\to_t\mathsf{zero?}\,(G\,\vec{\mathbf x}\,N_k)\,N_k\,R\to_t(G\,\vec{\mathbf x}\,N_k)\,(\lambda z.\mathsf{ff})\,\mathsf{tt}\,N_k\,R.$$

and $G\,\vec{\mathbf x}\,N_k\twoheadrightarrow\mathbf{g(\vec x,k)}$. If $g(\vec x,k)=0$, the last term reduces to $\mathbf0\,(\lambda z.\mathsf{ff})\,\mathsf{tt}\,N_k\,R\twoheadrightarrow\mathsf{tt}\,N_k\,R\twoheadrightarrow N_k\twoheadrightarrow\mathbf k$. If $g(\vec x,k)\ge1$, we use the following lemma.

Lemma. If $Q\twoheadrightarrow\mathbf{j}$ with $j\ge1$, then, for all terms $a,b,c_1,\dots,c_l$, $Q\,a\,b\,\vec c\to_t^*a\,P\,\vec c$ for some $P$. Indeed, for two variables $f,x$ not free in $Q,a,b$, we have $Q\,f\,x\twoheadrightarrow\mathbf j\,f\,x\twoheadrightarrow f\,(f^{j-1}x)$, which is normal with head the variable $f$. By the weak head normalization theorem and the second remark following it, the weak head reduction of $Q\,f\,x$ terminates on a term $f\,L_1$. Since weak head reduction is stable under substitution and under application to arguments (Fact 0 of its proof), $Q\,a\,b\,\vec c=(Q\,f\,x)[f:=a][x:=b]\,\vec c\to_t^*a\,P\,\vec c$ with $P=L_1[f:=a][x:=b]$.

If $g(\vec x,k)\ge1$, the lemma therefore gives $(G\vec{\mathbf x}N_k)\,(\lambda z.\mathsf{ff})\,\mathsf{tt}\,N_k\,R\to_t^*(\lambda z.\mathsf{ff})\,P\,N_k\,R\to_t\mathsf{ff}\,N_k\,R\to_t(\lambda y.y)\,R\to_tR$. In summary:

  • if $g(\vec x,k)\ge1$, then $\Theta W N_k\to_t^{+}\Theta W N_{k+1}$ (weak head steps only);
  • if $g(\vec x,k)=0$, then $\Theta W N_k\twoheadrightarrow\mathbf k$.

If $\mu[g](\vec x)=q$ is defined, we deduce $M\,\vec{\mathbf x}\twoheadrightarrow\Theta W N_0\twoheadrightarrow\Theta W N_1\twoheadrightarrow\cdots\twoheadrightarrow\Theta W N_q\twoheadrightarrow\mathbf q$. Otherwise, $g(\vec x,k)\ge1$ for every $k$, and the weak head reduction of $M\,\vec{\mathbf x}$, which reaches $\Theta W N_0$ in $n$ steps, then passes through all the $\Theta W N_k$: it is infinite.

Step 3: general case. Let $f$ be recursive of arity $n$. By the previous theorem, $f=\Psi^{(n)}_Z$ for a machine $Z$, with Gödel number $z$, and by the normal form, $f(\vec x)\simeq U(\mu y\,[g(\vec x,y)=0])$ with $g(\vec x,y)=1\monus\chi_{T_n}(z,\vec x,y)$, where $g$ and $U$ are primitive recursive. Let $M$ be the term of step 2 for $g$, $U'$ a term that λ-defines $U$ (step 1), and $\mathsf I=\lambda u.u$. Set

$$F=\lambda\vec x.\ M\,\vec x\ \mathsf I\ \mathsf I\ \big(U'\,(M\,\vec x)\big).$$

If $f(\vec x)\conv$, then $M\vec{\mathbf x}\twoheadrightarrow\mathbf q$ with $q=\mu y\,[g(\vec x,y)=0]$, and $\mathbf q\,\mathsf I\,\mathsf I\twoheadrightarrow\mathsf I^q\,\mathsf I\twoheadrightarrow\mathsf I$, so $F\vec{\mathbf x}\twoheadrightarrow\mathsf I\,(U'\,\mathbf q)\to U'\,\mathbf q\twoheadrightarrow\mathbf{U(q)}=\mathbf{f(\vec x)}$. If $f(\vec x)\ind$, the weak head reduction of $M\vec{\mathbf x}$ is infinite, hence so is that of $F\,\vec{\mathbf x}$, which begins with $n$ steps to $M\vec{\mathbf x}\,\mathsf I\,\mathsf I\,(U'(M\vec{\mathbf x}))$ and then follows that of $M\vec{\mathbf x}$ step by step (Fact 0); since $F\,\vec{\mathbf x}$ is closed, it has no normal form.

The prefix $M\,\vec x\,\mathsf I\,\mathsf I$ is indispensable: without it, $U'\,(M\vec{\mathbf x})$ could have a normal form even if $M\vec{\mathbf x}$ has none, for example if $U'$ does not use its argument. For the same reason, a direct induction on the definition of $f$, handling substitution and recursion of partial functions, would have to force the evaluation of each argument; going through the normal form avoids these complications, since the only partial function to handle is a minimization of a total function.

def compile(f):
    """(Named) λ-term that λ-defines the recursive function f."""
    from recursive import Const, Succ, Proj, Comp, Rec, Mu, Named
    while isinstance(f, Named):
        f = f.term
    if isinstance(f, Const):
        xs = _vars(f.k)
        return L(" ".join(xs), church(f.m)) if xs else church(f.m)
    if isinstance(f, Succ):
        return _P["S"]
    if isinstance(f, Proj):
        xs = _vars(f.k)
        return L(" ".join(xs), V(xs[f.i - 1]))
    if isinstance(f, Comp):
        xs = _vars(f.arity())
        G = compile(f.g)
        args = [Ap(compile(h), *[V(x) for x in xs]) for h in f.hs]
        return L(" ".join(xs), Ap(G, *args))
    if isinstance(f, Rec):
        G, H = compile(f.g), compile(f.h)
        y = _vars(1, "y")[0]
        xs = _vars(f.arity() - 1)
        p = _vars(1, "p")[0]
        fst, snd, pair, S = _P["fst"], _P["snd"], _P["pair"], _P["S"]
        X = [V(x) for x in xs]
        step = L(p, Ap(pair, Ap(S, Ap(fst, V(p))), Ap(H, Ap(fst, V(p)), Ap(snd, V(p)), *X)))
        start = Ap(pair, church(0), Ap(G, *X) if X else G)
        return L(" ".join([y] + xs), Ap(snd, Ap(V(y), step, start)))
    if isinstance(f, Mu):
        G = compile(f.g)
        xs = _vars(f.arity())
        rr, m = _vars(1, "r")[0], _vars(1, "m")[0]
        X = [V(x) for x in xs]
        W = L("%s %s" % (rr, m), Ap(_P["zero?"], Ap(G, *(X + [V(m)])), V(m), Ap(V(rr), Ap(_P["S"], V(m)))))
        body = Ap(_P["Θ"], W, church(0))
        return L(" ".join(xs), body) if xs else body
    raise TypeError("unknown term")

Theorem
λ-definable functions are recursive

Every λ-definable function is recursive.

In plain words. Conversely, everything computable in the λ-calculus is a recursive function.

Each expression of the λ-calculus is coded by a number, then one writes a formula that computes the code of the expression obtained after a replacement. It remains to look for the moment when no replacement is possible any more: this is, once again, a single search.

Code λ-terms by integers (for example with de Bruijn indices: $\ulcorner k\urcorner=\langle0,k\rangle$, $\ulcorner\lambda M\urcorner=\langle1,\ulcorner M\urcorner\rangle$, $\ulcorner MN\urcorner=\langle2,\langle\ulcorner M\urcorner,\ulcorner N\urcorner\rangle\rangle$). Substitution, shifting of indices and one step of normal-order reduction are primitive recursive (recursions on the structure of the code), as are “$t$ is a normal form” and “$t$ is the Church numeral $m$”. If $F$ λ-defines $f$, then $$f(\vec x)\simeq \mathrm{val}\Big(\mathrm{red}^{\,s}\big(\ulcorner F\,\mathbf{x_1}\cdots\mathbf{x_n}\urcorner\big)\Big)\quad\text{with}\quad s=\mu s\,\big[\mathrm{red}^{\,s}(\dots)\text{ is normal}\big],$$ where $\mathrm{red}^{\,s}$ iterates the reduction step $s$ times (primitive recursion on $s$) and $\mathrm{val}$ reads the integer of a numeral. By the normalization theorem, normal order finds the normal form if it exists, and by confluence it is the only one; if $f(\vec x)\ind$, there is no normal form and the minimization diverges.

The reducer on this page is exactly this program: assets/lambda.js represents terms with de Bruijn indices and iterates stepNormal until a normal form is reached. It is written in JavaScript rather than in recursive functions, but uses only structural recursions and a single unbounded loop.

The class of computable functions

Since the three languages compute the same thing, one can now say “computable” without specifying which one. A function is computable if there is a program, in any of these languages (or in any present-day programming language), that computes it.

Definition
Computable functions, decidable sets

The elements of the common class $\PR=\mathcal T=\Lambda$ are called computable functions, and we write $\mathcal R$ (or $\mathcal T_{tot}$) for the total computable functions. A set $A\subseteq\N$ is decidable (or recursive) if its characteristic function $\chi_A$ is computable. A language $L\subseteq\Sigma^*$ is decidable if the set of codes of its words is.

In plain words. A function is called computable if it is computed by a Turing machine, or, which amounts to the same thing, if it is recursive, or λ-definable. A problem is decidable if a program always answers correctly yes or no.

The word “computable” can now be used without specifying the model. Three very different ideas (mechanical, mathematical, and purely symbolic) delimit exactly the same territory. This is a powerful argument in favour of the Church–Turing thesis: everything computable by a mechanical procedure is computable by a Turing machine.

Functions, sets, predicates and languages are four presentations of the same notion, thanks to codings: a predicate is the characteristic function of a set; a language becomes a set of integers by Gödel numbering; and a total function $f$ is computable if and only if its graph $\{\langle x,f(x)\rangle\}$ is decidable (in one direction, test $f(x)=y$; in the other, search for $y$ by minimization).

★Exercise 1 — Coding a quadruple

With the codes $\gamma$ of the numbering of machines, write the Gödel number of the quadruple $q_0\,1\,B\,q_1$, then that of the machine $\{q_0\,1\,B\,q_1\}$. How many Gödel numbers does a machine with $k$ quadruples have?

Solution

The symbols of the word $q_0\,S_1\,S_0\,q_1$ have codes $\gamma(q_0)=7$, $\gamma(S_1)=13$, $\gamma(S_0)=9$, $\gamma(q_1)=11$, so $\mathrm{gn}(q_0\,1\,B\,q_1)=2^7\cdot3^{13}\cdot5^9\cdot7^{11}$. The machine, a sequence of a single quadruple, has Gödel number $2^{\,2^7\cdot3^{13}\cdot5^9\cdot7^{11}}$. A machine with $k$ (distinct) quadruples has $k!$ of them, one per order of enumeration of the quadruples. These numbers are gigantic; all that matters is that coding and decoding can be done by primitive recursive functions.

★Exercise 2 — Addition is not regular

Is the addition machine of chapter 3 2-regular? Why is regularity necessary for composing machines?

Solution

No. When it halts, the tape carries $B\,1^{x}\,B\,B\,1^{y}$ (the first block has lost its leading bar, and so has the second): the result is in two pieces, the head is not on its first bar, and the final state $q_4$ is indeed the largest but the tape does not follow the convention $\overline{x+y}$. To chain two machines, the second must find its input exactly in the form $q_0\,\overline{(y_1,\dots,y_s)}$; otherwise it would read leftover debris of computation as data. A regular machine returns its result “clean”, ready to serve as input.

★★Exercise 3 — A single minimization suffices

Deduce from the Kleene normal form that every partial recursive function can be written with a single unbounded minimization, applied to a primitive recursive function.

Solution

Let $f$ be partial recursive of arity $n$. It is Turing-computable (first direction): $f=\Psi^{(n)}_Z$ for a machine $Z$ with Gödel number $z$. By the normal form, $f(\vec x)\simeq U\big(\mu y\,T_n(z,\vec x,y)\big)$. The predicate $T_n(z,\vec x,y)$, with $z$ fixed, is primitive recursive, and so is $U$. There is therefore a single unbounded minimization, applied to $\overline{\mathrm{sg}}\big(\chi_{T_n}(z,\vec x,y)\big)$, which vanishes exactly when $T_n$ holds. Recursive definitions containing several nested $\mu$’s therefore bring no new function.

★★Exercise 4 — Computation time and primitive recursion

Let $f=\Psi^{(1)}_Z$ be total, and $t(x)$ the least $y$ such that $T_1(z,x,y)$ (the code of the computation). Show that if $t$ is bounded by a primitive recursive function $b$, then $f$ is primitive recursive.

Solution

If $t(x)\le b(x)$ for all $x$, then $\mu y\,T_1(z,x,y)=\mu y\le b(x)\ T_1(z,x,y)$: the search is bounded. Now bounded minimization, bounded by a primitive recursive function, of a primitive recursive predicate is primitive recursive (bounded minimization). So $f(x)=U\big(\mu y\le b(x)\,T_1(z,x,y)\big)$ is primitive recursive. A computable function that is not primitive recursive, such as the Ackermann function, therefore has computations whose size is bounded by no primitive recursive function.

★★★Exercise 5 — A computable function larger than all primitive recursive functions

Enumerate the terms built with the base functions, $\sigma$ and $\rho$, that define functions of one variable: $f_0,f_1,\dots$ (for example by increasing length of the text of the term). Show that $g(x)=1+\max_{e\le x}f_e(x)$ is computable and total, but is bounded by no primitive recursive function.

Solution

Computable. Terms are finite words; one can enumerate those that are well formed and of arity 1, and one can evaluate a term at a point by following the equations of $\sigma$ and $\rho$ (all functions of $\RP$ are total, so evaluation terminates). So $(e,x)\mapsto f_e(x)$ is computable and total, and so is $g$.

No upper bound. Let $b$ be primitive recursive of one variable. Then so is $b+1$, so $b+1=f_k$ for some $k$. For $x\ge k$, $g(x)>f_k(x)=b(x)+1>b(x)$. Thus $g$ exceeds $b$ from rank $k$ on: no primitive recursive function bounds $g$. In particular $g\notin\RP$ (otherwise $g$ would bound itself), and, by the previous exercise, the computation time of $g$ is bounded by no primitive recursive function.

This is the diagonal of the proposition on enumeration, strengthened: one obtains not only a function outside $\RP$, but a function that dominates them all.
