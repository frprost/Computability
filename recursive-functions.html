Recursive functions

Start from obviously computable functions, and combine them by composition, recursion and search for the least value: the “mathematician’s” approach to computation, and a toolbox used by the whole rest of the manual.

Another way of defining computation, without a machine: start from obvious operations (add one, copy, write a fixed number) and combine them according to three recipes. One obtains exactly what Turing machines compute.

The previous chapter described computation as a mechanism: a tape, a head, rules. This chapter describes it as a mathematician would: by definitions. We start from three operations that nobody doubts are computable, then allow ourselves three ways of building new functions from old ones. Everything obtained in this way is called a “recursive function”.

It is a bit like a construction set: a few basic pieces, a few ways of assembling them, and any building can be put up. The surprise, proved in the chapter Equivalence, is that this construction set and the Turing machine compute exactly the same functions.

A mathematical approach to the computable

Mathematicians have long defined sequences “by recursion”: one gives the first term, then a rule for going from one term to the next. For example, start from 10; if the number is even, divide it by 2, otherwise multiply it by 3 and add 1. One obtains 10, 5, 16, 8, 4, 2, 1, 4, 2, 1… Each term is computed mechanically from the previous one. Recursive functions generalize this idea.

The formalism of recursive functions starts from base functions, obviously computable, and adds operators that build more and more elaborate functions. It is a compositional approach: each function is defined from previous ones, as in a library of programs. It should be thought of as a mathematical assembly language into which the usual functions are “compiled”.

Definition by recursion generalizes an old tradition, that of recurrent sequences. For example, for a starting value $X$:

$$u_0=X,\qquad u_{n+1}=\begin{cases}u_n/2&\text{if }u_n\text{ is even},\\ 3u_n+1&\text{otherwise.}\end{cases}$$

With $X=10$, one computes mechanically $u_1=5$, $u_2=16$, $u_3=8$, $u_4=4$, $u_5=2$, $u_6=1$, $u_7=4$, $u_8=2$, …: the sequence then loops on $4,2,1$.

An equivalent OCaml program:

let rec collatz x n =
  if n = 0 then x
  else let p = collatz x (n - 1) in
       if p mod 2 = 0 then p / 2 else 3 * p + 1

Primitive recursive functions

The basic pieces are three obvious operations: always writing the same number, adding 1, and keeping one of the data while forgetting the others. We then allow two ways of combining: chaining functions (the result of one serves as input to the other), and repeating an operation a number of times known in advance. With this alone, one rebuilds addition (add 1, as many times as needed), multiplication (add, as many times as needed), power, factorial…

Definition
Primitive recursive functions

The set $\RP$ of primitive recursive functions is the smallest set of total functions $\N^k\to\N$ ($k\ge0$) that contains:

  • the constants $m^{(k)}:(x_1,\dots,x_k)\mapsto m$, for all $k,m\in\N$;
  • the successor $S:x\mapsto x+1$;
  • the projections (choice of argument) $A^{(k)}_i:(x_1,\dots,x_k)\mapsto x_i$, for $1\le i\le k$;

and that is closed under:

  • substitution (composition): if $g$ has arity $k$ and $h_1,\dots,h_k$ have arity $m$, then $\sigma[g,h_1,\dots,h_k]$ is the function of arity $m$ $$(x_1,\dots,x_m)\mapsto g\big(h_1(x_1,\dots,x_m),\dots,h_k(x_1,\dots,x_m)\big);$$
  • primitive recursion: if $g$ has arity $k-1$ and $h$ arity $k+1$, then $f=\rho[g,h]$ is the function of arity $k$ defined by $$f(0,x_2,\dots,x_k)=g(x_2,\dots,x_k),\qquad f(y+1,x_2,\dots,x_k)=h\big(y,\,f(y,x_2,\dots,x_k),\,x_2,\dots,x_k\big).$$

In plain words. We start from three basic functions: the one that always gives the same number, the one that adds 1, and the one that picks one of its inputs. We are allowed to chain them, and to repeat an operation a number of times known in advance. The functions obtained in this way are called primitive recursive functions.

In programming, this corresponds to “repeat $n$ times” loops, where one knows, before starting, how many rounds will be made. Such a program necessarily halts. It was long believed that this sufficed to compute everything. It does not: the Ackermann function is computable, but not in this way, and the chapter Motivations shows that no language in which all programs halt can compute everything.

A definition by recursion corresponds exactly to the following program, which shows that every primitive recursive function is computable and total (by induction on its construction):

res := g(x2, ..., xk)
for i from 0 to y-1:
    res := h(i, res, x2, ..., xk)
return res

By convention the recursion is on the first argument; projections allow arguments to be permuted, so this choice restricts nothing.

The simulator on the page Equivalence compiles any term built with $m^{(k)}$, $S$, $A^{(k)}_i$, $\sigma$, $\rho$ (and $\mu$, below) into a complete Turing machine. Its terms are written exactly in the syntax of this definition, for example $\mathrm{add}=\rho[A^{(1)}_1,\sigma[S,A^{(3)}_2]]$.

Proposition
The recursion scheme does define a function; general substitution
  1. If $g$ and $h$ are total, there is one and only one function $f=\rho[g,h]$ that satisfies the primitive recursion equations.
  2. Every class of functions that contains the projections $A^{(m)}_i$ and is closed under composition (in the sense of the definition) is closed under general substitution: if $g$ has arity $k$ and the $g_j$ are in the class, then $f(x_1,\dots,x_m)=g(B_1,\dots,B_k)$ is in it too, where each $B_i$ is either a variable $x_{p_i}$, or some $g_{j}$ applied to variables taken among $x_1,\dots,x_m$, in any order and with repetitions.

In plain words. A correct definition by recursion (one gives the value at 0, then says how to go from $n$ to $n+1$) does define a function, and only one. And one may freely write formulas such as “$f(x,y)=g(y,x,x)$”: they are legitimate abbreviations.

Not every “recursion” is a computation. A rule saying “to know $f(n)$, first compute $f(n+1)$” climbs instead of descending, and never stops. The recursion allowed here always descends towards 0, which guarantees both that the function exists and that its computation terminates.

(1) Existence: by induction on $y$, $f(y,\vec x)$ is defined for all $\vec x$ (case $y=0$ by $g$ total, case $y+1$ by $h$ total). Uniqueness: if $f_1\ne f_2$ satisfy the system, let $y_0$ be the least $y$ such that $f_1(y,\vec x)\ne f_2(y,\vec x)$ for some $\vec x$; $y_0=0$ is impossible (both equal $g(\vec x)$), and if $y_0>0$, $f_1(y_0,\vec x)=h(y_0-1,a,\vec x)=f_2(y_0,\vec x)$ with $a=f_1(y_0-1,\vec x)=f_2(y_0-1,\vec x)$: contradiction.

(2) Set $h_i=A^{(m)}_{p_i}$ in the first case and $h_i=\sigma[g_{j_i},A^{(m)}_{q_1},\dots,A^{(m)}_{q_s}]$ in the second; each $h_i$ is in the class, and $f=\sigma[g,h_1,\dots,h_k]$.

First examples

Example
Addition, multiplication, power, factorial, predecessor

The functions $x+y$, $x\times y$, $x^y$, $x!$ and $\mathrm{pred}(x)=x\monus 1$ are primitive recursive.

In plain words. Addition, multiplication, power, factorial and “subtract 1” are built from the basic pieces.

The construction follows what is learned in primary school. Adding $x$ and $y$ is adding 1 to $y$, $x$ times in a row. Multiplying is adding $y$, $x$ times in a row. Raising to a power is multiplying, $y$ times in a row. Each operation is a repetition of the previous one: a ladder whose rungs can be climbed one by one.

We give the recursion equations; each right-hand side is a composition of functions already obtained.

  • General successor: $S_a(0)=a$, $S_a(x+1)=S(S_a(x))$.
  • Addition: $\mathrm{add}(0,y)=y$, $\mathrm{add}(x+1,y)=S(\mathrm{add}(x,y))$.
  • Multiplication: $\mathrm{mult}(0,y)=0$, $\mathrm{mult}(x+1,y)=\mathrm{add}(y,\mathrm{mult}(x,y))$.
  • Power: the recursion is on the exponent, which is the second argument of $x^y$; first define $t(y,x)=x^y$ by $t(0,x)=1$, $t(y+1,x)=\mathrm{mult}(x,t(y,x))$, then $x^y=t(A^{(2)}_2(x,y),A^{(2)}_1(x,y))$.
  • Factorial: $0!=1$, $(y+1)!=\mathrm{mult}(S(y),y!)$.
  • Predecessor: $\mathrm{pred}(0)=0$, $\mathrm{pred}(y+1)=y$. The recursion step ignores the recursive call: $h=A^{(2)}_1$.

The same functions, written entirely in the formalism (arities as superscripts):

$$\begin{aligned} S_a&=\rho\big[a^{(0)},\ \sigma[S,A^{(2)}_2]\big]\\ \mathrm{add}&=\rho\big[A^{(1)}_1,\ \sigma[S,A^{(3)}_2]\big]\\ \mathrm{mult}&=\rho\big[0^{(1)},\ \sigma[\mathrm{add},A^{(3)}_3,A^{(3)}_2]\big]=\rho\big[0^{(1)},\ \sigma[\rho[A^{(1)}_1,\sigma[S,A^{(3)}_2]],A^{(3)}_3,A^{(3)}_2]\big]\\ t&=\rho\big[1^{(1)},\ \sigma[\mathrm{mult},A^{(3)}_3,A^{(3)}_2]\big],\qquad \mathrm{pow}=\sigma[t,A^{(2)}_2,A^{(2)}_1]\\ \mathrm{fact}&=\rho\big[1^{(0)},\ \sigma[\mathrm{mult},\sigma[S,A^{(2)}_1],A^{(2)}_2]\big]\\ \mathrm{pred}&=\rho\big[0^{(0)},\ A^{(2)}_1\big] \end{aligned}$$

Let us check $\mathrm{mult}$: $\mathrm{mult}(x+1,y)=h(x,\mathrm{mult}(x,y),y)$ with $h=\sigma[\mathrm{add},A^{(3)}_3,A^{(3)}_2]$, that is, $\mathrm{add}(y,\mathrm{mult}(x,y))$. These terms have been evaluated and compiled into Turing machines; the results agree (see the compiler).

Library of primitive recursive functions

With these tools alone, one recovers almost all of school arithmetic: division with remainder, the test “is this number prime?”, the list of prime numbers, the greatest common divisor. Each function is built from the previous ones, just as one enriches a library of programs.

Proposition
Bounded minimization, quotient, remainder and primes

If $P$ is a primitive recursive predicate, $\mu z<y\,[P(z,\vec x)]$ is primitive recursive. Consequently the quotient, the remainder, primality, the sequence $(p_k)$ of primes and the exponents $(x)_k$ are primitive recursive.

In plain words. Looking for the first number that fits, when one knows how far to search, is a safe operation: it always halts. From it one derives division, remainder, the primality test, the list of prime numbers.

To find the quotient of 17 by 5, we try 0, 1, 2, 3 and stop, knowing that there is no point going beyond 17. Only when we do not know how far to search does the risk of never stopping appear. The whole difficulty of computability lies in this difference.

The product $\prod_{z\le v}(1\monus\chi_P(z,\vec x))$ equals 1 as long as no $z\le v$ satisfies $P$, and 0 afterwards; the sum of these products for $v<y$ therefore counts the $v<y$ that precede the first witness, that is, it equals this witness (or $y$). For the quotient, the bound $x$ suffices since $q=x$ satisfies $x<(x+1)y$ as soon as $y\ge1$. For $p_{k+1}$, the bound $p_k!+1$ is justified by Euclid’s argument: every prime factor of $p_k!+1$ is strictly greater than $p_k$.

The compiler contains truncated difference and the quotient (the latter defined by unbounded minimization, to illustrate partiality at $y=0$).

Proposition
Further primitive recursive functions, predicates and constructions

The following are primitive recursive (these examples come from Ch. Boitet’s lecture notes; the formulas have been checked by program):

  • $|x-y|=(x\monus y)+(y\monus x)$, $\ \min(x,y)=y\monus(y\monus x)$, $\ \max(x,y)=(x+y)\monus\min(x,y)$;
  • the sign $\mathrm{sg}(0)=0$, $\mathrm{sg}(x+1)=1$, and its opposite $\overline{\mathrm{sg}}(x)=1\monus\mathrm{sg}(x)$;
  • the remainder and the quotient, by recursion on $x$: $R(0,y)=0$, $R(x+1,y)=(R(x,y)+1)\cdot\mathrm{sg}\,|y-(R(x,y)+1)|$, and $\lfloor 0/y\rfloor=0$, $\lfloor (x+1)/y\rfloor=\lfloor x/y\rfloor+\overline{\mathrm{sg}}\,|y-(R(x,y)+1)|$;
  • cumulative sums and products $\sum_{y\le z}f(y,\vec x)$ and $\prod_{y\le z}f(y,\vec x)$, and more generally bounded by primitive recursive functions $f_1(\vec x)\le y\le f_2(\vec x)$; for example $\lfloor\sqrt x\rfloor=\sum_{i=1}^{x}\overline{\mathrm{sg}}(i^2\monus x)$;
  • functions defined by cases: if $P_1,\dots,P_s$ are pairwise exclusive primitive recursive predicates and $f_1,\dots,f_{s+1}$ primitive recursive functions, the function equal to $f_i$ where $P_i$ holds and to $f_{s+1}$ elsewhere, which can be written $\sum_i f_i\,\chi_{P_i}+f_{s+1}\,\overline{\mathrm{sg}}\big(\sum_i\chi_{P_i}\big)$;
  • the predicates $x=y$ (with characteristic function $\overline{\mathrm{sg}}|x-y|$), $x<y$ ($\mathrm{sg}(y\monus x)$), “$x$ is even” ($\chi(0)=1$, $\chi(x+1)=\overline{\mathrm{sg}}(\chi(x))$), “$x$ divides $y$” ($\overline{\mathrm{sg}}\,R(y,x)$), and their combinations by $\neg,\wedge,\vee$ and bounded quantification;
  • the predicate “$x$ is prime” and the function $\mathrm{Pr}(n)$ = $n$-th prime: $\mathrm{Pr}(0)=0$, $\mathrm{Pr}(n+1)=\mu y\le \mathrm{Pr}(n)!+1\ [y\text{ prime}\wedge y>\mathrm{Pr}(n)]$, the bound coming from Euclid’s proof (a prime factor of $\mathrm{Pr}(n)!+1$ is greater than $\mathrm{Pr}(n)$). Thus $\mathrm{Pr}(k)=p_k$ for $k\ge1$, with the numbering $p_1=2$, $p_2=3$, … used throughout the manual.

In plain words. The distance between two numbers, minimum, maximum, parity, divisibility, the GCD, and many other functions are built in the same way.

This catalogue shows that almost all of elementary arithmetic, and all the tests performed in it, can be programmed with loops whose number of rounds is known in advance. The functions that require more are rare and often exotic.

For the remainder: if $R(x,y)+1<y$, the remainder increases by 1; if it reaches $y$, it falls back to 0, and that is when the quotient increases. With the convention $y=0$, we get $R(x,0)=x$ and $\lfloor x/0\rfloor=0$, and we always have $x=y\lfloor x/y\rfloor+R(x,y)$. For the square root: $\overline{\mathrm{sg}}(i^2\monus x)=1$ if and only if $i^2\le x$, and we count the $i\ge1$ satisfying this condition.

Theorem
Robinson’s theorems

Let $S(x)=x+1$ and $Q(x)=x\monus\lfloor\sqrt x\rfloor^2$ (the excess of $x$ over the largest square not exceeding it).

  1. (R. M. Robinson, 1947) The primitive recursive functions of one variable form the smallest class $\mathcal C_1$ containing $S$ and $Q$, closed under addition ($f+g$), composition ($f\circ g$) and iteration $J$: $J[g](0)=0$, $J[g](n+1)=g(J[g](n))$.
  2. (J. Robinson, 1950) The total recursive functions of one variable form the smallest class $\mathcal C_2$ containing $S$ and $Q$, closed under addition, composition and inversion of surjective functions: $I[f](x)=\mu y\,[f(y)=x]$, for surjective $f$.

In plain words. The construction set can be reduced further: for functions of a single input, two basic functions and three ways of combining suffice.

This result, due to Raphael Robinson (1947), belongs to the search for maximal economy, like an architect looking for the smallest number of kinds of bricks needed to build everything. One discovers that the complexity of computation does not come from the richness of the bricks, but from the way they are assembled.

The easy inclusions: $Q$ is primitive recursive (library), and iteration is a special case of primitive recursion ($f(n+1)=h(n,f(n))$ with $h=\sigma[g,A^{(2)}_2]$), so $\mathcal C_1\subseteq\mathrm{RP}^{(1)}$. If $f$ is total recursive and surjective, $I[f]$ is recursive (by minimization) and total, so $\mathcal C_2$ contains only total recursive functions. It remains to show the reverse inclusions. Throughout, “$F\in\mathcal C$” denotes a function of one variable $n$, and an equality such as $F=G^2+3G+1$ reads $F(n)=G(n)^2+3G(n)+1$: it is obtained by addition and composition, as soon as $n\mapsto n^2$ is in the class. The basic fact, used constantly, is $$Q(m^2+r)=r\quad\text{if }0\le r\le 2m,\qquad\text{since }m^2\le m^2+r<(m+1)^2.$$

1. First functions of $\mathcal C_1$. The identity is $J[S]$, the zero function $Z=J[Q]$ (since $Q(0)=0$), the constants are $S\circ\cdots\circ S\circ Z$, and $kF=F+\cdots+F$.

  • $\mathrm{sg}=J[S\circ Q]$ (the sequence $0,1,1,1,\dots$ since $Q(0)+1=Q(1)+1=1$), and $\overline{\mathrm{sg}}(n)=Q(2\,\mathrm{sg}(n)+2)$, since $Q(2)=1$ and $Q(4)=0$.
  • $U(n)=n^2+2n$: this is $J[g]$ with $g(x)=x+Q(x)+3$, since if $x=n^2+2n$ then $Q(x)=2n$ and $g(x)=n^2+4n+3=U(n+1)$.
  • Predecessor: $\mathrm{pd}(n)=Q(n^2+3n)$, since $n^2+3n=(n+1)^2+(n-1)$ for $n\ge1$. And $n\mapsto n^2+3n$ is $J[g]$ with $g(x)=x+4+2Q(x+1)$: if $x=n^2+3n$, then $x+1=(n+1)^2+n$, $Q(x+1)=n$, and $g(x)=n^2+5n+4=(n+1)^2+3(n+1)$.
  • Square: $n^2=U(\mathrm{pd}(n))+\mathrm{sg}(n)$.
  • Parity $\mathrm{par}=J[Q\circ(S+S)]$ (the sequence $0,1,0,1,\dots$ since $Q(2)=1$, $Q(4)=0$), and remainder modulo 3, $m_3=J[Q\circ S\circ S]$ (since $Q(2)=1$, $Q(3)=2$, $Q(4)=0$).

2. Restricted subtraction. Set $D(a,b)=Q\big((a+b)^2+3a+b+1\big)$. If $a\ge b$, then $D(a,b)=a-b$: indeed $(a+b)^2+3a+b+1=(a+b+1)^2+(a-b)$ and $0\le a-b\le 2(a+b+1)$. (If $a<b$, the same computation gives $D(a,b)=3a+b+1$.) Thus $F\monus G\in\mathcal C$ as soon as $F\ge G$. We deduce:

  • equality: $D(a,b)+D(b,a)=(2a+2b+1)\cdot[a\ne b]$, so $\mathrm{eq}(a,b)=\overline{\mathrm{sg}}\big(D(a,b)+D(b,a)\big)$ equals $1$ if $a=b$, $0$ otherwise;
  • comparison: $D_2(a,b)=Q\big((a+b)^2+4a+1\big)$ equals $2(a-b)$ (even) if $a\ge b$ and $4a+1$ (odd) if $a<b$; so $\mathrm{lt}(a,b)=\mathrm{par}(D_2(a,b))=[a<b]$.

3. Halving and square root in $\mathcal C_1$. The sequence $\sigma(n)=\lfloor 3n/2\rfloor$ is $J[g]$ with $g(x)=x+1+\mathrm{par}(m_3(x))$: we advance by $1$ or by $2$ according to whether $\sigma(n)\equiv0$ or $1\pmod 3$, that is, according to the parity of $n$. So $\lfloor n/2\rfloor=D(\sigma(n),n)$. Likewise $\tau(n)=n+\lfloor\sqrt n\rfloor$ is $J[g]$ with $g(x)=x+1+\overline{\mathrm{sg}}\big(Q(4x+9)\big)$, whence $\lfloor\sqrt n\rfloor=D(\tau(n),n)$. Justification: if $n=r^2+q$ ($0\le q\le 2r$), then $x=\tau(n)=r^2+r+q$, and $n+1$ is a square if and only if $q=2r$, if and only if $4x+9=(2r+3)^2$; for $q<2r$, we have $(2r+1)^2<4x+9<(2r+3)^2$, and $4x+9$, being odd, cannot equal $(2r+2)^2$.

4. Product and pairs. Product by a Boolean: for $c\in\{0,1\}$, $Q\big((x+c)^2+2x+1\big)=c\,(2x+1)$, so $c\cdot x=\big\lfloor D\big(c(2x+1),c\big)/2\big\rfloor$. Hence the choice “if $c$ then $u$ else $v$”: $\mathrm{sel}(c,u,v)=c\cdot u+\overline{\mathrm{sg}}(c)\cdot v$. The general product: $ab=\big\lfloor D\big((a+b)^2,\,a^2+b^2\big)/2\big\rfloor$. The coding of pairs $$\pi(a,b)=(a+b)^2+a,\qquad K(z)=Q(z),\qquad L(z)=D\big(\lfloor\sqrt z\rfloor,\,Q(z)\big)$$ satisfies $K(\pi(a,b))=a$ and $L(\pi(a,b))=b$ (since $a\le 2(a+b)$), $\pi(0,0)=0$, and $\pi(a,b)$ is strictly increasing in $b$. If $F,G\in\mathcal C$, then $\pi(F,G)\in\mathcal C$. Tuples are coded by nesting to the left: $\langle x\rangle=x$, $\langle x_1,\dots,x_k,y\rangle=\pi(\langle x_1,\dots,x_k\rangle,y)$.

5. Iteration from an arbitrary starting point. For $g\in\mathcal C_1$, set $\Phi_g(\pi(a,b))=g^b(a)$. We show that $\Phi_g\in\mathcal C_1$ (on codes; elsewhere its value does not matter). The idea is to schedule all the computations in a single iteration starting from $0$: the code $c$ is allotted the block of steps $[T(c),T(c+1)[$, where $T(c)=c^2+c$, of length $2c+2$, enough to apply $g$ up to $L(c)\le c$ times. The state is $w=\pi(c,\pi(k,v))$ (current block, step within the block, current value), and we set $G(w)=\pi(c',\pi(k',v'))$ with $e=\mathrm{eq}(k,2c+1)$ and $$c'=c+e,\qquad k'=\overline{\mathrm{sg}}(e)\cdot(k+1),\qquad v'=\mathrm{sel}\Big(e,\ K(c+1),\ \mathrm{sel}\big(\mathrm{lt}(k,L(c)),\,g(v),\,v\big)\Big).$$ In block $c$, we start from $v=K(c)$, apply $g$ as long as $k<L(c)$, then wait; at the end of the block, we move to code $c+1$. Since the iteration $J[G]$ starts from the state $0=\pi(0,\pi(0,\,K(0)))$, an induction on $c$ shows that $J[G](T(c)+2c+1)=\pi(c,\pi(2c+1,\,g^{L(c)}(K(c))))$ for every code $c$, whence $\Phi_g(c)=L\big(L(J[G](c^2+3c+1))\big)$, which is in $\mathcal C_1$.

6. All primitive recursive functions. Permuting the arguments and adding a dummy argument if necessary, we may assume recursions of the form $f(\vec x,0)=g(\vec x)$, $f(\vec x,y+1)=h(\vec x,y,f(\vec x,y))$, with no function of arity $0$. With every primitive recursive $f$ of arity $k$, associate $\hat f(z)=f(x_1,\dots,x_k)$ where $z=\langle x_1,\dots,x_k\rangle$ (the $x_i$ are obtained from $z$ by $K$ and $L$). We show by induction that $\hat f\in\mathcal C_1$; for $k=1$, $\hat f=f$, which proves the theorem.

  • Base functions: constants, $S$, and projections, which are composites of $K$ and $L$.
  • Substitution $f=\sigma[g,h_1,\dots,h_m]$: $\hat f(z)=\hat g\big(\langle\hat h_1(z),\dots,\hat h_m(z)\rangle\big)$.
  • Recursion: for $z=\pi(X,y)$ with $X=\langle\vec x\rangle$, iterate on the states $w=\pi(\pi(X,i),v)$ the function $G(w)=\pi\big(\pi(K(K(w)),\,L(K(w))+1),\ \hat h(w)\big)$ (note that $w$ is exactly the code of $(\vec x,i,v)$), starting from $s(X)=\pi(\pi(X,0),\hat g(X))$. Then $\hat f(z)=L\Big(\Phi_G\big(\pi(s(K(z)),L(z))\big)\Big)$.

7. The second theorem. It suffices to show that $\mathcal C_2$ contains $\mathcal C_1$ and allows minimization.

  • First functions by inversion. $Q$ is surjective and $I[Q](x)=\lceil x/2\rceil^2+x$ (the least $y=m^2+x$ with $x\le 2m$). Hence the identity $Q\circ I[Q]$, doubling $2x=Q(I[Q](x))+Q(I[Q](x))$, and $U(k)=I[Q](2k)=k^2+2k$. The function $y\mapsto Q(y+1)$ is surjective and $\mathrm{pd}=Q\circ I[Q\circ S]$. Then $Z=Q\circ S\circ U$; $\mathrm{pd}$ is surjective and $I[\mathrm{pd}](x)=x+\mathrm{sg}(x)$, whence $\mathrm{sg}(n)=Q\big(I[\mathrm{pd}](U(n))+1\big)=Q\big((n+1)^2+\mathrm{sg}(n)\big)$. The square, $\overline{\mathrm{sg}}$, $D$ and $\mathrm{eq}$ are then obtained as in steps 1 and 2.
  • Halving. The function $f(z)=2Q(z)+\mathrm{eq}\big(D(z,Q(z)),\,Q(z)^2\big)$ is surjective: for $z=s^2+q$ ($q\le 2s$), it equals $2q+[s=q]$, and $s=q+1$ and $s=q$ give $2q$ and $2q+1$. If $f(z)=n$, then $Q(z)=\lfloor n/2\rfloor$: so $\lfloor n/2\rfloor=Q(I[f](n))$, then $\mathrm{par}(n)=D(n,2\lfloor n/2\rfloor)$.
  • Root. $P(x)=D(x,Q(x))=\lfloor\sqrt x\rfloor^2$ is a square $s^2$, and $Q(s^2-1)=2s-2$ for $s\ge1$ (since $s^2-1=(s-1)^2+2(s-1)$). So $\lfloor\sqrt x\rfloor=\big\lfloor\big(Q(\mathrm{pd}(P(x)))+2\,\mathrm{sg}(P(x))\big)/2\big\rfloor$.
  • Minimization. With these functions, steps 2 and 4 hold in $\mathcal C_2$. Let $\chi\in\mathcal C_2$ with values in $\{0,1\}$ be such that, for every $X$, there is $y$ with $\chi(\pi(X,y))=1$. For even $w$, set $z=w/2$ and $c=[Q(z)\le\lfloor\sqrt z\rfloor]\cdot\chi(z)$ ($z$ is a genuine code and satisfies the condition), $h(w)=2Q(z)$ if $c=1$, $h(w)=1$ if $c=0$; and $h(w)=w$ for odd $w$. Then $h\in\mathcal C_2$ (selections), $h$ is surjective (odd numbers are reached by themselves, $2X$ by $2\pi(X,y)$ for a suitable $y$), and the least preimage of $2X$ is $2\pi(X,y_0)$ where $y_0=\mu y\,[\chi(\pi(X,y))=1]$, since $\pi(X,y)$ increases with $y$. So $X\mapsto y_0=L\big(\lfloor I[h](2X)/2\rfloor\big)$ is in $\mathcal C_2$.
  • Iteration. For $g\in\mathcal C_2$, $J[g](n)=\Gamma(n,w_n)$ where $\Gamma$ is Gödel’s function (see relative recursion: $\Gamma(i,w)$ is the remainder of $K(w)$ modulo $1+(i+1)L(w)$, and every finite sequence has a code $w$), and $w_n=\mu w\,[\Gamma(0,w)=0\wedge E(n,w)=n]$ with $E(n,w)=\mu z\,[z=n\vee\Gamma(z+1,w)\ne g(\Gamma(z,w))]$. These two searches always succeed (the second before $n$, the first by the Chinese remainder theorem), and so do the remainder $u\bmod m=D(u,\,m\lfloor u/m\rfloor)$ and the quotient $\lfloor u/m\rfloor=\mu z\,[u<(z+1)m]$ ($m\ge1$): everything is expressed in $\mathcal C_2$ by the coded operations and the minimization above. So $\mathcal C_2$ is closed under iteration, and contains $\mathcal C_1=\mathrm{RP}^{(1)}$.
  • Conclusion. This step uses the Kleene normal form, proved in chapter 6. Its proof does not use Robinson’s theorems, which are used nowhere else: there is no circularity, and this step can be read after chapter 6. If $f$ is total recursive of one variable, the normal form gives $f(x)=U(\mu y\,T_1(e,x,y))$ with $T_1$ and $U$ primitive recursive, and the search succeeds for every $x$. By step 6, $\hat T_1(\pi(x,y))$ is in $\mathcal C_1\subseteq\mathcal C_2$, and the minimization above gives $f\in\mathcal C_2$.

Each construction has been checked by program, implementing the operations $+$, $\circ$, $J$ and $I$ literally (inversion by search in a table):

  • in $\mathcal C_2$: identity, doubling, $U$, $\mathrm{pd}$, $\mathrm{sg}$, square, halving and root by inversion, for $n<120$, as well as the surjectivity of the halving function $f$ on the values tested; and minimization by inversion, compared with a direct search for a test predicate on $X<40$.

These checks do not replace the proofs, but they rule out computational errors, which are frequent in constructions of this kind. For example, here is the square root of $\mathcal C_1$ in Python:

Codings in the integers

A computer handles only numbers, and yet it processes texts, images, programs. The secret is coding: one agrees on a way of representing each object by a number. This section shows how to represent a pair of numbers, then a list, then a word, by a single number, in such a way that the original object can always be recovered. This is the idea that will allow Gödel to make arithmetic speak about itself, and Turing to design a program that reads other programs.

Codings reduce structured objects (pairs, sequences, words, programs) to integers, by primitive recursive functions in both directions.

Proposition
Cantor pairing function

The function $\langle x,y\rangle=\dfrac{(x+y)(x+y+1)}{2}+x$ is a primitive recursive bijection from $\N^2$ onto $\N$, whose inverses $\pi_1,\pi_2$ (with $\pi_1(\langle x,y\rangle)=x$, $\pi_2(\langle x,y\rangle)=y$) are primitive recursive. Iterating, $\langle x_1,\dots,x_n\rangle=\langle x_1,\langle x_2,\dots,x_n\rangle\rangle$ codes $\N^n$ bijectively.

In plain words. All pairs of numbers, $(0,0)$, $(0,1)$, $(1,0)$, $(0,2)$… can be numbered so that each pair receives a number and each number corresponds to a single pair. A pair of numbers can therefore be replaced by a single number, without losing anything.

The pairs are arranged in diagonals, as one runs through an infinite table in a zigzag. This arrangement, devised by Georg Cantor, shows that there are “no more” pairs of integers than integers. It also makes it possible to reduce every function of several inputs to a function of a single input.

Let $w=x+y$ and $T(w)=w(w+1)/2$, the number of pairs with sum $<w$. The pairs with sum $w$ receive the numbers $T(w),T(w)+1,\dots,T(w)+w$, in the order $x=0,\dots,w$; since $T(w)+w<T(w+1)$, we get a bijection. Conversely, for a given $z$, $w=\mu w\le z\,[T(w+1)>z]$, then $\pi_1(z)=z\monus T(w)$ and $\pi_2(z)=w\monus\pi_1(z)$: these are bounded minimizations, hence primitive recursive. Explicitly, $w=\big\lfloor(\sqrt{8z+1}-1)/2\big\rfloor$.

Remark: $\dfrac{(x+y)(x+y+1)}{2}+x=\dfrac{(x+y)^2+3x+y}{2}$, another common form.

Definition
Gödel numbering of words and of sequences of words

Let $\Sigma=\{S_0,\dots,S_n\}$ be an alphabet, whose letters are coded by $\gamma(S_i)=2i+1$ (odd numbers). We write $p_1=2,p_2=3,p_3=5,\dots$ for the primes.

  • The Gödel number of a nonempty word $a_1\cdots a_n$ is $\mathrm{gn}(a_1\cdots a_n)=\prod_{k=1}^n p_k^{\gamma(a_k)}$.
  • The Gödel number of a nonempty sequence of nonempty words $M_1,\dots,M_n$ is $\prod_{k=1}^n p_k^{\mathrm{gn}(M_k)}$.

In plain words. Every word written with a fixed alphabet can be represented by an integer, in such a way that the word can always be recovered from the number. The method uses prime numbers: the first letter is placed in the exponent of 2, the second in the exponent of 3, and so on.

This simple idea had immense consequences. A mathematical statement, a proof, a program are words; they therefore become numbers, and the mathematics of numbers can speak about statements, proofs and programs. This is how Kurt Gödel was able to build, in 1931, a statement that speaks about itself (see Incompleteness).

The coding is injective by uniqueness of prime factorization, and decoding is primitive recursive thanks to the functions $(x)_k$ and the length $\ell(x)=\mu k\le x\,[(x)_{k+1}=0]$. A word code has an odd exponent of 2 (the code of a letter), a sequence code an even exponent of 2 (the code of a nonempty word, which is even): the two kinds of codes can therefore be told apart.

With $\gamma(B)=\gamma(S_0)=1$ and $\gamma(1)=\gamma(S_1)=3$: $\mathrm{gn}(1\,1\,B)=2^3\cdot3^3\cdot5^1=1080$. Decoding 1080: $1080=2^3\cdot3^3\cdot5$, exponents $3,3,1$, hence the word $S_1S_1S_0$.

Sequence codes quickly become gigantic: the sequence consisting of the single word $11B$ has code $2^{1080}$, a number with 326 digits. These numbers are never computed in practice; all that matters is the existence of primitive recursive functions that manipulate them.

Proposition
Other codings of pairs and sequences
  • The binary coding $P(x,y)=2^x(2y+1)\monus1$ is a primitive recursive bijection from $\N^2$ onto $\N$, with inverses $Q(z)$ = exponent of 2 in $z+1$ and $R(z)=\big((z+1)/2^{Q(z)}\monus1\big)/2$.
  • If $\tau$ is a primitive recursive coding of $\N^2$ onto $\N$ (Cantor or binary), $k$-tuples are coded by $\tau^1(x)=x$, $\tau^{k+1}(x_1,\dots,x_{k+1})=\tau(\tau^k(x_1,\dots,x_k),x_{k+1})$, and finite sequences of arbitrary length by $\tau^*(\,)=0$, $\tau^*(x_1,\dots,x_k)=\tau(\tau^k(x_1,\dots,x_k),k\monus1)+1$. One often writes $\langle x_1,\dots,x_k\rangle$ (“bracket” notation).

In plain words. There are many other ways of coding pairs and lists by numbers. All of them are suitable, provided coding and decoding can be done by a computation.

Choosing a coding is like choosing a file format: a matter of convenience, not of principle. What matters is that a program can go from the object to the number and from the number to the object.

Every integer $z+1\ge1$ can be written uniquely as $2^x\cdot m$ with $m$ odd, $m=2y+1$, which proves bijectivity. $Q(z)=\exp(1,z+1)$ where $\exp(n,x)$, the exponent of $\mathrm{Pr}(n)$ in $x$, equals $\mu y\le x\,[\neg\,\mathrm{Pr}(n)^{y+1}\mid x]$, primitive recursive. The formulas have been checked by program for all $z<500$, as well as the explicit inversion formulas for Cantor’s coding given above.

Proposition
The primitive recursive functions cannot be enumerated primitive recursively

There is no primitive recursive function $g(n,x)$ such that every primitive recursive function $f$ of one variable can be written $f=g(n,\cdot)$ for some $n$. (There is such a $g$ that is total recursive, but it is not primitive recursive.)

In plain words. One cannot write, with “repeat $n$ times” loops alone, a program able to run all the programs written with these same loops.

If such an interpreter existed, one could build a program that does the opposite of what each program does on itself, and this program could appear nowhere in the list. This is the diagonal argument, which will come back throughout the manual. It follows that a language in which everything halts cannot contain its own interpreter.

If $g$ existed, $h(x)=g(x,x)+1$ would be primitive recursive, so $h=g(n,\cdot)$ for some $n$, and $h(n)=g(n,n)+1\ne g(n,n)=h(n)$.

Partial recursive functions

One last recipe is missing, the most important one: search until found. We try 0, then 1, then 2, and stop at the first number that fits. If none fits, we search forever. This recipe is the only one that may fail to stop; it is also the only one that makes it possible to reach everything computable.

Definition
Unbounded minimization and (partial) recursive functions

If $g:\N^{n+1}\to\N$ is a (partial) function, the minimization $\mu[g]$ is the partial function of arity $n$:

$$\mu[g](\vec x)\simeq\text{the least } y \text{ such that } g(\vec x,y)=0 \text{ and } g(\vec x,z)\conv \text{ for all } z<y,$$

undefined if no such $y$ exists. The set $\PR$ of (partial) recursive functions is the smallest set of partial functions containing the base functions ($m^{(k)}$, $S$, $A^{(k)}_i$) and closed under substitution, primitive recursion and minimization. We write $\mathcal R$ for the set of total recursive functions.

In plain words. We add one last recipe: look for the smallest number that makes a certain quantity equal to zero, by trying 0, 1, 2… without limit. If it is found, it is the answer; otherwise, the search lasts forever and the function has no value. The functions obtained in this way are the recursive functions.

In programming, this is the “while” loop: on entering, one does not know how many rounds will be made. With it come both the full power of computation and the risk of never stopping. One cannot have one without the other: it is one of the most important lessons of the manual.

The condition “$g(\vec x,z)\conv$ for all $z<y$” reflects actual execution: to reach the candidate $y$, the computations of $g(\vec x,0),\dots,g(\vec x,y-1)$ must have terminated. Minimization can be restricted to total functions $g$ (one then speaks of “regular minimization”) without changing the class obtained: this is a consequence of the normal form theorem, proved in chapter 6 without using this point, which shows that every recursive function can be written $U(\mu y\,T_n(e,\vec x,y))$ with a single minimization, applied to a primitive recursive function.

Division can be written, staying within $\N$: $\lfloor x/y\rfloor\simeq\mu q\,\big[\,\overline{\mathrm{sg}}\big(((q+1)\,y)\monus x\big)=0\,\big]$.

An example of a partial function obtained by minimization (Boitet’s lecture notes): $f(x)=\mu y\,[\,|y+y-x|=0\,]$ equals $x/2$ if $x$ is even and is undefined if $x$ is odd. The function $(y,x)\mapsto|y+y-x|$ is not regular: for odd $x$, it never vanishes, and the search does not terminate.

In the compiler, choose “Quotient” with input 7, 0: the Turing machine produced does not halt (the simulator gives up after 5 million steps), whereas with 7, 2 it answers 3.

The file recursive.py of the downloadable programs implements exactly the definitions of this chapter. A term is a tree whose nodes are the six constructions; the arity is checked at construction time (an ill-formed term is rejected), and evaluation follows the defining equations. Primitive recursion is a for loop whose number of rounds is fixed before entering; minimization is a while loop.

def _ev(t, args, fast):
    if isinstance(t, Const):
        return t.m                                  # m^(k)
    if isinstance(t, Succ):
        return args[0] + 1                          # S
    if isinstance(t, Proj):
        return args[t.i - 1]                        # A^(k)_i
    if isinstance(t, Comp):                         # sigma[g, h1..hk]
        return _ev(t.g, tuple(_ev(h, args, fast) for h in t.hs), fast)
    if isinstance(t, Rec):                          # rho[g, h]
        y, rest = args[0], args[1:]
        acc = _ev(t.g, rest, fast)
        for i in range(y):                     # the "for" loop: y rounds, known in advance
            acc = _ev(t.h, (i, acc) + rest, fast)
        return acc
    if isinstance(t, Mu):                           # mu[g]
        z = 0
        while True:                            # the "while" loop: number of rounds unknown
            if _ev(t.g, args + (z,), fast) == 0:
                return z
            z += 1

Definition
Recursive sets and predicates

A set $A\subseteq\N^n$ (or a predicate) is recursive (resp. primitive recursive) if its characteristic function $\chi_A$ is recursive (resp. primitive recursive). For a predicate $P$ of arity $n+1$, we write $\mu y\,P(\vec x,y)\simeq\mu[(\vec x,y)\mapsto 1\monus\chi_P(\vec x,y)]$, the least $y$ making $P$ true.

In plain words. A set of numbers is called recursive, or decidable, when a program can answer, for any number, yes or no to the question “is this number in the set?”, and always halt.

The even numbers, the prime numbers, the squares form decidable sets. The chapter Undecidability will show perfectly well-defined sets for which no program can ever answer correctly in all cases.

“Recursive”, “decidable” and “computable” are synonyms for sets: a set is decidable if a program that always halts answers the question “$x\in A$?”.

Theorem
Relative recursion; primitive recursion is superfluous

Let $A\subseteq\N$ and $c_A$ its characteristic function.

  1. The class $P^A$ of functions recursive relative to $A$ (or $A$-recursive) is the smallest class containing the base functions and $c_A$, closed under composition, primitive recursion and minimization (applied to total functions). For $A=\emptyset$, we recover the partial recursive functions; a set is $A$-recursive (or $A$-decidable) if its characteristic function is in $P^A$.
  2. Let $D^A$ be the smallest class containing the projections $A^{(n)}_i$, $S$, $+$, $\monus$, $\times$ and $c_A$, closed under composition and minimization (applied to total functions), without primitive recursion. Then $D^A=P^A$.

In plain words. One can add to the basic pieces a “black box” that answers a fixed question, and study what can be computed with its help. Moreover, the recipe “repeat $n$ times” is not indispensable: “search until found” suffices to replace it.

The black box is the oracle of the previous chapter, in another form. The second point shows that the most powerful recipe contains the others: a well-conducted search can simulate a repetition.

$D^A\subseteq P^A$ is clear. For the converse, the base functions are in $D^A$ ($0^{(n)}=A^{(n)}_1\monus A^{(n)}_1$), and we must show that $D^A$ is closed under primitive recursion. Let $f(0,\vec y)=g(\vec y)$, $f(x+1,\vec y)=h(x,f(x,\vec y),\vec y)$. Suppose we have a function $\Gamma\in D^A$ such that every finite sequence $a_0,\dots,a_n$ is “coded” by some $w$: $\Gamma(i,w)=a_i$ for $i\le n$. Then

$$f(x,\vec y)=\Gamma\Big(x,\ \mu w\,\big[\,\Gamma(0,w)=g(\vec y)\ \wedge\ \forall z<x\ \ \Gamma(z+1,w)=h(z,\Gamma(z,w),\vec y)\,\big]\Big),$$

where the bounded quantifier is eliminated by a second minimization: $\eta(x,w,\vec y)=\mu z\,[z=x\vee\Gamma(z+1,w)\ne h(z,\Gamma(z,w),\vec y)]$ and the condition becomes $\eta(x,w,\vec y)=x$, which is expressed with $|a-b|=(a\monus b)+(b\monus a)$.

Construction of $\Gamma$. The remainder $R(u,m)=u\monus m\cdot\mu z[(z+1)m>u]$ is in $D$. We set

$$\Gamma(i,w)=R\big(\pi_1(w),\ 1+(i+1)\pi_2(w)\big),$$

where $\pi_1,\pi_2$ are the inverses of the Cantor pairing $\langle x,y\rangle=((x+y)^2+3x+y)/2$, definable in $D$ by minimization. Given $a_0,\dots,a_n$, let $M=\max_i a_i+1$ and $v=2M\cdot(n+1)!$. The numbers $m_i=1+(i+1)v$ ($0\le i\le n$) are pairwise coprime (a prime $p$ dividing $m_i$ and $m_j$ would divide $(j-i)v$, hence $v$ since $j-i\le n$ divides $(n+1)!$, but $p\mid m_i=1+(i+1)v$ does not divide $v$), and $a_i<M\le v<m_i$. By the Chinese remainder theorem, there is $u$ with $R(u,m_i)=a_i$ for all $i$, and $w=\langle u,v\rangle$ works.

Chinese remainder theorem. If $m_1,\dots,m_n$ are pairwise coprime and $a_i<m_i$, there is $u$ with $u\equiv a_i\pmod{m_i}$ for all $i$. By induction on $n$: if $u_n$ works for the first $n$, $M_n=m_1\cdots m_n$ is coprime to $m_{n+1}$; by Bézout, $xM_n+ym_{n+1}=1$ with $x,y$ integers, whence $s,r$ with $u_n+sM_n=a_{n+1}+rm_{n+1}$; adding a multiple of $m_{n+1}$ to $s$ if necessary, we take $s\ge0$, and $u_{n+1}=u_n+sM_n$ works.

The function $\Gamma$ has been tested: for the sequences $(3,0,7)$, $(5,5,1,2)$, $(0)$ and $(9,2)$, we computed $v$ and the moduli $m_i$, checked that they are coprime, found $u$ by Chinese remaindering and checked $\Gamma(i,\langle u,v\rangle)=a_i$. For example for $(9,2)$: $M=10$, $v=2\cdot10\cdot2!=40$, $m_0=41$, $m_1=81$, and the least suitable $u$ is $u=2756=67\cdot41+9=34\cdot81+2$.

The same twelve functions are defined in the three models of this manual: here by the recursion schemes, in the chapter Turing machines by machines, in the chapter λ-calculus by terms. Example
Addition

Specification: $\mathrm{add}(x,y)=x+y$.

$\mathrm{add}=\rho\big[A^{(1)}_1,\ \sigma[S,A^{(3)}_2]\big]$, that is, $\mathrm{add}(0,y)=y$ and $\mathrm{add}(x+1,y)=S(\mathrm{add}(x,y))$.

The three versions: recursive · Turing · λ-calculus.

By induction on $x$. $\mathrm{add}(0,y)=A^{(1)}_1(y)=y=0+y$. If $\mathrm{add}(x,y)=x+y$, then $\mathrm{add}(x+1,y)=\sigma[S,A^{(3)}_2](x,\mathrm{add}(x,y),y)=S(x+y)=(x+1)+y$.

With the convention of this site, $\rho[g,h](x+1,\vec y)=h(x,\rho[g,h](x,\vec y),\vec y)$: the second argument of $h$ is the recursive call, hence $A^{(3)}_2$.

Example
Predecessor

Specification: $\mathrm{pred}(x)=x\monus1$.

$\mathrm{pred}=\rho\big[0^{(0)},\ A^{(2)}_1\big]$: $\mathrm{pred}(0)=0$, $\mathrm{pred}(y+1)=y$.

The three versions: recursive · Turing · λ-calculus.

$\mathrm{pred}(0)=0=0\monus1$ and $\mathrm{pred}(y+1)=A^{(2)}_1(y,\mathrm{pred}(y))=y=(y+1)\monus1$. The recursion step does not use the recursive call, only the counter.

Term: $\rho[0^{(0)},A^{(2)}_1]$, a function of arity 1.

Example
Truncated subtraction

Specification: $x\monus y=\max(x-y,0)$.

$x\monus0=x$, $x\monus(y+1)=\mathrm{pred}(x\monus y)$; formally $\monus=\sigma\big[\rho[A^{(1)}_1,\sigma[\mathrm{pred},A^{(3)}_2]],\ A^{(2)}_2,A^{(2)}_1\big]$ (recursion on $y$, then swapping the arguments).

The three versions: recursive · Turing · λ-calculus.

By induction on $y$. $x\monus0=x$. If $x\monus y=\max(x-y,0)$: when $x>y$, $\mathrm{pred}(x-y)=x-y-1=\max(x-(y+1),0)$; when $x\le y$, $\mathrm{pred}(0)=0=\max(x-y-1,0)$.

The recursion is on the first argument of $\rho$; we therefore define $r(y,x)=x\monus y$ by $\rho$, then $x\monus y=r(A^{(2)}_2(x,y),A^{(2)}_1(x,y))$.

Example
Multiplication

Specification: $\mathrm{mult}(x,y)=x\times y$.

$\mathrm{mult}=\rho\big[0^{(1)},\ \sigma[\mathrm{add},A^{(3)}_3,A^{(3)}_2]\big]$: $\mathrm{mult}(0,y)=0$, $\mathrm{mult}(x+1,y)=y+\mathrm{mult}(x,y)$.

The three versions: recursive · Turing · λ-calculus.

By induction on $x$: $\mathrm{mult}(0,y)=0$ and $\mathrm{mult}(x+1,y)=\mathrm{add}(y,xy)=y+xy=(x+1)y$, using the correctness of $\mathrm{add}$.

$h(x,v,y)=\mathrm{add}(A^{(3)}_3,A^{(3)}_2)(x,v,y)=y+v$: the step adds $y$ to the recursive call $v$.

Example
Power

Specification: $\mathrm{pow}(x,y)=x^y$.

$t(0,x)=1$, $t(y+1,x)=x\times t(y,x)$, and $x^y=t(y,x)$: $t=\rho\big[1^{(1)},\sigma[\mathrm{mult},A^{(3)}_3,A^{(3)}_2]\big]$, $\mathrm{pow}=\sigma[t,A^{(2)}_2,A^{(2)}_1]$.

The three versions: recursive · Turing · λ-calculus.

By induction on $y$: $t(0,x)=1=x^0$ and $t(y+1,x)=\mathrm{mult}(x,x^y)=x^{y+1}$.

Evaluation and compilation: see the compiled machine.

Example
Factorial

Specification: $\mathrm{fact}(y)=y!$.

$\mathrm{fact}=\rho\big[1^{(0)},\ \sigma[\mathrm{mult},\sigma[S,A^{(2)}_1],A^{(2)}_2]\big]$: $0!=1$, $(y+1)!=(y+1)\times y!$.

The three versions: recursive · Turing · λ-calculus.

This is the definition of the factorial: $\mathrm{fact}(0)=1=0!$ and $\mathrm{fact}(y+1)=\mathrm{mult}(S(y),\mathrm{fact}(y))=(y+1)\cdot y!=(y+1)!$, by induction. Here the step uses the counter $y$, not only the recursive call.

Evaluation and compilation: see the compiled machine.

Example
Sign and zero test

Specification: $\mathrm{sg}(x)=1$ if $x>0$, $0$ otherwise; $\overline{\mathrm{sg}}(x)=1-\mathrm{sg}(x)$.

$\mathrm{sg}=\rho\big[0^{(0)},1^{(2)}\big]$ and $\overline{\mathrm{sg}}=\rho\big[1^{(0)},0^{(2)}\big]$.

The three versions: recursive · Turing · λ-calculus.

$\mathrm{sg}(0)=0$ and $\mathrm{sg}(y+1)=1^{(2)}(y,\mathrm{sg}(y))=1$; likewise for $\overline{\mathrm{sg}}$. The step ignores everything: here a primitive recursion serves as a simple “zero or not” test.

These two functions serve as Booleans: $\chi_{P\wedge Q}=\chi_P\cdot\chi_Q$, $\chi_{\neg P}=\overline{\mathrm{sg}}(\chi_P)$, etc. (library).

Example
Equality

Specification: $\chi_=(x,y)=1$ if $x=y$, $0$ otherwise.

$\chi_=(x,y)=\overline{\mathrm{sg}}\big((x\monus y)+(y\monus x)\big)$, that is, $\chi_==\sigma\big[\overline{\mathrm{sg}},\sigma[\mathrm{add},\monus,\sigma[\monus,A^{(2)}_2,A^{(2)}_1]]\big]$.

The three versions: recursive · Turing · λ-calculus.

$(x\monus y)+(y\monus x)=|x-y|$ (one of the two terms is zero, the other is the difference), which is zero if and only if $x=y$; $\overline{\mathrm{sg}}$ then returns $1$, and $0$ otherwise.

Evaluation and compilation (7,633 quadruples): see the Turing version, which also gives a hand-written machine with 27 quadruples.

Example
Quotient (minimization)

Specification: $\mathrm{quot}(x,y)=\lfloor x/y\rfloor$ if $y\ge1$, undefined if $y=0$.

$\mathrm{quot}(x,y)=\mu z\,\big[\overline{\mathrm{sg}}\big((z+1)\,y\monus x\big)=0\big]$, that is, the least $z$ such that $(z+1)\,y>x$.

The three versions: recursive · Turing · λ-calculus.

The minimized function $g(x,y,z)=\overline{\mathrm{sg}}((z+1)y\monus x)$ is total and equals $0$ exactly when $(z+1)y>x$. If $y\ge1$, let $q=\lfloor x/y\rfloor$: $qy\le x<(q+1)y$, so $g(x,y,q)=0$, and for $z<q$, $(z+1)y\le qy\le x$, so $g(x,y,z)=1$: the minimization returns $q$. If $y=0$, $(z+1)\cdot0=0\not>x$ for all $z$: there is no witness and $\mathrm{quot}(x,0)$ is undefined, as the definition of $\mu$ requires.

Term:

$$\mu\big[\sigma[\overline{\mathrm{sg}},\sigma[\monus,\sigma[\mathrm{mult},\sigma[S,A^{(3)}_3],A^{(3)}_2],A^{(3)}_1]]\big]$$

Evaluation and compilation: see the compiled machine.

Exercises

★Exercise 1 — Writing a term

Write the function $f(x,y)=2x+y$ using only the base functions and the schemes $\sigma$ and $\rho$.

Solution

By recursion on the first argument: $f(0,y)=y$ and $f(x+1,y)=f(x,y)+2=S(S(f(x,y)))$. With the arities of the definition ($g$ of arity 1, $h$ of arity 3, applied to $(x,f(x,y),y)$):

$$f=\rho\Big[A^{(1)}_1,\ \sigma\big[S,\ \sigma[S,A^{(3)}_2]\big]\Big].$$

Check: $\sigma[S,A^{(3)}_2](x,u,y)=u+1$, then $\sigma[S,\sigma[S,A^{(3)}_2]](x,u,y)=u+2$.

★Exercise 2 — A partial minimization

Let $g(x,y)=|x-y^2|$. What is the function $\mu[g]$? Is it total?

Solution

$g$ is total (primitive recursive), so the condition “$g(x,z)\conv$ for $z<y$” is automatic, and $\mu[g](x)$ is the least $y$ such that $y^2=x$. Thus $\mu[g](x)=\sqrt x$ if $x$ is a perfect square, and $\mu[g](x)\ind$ otherwise: $\mu[g](4)=2$, $\mu[g](5)\ind$. Minimizing a total function can therefore produce a partial function; this is what distinguishes $\PR$ from $\RP$.

★Exercise 3 — Coding and decoding pairs

Compute $\langle 2,3\rangle$ for the Cantor pairing, then find the pair coded by $17$ and by $20$. Show that $\pi_1$ and $\pi_2$ are primitive recursive.

Solution

$\langle2,3\rangle=\frac{5\cdot6}2+2=17$. To decode $z$, we look for the “diagonal” $s=x+y$: it is the largest $s$ such that $\frac{s(s+1)}2\le z$. For $z=17$: $\frac{5\cdot6}2=15\le17<21=\frac{6\cdot7}2$, so $s=5$, $x=17-15=2$, $y=s-x=3$. For $z=20$: $s=5$, $x=5$, $y=0$.

In general $s(z)=\mu s\le z\,\big[(s+1)(s+2)>2z\big]$ (bounded minimization of a primitive recursive predicate), then $\pi_1(z)=z\monus\frac{s(z)(s(z)+1)}2$ and $\pi_2(z)=s(z)\monus\pi_1(z)$; division by 2 is the quotient from the library.

★★Exercise 4 — Fibonacci via pairs

The Fibonacci sequence is defined by $F(0)=0$, $F(1)=1$, $F(x+2)=F(x+1)+F(x)$. The scheme $\rho$ only allows the previous value to be used. Show nevertheless that $F$ is primitive recursive.

Solution

We compute two values at once, stored in a pair: $g(x)=\langle F(x),F(x+1)\rangle$. Then $g(0)=\langle0,1\rangle=1$ and

$$g(x+1)=\big\langle F(x+1),F(x)+F(x+1)\big\rangle=\big\langle\pi_2(g(x)),\ \pi_1(g(x))+\pi_2(g(x))\big\rangle,$$

which has the form $g(x+1)=h(x,g(x))$ with $h$ primitive recursive (previous exercise). So $g\in\RP$, and $F=\pi_1\circ g\in\RP$. The same idea handles any recursion involving a fixed number of previous values, or several functions defined simultaneously.

★★Exercise 5 — Range of an increasing function

Let $f:\N\to\N$ be primitive recursive and strictly increasing. Show that its range $\{f(x):x\in\N\}$ is a primitive recursive set.

Solution

By induction, $f(x)\ge x$: $f(0)\ge0$, and $f(x+1)>f(x)\ge x$ gives $f(x+1)\ge x+1$. So if $y=f(x)$, then $x\le y$: $y\in\mathrm{Im}\,f\iff\exists x\le y\ f(x)=y$. The characteristic function is $\mathrm{sg}\big(\sum_{x\le y}\overline{\mathrm{sg}}\,|f(x)-y|\big)$, primitive recursive by bounded sums. Without monotonicity, the range of a primitive recursive function can be undecidable: it is an arbitrary (nonempty) semi-decidable set, see the chapter Semi-decidability.

★★★Exercise 6 — Course-of-values recursion

Let $h$ be primitive recursive and $f$ defined by $f(0)=a$ and $f(x+1)=h\big(x,\bar f(x)\big)$, where $\bar f(x)=\prod_{i\le x}p_{i+1}^{f(i)}$ codes the list $f(0),\dots,f(x)$. Show that $f$ is primitive recursive. Application: the function $c(0)=1$, $c(x+1)=\sum_{i\le x}c(i)\,c(x-i)$ (Catalan numbers) is primitive recursive.

Solution

We first show that $\bar f$ is primitive recursive: $\bar f(0)=2^a$, and

$$\bar f(x+1)=\bar f(x)\cdot p_{x+2}^{\,f(x+1)}=\bar f(x)\cdot\mathrm{Pr}(x+2)^{\,h(x,\bar f(x))},$$

of the form $\bar f(x+1)=H(x,\bar f(x))$ with $H(x,u)=u\cdot\mathrm{Pr}(x+2)^{h(x,u)}$ primitive recursive. Then $f(x)=\exp(x+1,\bar f(x))$, the exponent of $p_{x+1}$ in $\bar f(x)$, primitive recursive (codings).

For the Catalan numbers, $c(i)=\exp(i+1,u)$ when $u=\bar c(x)$ and $i\le x$, so $c(x+1)=h(x,\bar c(x))$ with $h(x,u)=\sum_{i\le x}\exp(i+1,u)\cdot\exp(x-i+1,u)$, primitive recursive by bounded sum. We get $1,1,2,5,14,42,\dots$
